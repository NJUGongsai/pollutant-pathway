## 一、问题陈述（为什么重设计）

chain13 实测：v2 豁免按设计工作，但**模拟解锁 13 题兑现 0/13**。锁有三道
（全部有候选级程序证据）：

| 锁 | 证据 | 涉及面 |
|---|---|---|
| 锁1 前置门资格窄 | 13 题 297 池候选中仅 17 件获救援尝试资格（attempted=17），其余死在普通编译门（no_alignment=141/枚举截断 76/transform_no_change 31/bonded 25） | 9/13 题连可执行候选都没有 |
| 锁2 救援件编译死 | 17 件救援尝试**成功 0**（全死于过门后编译：对齐/枚举） | 救援机制本身在，喂进去的件编不过 |
| 锁3 普通门 spec 无声明面 | 13 题中 4 题池内已有 H₂O 共底物 spec（rhea:14570 醛⇄醇水合/rhea:56586 环氧开环加水，普通门 compiled）——但**声明面（cosubstrate_event_contract/record_equation）只由 C 供给救援路径附加**，普通门 spec 不带 ⇒ 即使被选中执行，事件无声明链，pred1 unknown fail-closed，v2 豁免结构性不开 | 4/13 题钥匙在场但没齿 |

另有一块独立可成片回收面：25 件 `cosubstrate_bonded_contribution_unsupported`
全在 corpus 通道、去重仅 **11 个 RHEA 记录**（8 糖基转移酶+2 磷酸酶+1 EPSP 类），
族构成糖基 16/Pi+H₂O 8/无族 1。

## 二、目标与非目标

**目标**：让 partial 面（13 题所代表的「参考缺共底物参与物」题类）的共底物
候选能**带着可解析声明面**进池、被选中执行后可被 v2 豁免消费；同时把放宽
带来的 strict 题暴露面风险控制在预算内。

**非目标**（红线，全程不动）：不改判分口径与互变归一禁令；不动硬拒绝表与
零碳断言（NAD/ATP/CoA/FAD/THF/O₂/NH₃/CN⁻ 等，mimo Q4-5）；不给 decide 加
调用次数；不回滚 C 线与 v2（净零+净赚 2 已归因）；不改池宽/排序既有语义。

## 五、验证设计（chain14 合并批，与方差治理合并）

- **单变量**：chain14 = chain13 协议 + 拍板选定的 C 杠杆（其余不动：3 调用预算
  保持、v2 headline、no-cap）。
- **双跑两臂**：同协议 A1/A2 只差采样（≈2×6.3M tokens），一次拿杠杆效应量+
  同输入翻转率方差基线（hpc2 A/B 34/298 为参照锚）。
- **分族记账**（mimo Q4-4）：按 簿记四件/有机第二底物/机理类（C#N、NH₃ 等）
  分族记 exposure→面貌变化→S 得失；13 题去重记录面加权（4 题同 48 件候选
  构成，别把一份族面数四遍）。
- **判读停点**：分族 S 净得失任一族 ≤-3 即停点复盘；C 门新开 strict 题被挤成
  partial 的数量 >P3 预算即触发退出条件复审（预注册 §九退出条款沿用）。
- **卫生件随批**（不影响单变量性，运营面）：传输失败自动重试；采样参数显式
  化+落 calls 记录（当前无温度字段）。

## 六、风险登记（mimo Q3/Q4 采纳 + 程序面）

1. **暴露面**（最高）：L1/L3 放宽前必须先出「新开 C 门的现有 strict 题数」
   （P1/P3）；无该数字不发货。
2. **先声明链后放宽**：pred1 依赖生成侧发射；无链放宽=上行打不开、下行照吃。
3. **机制类共底物最高危**：小分子亲核加成（C#N→氰醇/NH₃→胺化/CH₂O→羟甲基）
   面貌=新产物、无 v2 兜底、封顶不计覆盖——分族记账里单列，只准诊断
   （legal_alternate_face 诊断标签为下一轮预注册候选，本轮不记分）。
4. **预期管理**：参考侧若剥共底物，多数收益封顶 partial（P4 计数定预期）；
   不承诺 strict 增量。
5. **归属造数据红线**（L4）：无键级映射不放行；歧义即拒；键合贡献身份永不
   入豁免面。
6. **单变量纪律**：chain13 归因困难的教训写死——任何同批新变量须预注册
   登记并可分族拆账。
