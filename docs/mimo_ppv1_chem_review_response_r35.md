## M1（hwall 新命中的化学合法性）

**一句话结论**：从化学面看，"括号显式氢按级差消耗"放开的是**表示层价态假墙**而非化学判据，本身造不出"记账通了但化学不该通还能得分"的命中——因为最终得分仍要求产物与参考严格身份相等；真正的边界残余在**开壳层/芳香性/互变异构**三处，且都表现为"垃圾候选占位"而非"假命中"。

展开：

1. **消耗规则在价态上是被逼出来的唯一解，不是任意放宽**。每个端点自身价态必须守恒：键级升 d、原价态已达允许值 ⇒ 该端点必须交出恰好 d 个 H（`atom_tool.py:496-503` 逐端点按级差减、存量不足截 0）。我核了 C/N/O 单价位原子与 P/S 多价位原子（{3,5}、{2,4,6}）在 d=1 情形：凡 n>0 时消费都是价态强制的，不存在"本可保留 H 却被白吃"的常见情形。所以"本不该脱氢的位点"这个担心，在**位点选择权**上不成立于工具——工具不选位点，模型声明的 target 才选位点，而 `check_target_consistency` 的终判要求执行产物 canonical 与 target 逐字相等（`atom_tool.py:771-778`，短路路径 697-709 同样要求相等），错位点的脱氢产物会 target_edit_mismatch 被拒。**该链路是否覆盖全部入池路径，待执行验证**（recorded 直通候选不走编辑+target 路径，但它整分子来自记录，不经 hwall）。

2. **"两边端点都吃 H"不是过度脱氢，是脱氢记账的化学正确写法**。醇→酮/醛（C–O 单→双：C 失 1H、O 失 1H，净失 H₂）、胺→亚胺、炔烃形成，都是每端各失 1——正是净脱氢 2H 的标准计量。苯甲醇→苯甲醛这类 c11 被 sanitize 拒、c12 通的例子，化学上就是最普通的醇氧化，RHEA 里占比极高，**不构成可疑命中类**。

3. **方向性不对称的真边界在键级"降低"侧**：升高消费 H，降低**不回填 H**。非括号原子靠 sanitize 按剩余价自动补隐式 H（酮→醇还原正常），但**括号 noImplicit 原子降键级后价态留洞，sanitize 会按自由基放行**（RDKit 对未满价 noImplicit 原子标 radical 电子）。hwall 让升侧与隐式原子行为对齐了，降侧括号原子仍是旧洞。**本批是否已有自由基产物通过，待执行验证**（需扫描 c12 产物 NumRadicalElectrons）。同理：多编辑序列里先被吃掉的 H 不能被后面的 break_bond 还原，结果方向是**欠氢（偏保守、易被 target/身份挡下）**，不是超价放行。

4. **互变异构与芳香体系**：① 互变异构体 canonical 身份不同 ⇒ keto/enol 对不上就丢命中，方向是**伤召回不伤精度**；唯一精度相关处是身份键本身——`check_target_consistency` 用了 `cn_identity` 双口径（`atom_tool.py:699-702`），**若 cn 口径含 InChI（对可迁移氢不敏感），互变异构可能被判同一身份；cn_identity 实现本请求未读到，待执行验证**——若属实，那是身份键设计问题、非 hwall 问题，且属程序侧冻结契约。② 芳香体系：执行前 `Kekulize(clearAromaticFlags=True)`（427-429），凯库勒环内单键升双可造出"累积双键型缺氢环"这类 sanitize 能过、化学上荒谬的结构（每个碳价态恰好 4）——但它与芳构参考 canonical 必不等 ⇒ **只污染排名、换不来命中**；建议做成披露扫描而非门（避免过拒）。

5. **一个表示层反推（不确定）**：c11 同题 AtomValenceException、c12 消失（20/35 指纹），说明底物 SMILES 带括号显式氢；括号 H 从何而来（管线 AddHs/RemoveHs 归一？记录原样？）**本请求无源码证据，待执行验证**。若确为归一则更坐实"hwall 是表示层假墙拆除"：同分子括号/非括号两种写法在改键后应回到同一产物，hwall 恰好消除了这种**写法依赖的执行差异**——这是化学上该有的性质。

6. **一个反向（过拒）微边界**：单→三键在多价位括号原子带 H 时，消费截 0 后价态可能落在非法中值（如 P 落 4）而被拒，其实更高允许价（5）可收——方向是丢命中不是假通，极罕见，登记即可。

**不确定/缺证据**：自由基通过实例数、cn_identity 是否含 InChI、target 门覆盖哪些入池路径、括号 H 来源——四项均需执行面证据。

## M2（hwall 边界钉得够不够）

**一句话结论**：现行负控族对"键级升高"方向在化学上够用（超价、无 H 端点、form_bond 不放宽、醚 O、独立 H/同位素原子各堵一类），但**没钉住"键级降低"侧的开壳层出口**，也缺可审计的脱氢披露——建议补 1 个硬负控 + 3 个披露位，不建议加化学可行性门。

展开（按优先序）：

| # | 建议 | 性质 | 化学理由 | 风险控制 |
|---|---|---|---|---|
| 1 | **sanitize 后自由基检查**（全原子 NumRadicalElectrons==0 才放行） | 硬负控 | 关死降键级/过量消费在括号 noImplicit 原子上留下的价态洞；自由基产物在 RHEA 已见题里不是合法参考形态 | 唯一例外需显式登记（若确有自由基参考，白名单而非放宽） |
| 2 | **逐编辑 H 消费披露**（端点 ID+数量进执行结果） | 披露 | 脱氢位点可审计，20 道指纹题可批量核查"脱氢位点是否像氧化还原酶该动的地方" | 零行为变化，不动判分 |
| 3 | **芳香性增量披露**（改键前芳环→改键后非芳、且编辑表无还原意图） | 披露 | 抓凯库勒环升键造出的累积双键/缺氢环垃圾候选 | 先披露后评估，防止过拒 |
| 4 | **杂原子端点（P/S/B/Si）键级升高计数** | 披露 | 允许价表对高价原子既过放又过拒（P 落 4 被拒这类），是工具面不是化学面 | 只计数，不做门 |

- 已钉住的不重复要求：真实超价（sanitize 终检 `atom_tool.py:530-538`）、季碳无 H（n=0 无从消费⇒超价拒）、form_bond 零触碰（452-458 硬拒 bond_already_present）、独立 H 原子含 [2H]（只动 numExplicitHs，图原子不进记账面）——**这四条我认可为充分**（对升高方向）。
- **不建议**补"脱氢位点化学可行性门"（比如只许醇/胺位点）：位点合法性由 model 声明的 target + 参考严格身份双重兜底，工具层再加机理判断会变成第二套金标口径，越过"判分零 LLM、判据冻结"的红线，也会造成大面积过拒。
- 另一处登记（非门）：`element_delta` 明文**氢不计**（`atom_tool.py:830-834`），脱氢在重原子元素守恒线上天然隐形——这是"氢当量不进参与物"的表示层既定口径，正确，但意味着**脱氢合理性在全链上只有 sanitize+身份两道闸**，故 #2 披露位价值更高。

## M3（D2 双刃的判分立场）

**一句话结论**："诚实=partial"立场**正确且应维持，绝不能靠生成侧删共底物 B 换 strict**；它与 T1′（产物侧辅因子恒不忽略）、NC-12（本通道 matched_strict 恒 0 的**范围限定**熔断）三者一致，且与"不改判分器换通过"的红线同向。

展开：

1. **化学面为什么站在诚实侧**：消耗共底物 B 的转化把 B 写进反应物侧、把拷贝产物写进产物侧，是**原子/质量账更完整**的写法；删 B 换 strict 等于为了对齐"参考抽取时把辅因子滤掉"这一**表示层约定**而把反应写得更不完整——化学上是倒退，工程上是游戏尺子。判分侧证据一致：exact 要求两侧集合严格相等（`evaluation.py:1063-1068`），B 在场 ⇒ superset ⇒ partial，这是**尺子与参考口径的结构关系**，不是候选化学错误。

2. **代价是可见的、且已被诚实预登记**：D2 全库 13 题 declared_copy_components **零道 strict**、3 道旧 strict→partial、退步指纹 4 道，方向与 s5b_builder 的落字完全一致——"事件恒 partial、结构性无 strict 通路、hit@1 预期贡献 = 0"（`s5b_builder.py:400-403, 464-467`）。**预期先写死、数字后落地**，这正是 D2 设计书"诚实拷贝型候选主要贡献 partial"要的量化，不存在事后解释。

3. **与 T1′ 一致性**：T1′ 说产物侧辅因子恒不忽略，D2 把反应侧 B/copy 同样不忽略，是同一诚实原则的两侧——若 D2 让步删 B，T1′ 立刻失去对称依据。**一致，维持。**

4. **与 NC-12 一致性**：NC-12 的熔断文本自带范围限定——"仅对当前剥除 B/copy 的 root-only 参考构建口径 matched_strict 恒 0；合法完整 B/copy 参考可 strict，不是漂移，且不得靠改评测器掩盖"（`recorded_source.py:196-197, 249-256`）。它是**断言而非禁令**：今天 0 是尺子口径的必然，不是化学失败；将来若参考构建侧改为含 B/copy（属参考口径变更，须走预注册、用户拍板），同批 D2 事件可合法 strict。**一致，且范围限定写得对，不要把 NC-12 读成"这批永远不算对"。**

5. **一个必须登记的尺子不对称（观察，不要求本轮改）**：hwall 让"默默脱氢"（H₂/NADH 不进参与物、`element_delta` 氢不计）拿到 strict，而 D2"明写共底物"却吃 partial——**同一类诚实问题（当量伙伴去哪了）在现行尺子下一边受奖一边受罚**。根源是参考抽取口径（辅因子不列）先于两者存在。建议把这条写成已知口径边界，防止后续轮次把 D2-partial 读成比"隐式脱氢 strict"更差的化学质量；也顺带回答了"要不要删 B"——不要，且**也不应**反过来要求脱氢候选补声明 NADH（那会成新门、动参考口径）。

展开：

1. **为什么不存在"可疑命中"类**（结构性论证）：strict 要求反应物/产物两侧参考节点全部严格命中且参与物集合相等（`evaluation.py:1063-1078`）。hwall 放开的只是"执行器能不能到达声明的 target"，到达后仍要 canonical==target、再要与参考严格身份相等——**hwall/D2 在结构上都无法让一个错分子变成 strict**。所以 92/130 的精度由冻结身份键兜底，化学面不需要作废任何类。反过来，它们的风险都落在**召回/排名**（垃圾候选占槽、掉位），与观察到的 125 uncovered、38 后位答案同向。

2. **三条 watch item（都不构成作废理由）**：
