1. **先引擎基线后 agent**：引擎基线零 LLM；agent 用冻结版本一次成型，
   不择优、不看了结果再重跑。
2. 判定规则先冻结再跑分（I2）：**闭卷轨道里程碑 hit@1 ≥ 30% 在此判定**
   （teacher 双轨裁决：60% 只挂覆盖轨道，不在本任务判定）；配对四格
   （agent vs 引擎 @1/@5）、hit@3/5、空答率、spurious 率、费用账全落盘；
   题域标签强制（与 dev/298 双向不外推）。
3. **298 同批复测一份**：同一冻结版本在 EC298 跑一次，作 post-hoc 参照——
   分开报告不混分，节名固定「已见基准回归跟踪」（I1：298 已被逐题审计
   暴露，永不改称盲测）。看分后不得改同一版本重跑再自称终测；需再改
   另起版本。

## 3. mimo 化学评审（AGENTS.md 三触发点，本任务占两个）

1. **出题前·考卷评审（触发点 2）**：题卷冻结**前**必出一份 mimo 考卷
   抽审请求 md（抽题化学合理性 + 金标口径抽审 + 题域/路由结构核对）；
   盲测卷题面/金标数据外发须用户**逐次拍板**；评审独立性不背书、采信

   未达题的化学解读）；**后置不改已冻结判定**，采纳结论走下一轮版本
   预注册（I2）。
