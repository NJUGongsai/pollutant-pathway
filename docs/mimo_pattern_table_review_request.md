## 二、提案总则（先裁这个，再裁行）

现行 `R2_PATTERNS` 是 7 个 (ΔC,ΔO,ΔH) 精确元组（单加氧/双加氧/水合/双羟化/
还原/脱氢/脱水），留痕不作门槛。复核发现桶内模式大量带「**离去元素**」
（ΔN<0、ΔCl<0、ΔBr<0）——按你上轮 R1' 的裁决「Δe<0 不拦（脱卤/脱氨/脱磷酸/
脱硫酸都是合法方向）」它们本就放行，但**模式表没有行可打标**，于是全部落进
人审桶。提案：

1. **行 schema 扩展**：每行 = (ΔC,ΔO,ΔH) + 离去元素条件（仅 Δ<0 方向）+
   可选 ΔDoU 条件 + 标签名；多行共享同一元组时按附加条件区分（如
   (0,+1,−1) 在 ΔN=−1 与 ΔCl=−1 且 ΔDoU=+1 时是两个不同反应类）。
2. 全部新行**仍是留痕标签，不是门槛**：归不上继续进人审桶不拦，不改变
   任何拦截语义。
3. 离去元素条件不豁免 R1'：卤素/氮若**新增**（Δ>0）仍由 R1' 白名单补集拦，
   行条件只声明「减少方向合法且可指认反应类」。

➡️ 请挑战：schema 这样扩是否会把「同 Δ 元组不同机理」错标（标签错 vs 拦错，
后果不同）；离去元素白名单该不该限 {N,Cl,Br,F,I} 还是放开到任何 Δ<0 元素。

## 六、漏网与误杀风险（请补你自己的）

复核已知的：

1. **计数级无法区分同 Δ 异机理**：P02 四种机理一行盖住——标签错不拦错
   （留痕行），但归因统计会混；
2. **C2H2O 放行后的碳丢失盲区**：真·碳丢失 2C 的错金标若恰好凑出 C2H2O
   会获错误放行（需要结构级「底物确有 1,3-二羰基 motif」判据才能堵，
   计数级堵不住——请评是否值得加 SMARTS 前置条件，还是接受为已知残差）；
3. **糖苷类缺口无固定行**：糖苷水解只列配基时缺口 = [糖−H₂O]，尺寸可变
   （C6H10O5 / C12H20O9 / …），复核判为「共产物未列全」走数据问题旗标而非
   加行——请确认这个分界（C1/C2 小碎片可放行不列、C3+ 有机共产物必须列全）
   是否就是你上轮「缺口分子式表」的本意；
4. **多事件压缩**仍归不上行（如 C-N 断键+脱饱和并存）——维持人审桶，符合
   ΔC≤−3 桶设计；
5. **卷内重复/立体对**（复核中发现桶内有同底物同产物逐字节重复对与仅
   E/Z 差异对）不是模式表能覆盖的——已转卷内查重线，与你无关，仅告知。
