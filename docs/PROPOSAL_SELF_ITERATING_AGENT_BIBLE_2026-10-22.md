# 构想方案（讨论稿）：沉淀迭代方法论 + 自主迭代 Agent

- 日期：2026-10-22
- 性质：初步方案，供黄老师过目讨论；非任务书
- 构想来源：黄老师提议——基于最好成绩版本创建 agent，把后续迭代的方向与方法沉淀为 bible/agent skills，让 agent 在其上自行迭代

---

## 一、一句话定位

把弓赛线这几个月验证过的**评测工程方法论**沉淀为一组 agent skills（bible），再让一个 agent 在这套纪律约束下驱动 ppv1 系统的后续迭代——**人保留拍板权，agent 获得执行权**。

| B | **ppv1 当前架构（chain14 A / c9c6c7a，30.5%）** | 活跃主线、多步方向、迭代空间大（40% 目标在射程内）、工程纪律最新——**建议** |

建议选 B。若文章叙事需要单步线成绩，单步 45.6% 作为引用数字保留，不作为 agent 迭代的基座。

## 二、Skills 沉淀清单（bible 的内容骨架）

从弓赛线的实际迭代史提炼，每个 skill 对应一套被验证过的纪律：

| Skill | 内容 | 来源实证 |
|---|---|---|
| `prereg-first` | 预注册先于付费：判定线写死、发车登记、身份冻结 | 全部批次 |
| `zero-llm-scoring` | 判分零 LLM + 金标隔离 + 封存只读 + 泄漏扫描 | S5b/BIOSYSMOdb150 全线 |
| `probe-before-build` | 零 LLM 探针先行（门 1 机制）：召回验证、误拒率实测后才立项 | 深位召回两轮证伪、P0-1 |
| `batch-discipline` | 凑批跑、单变量成臂、≥3 seed、post-hoc 标签 | T-H、chain13 |
| `loss-attribution` | 失分桶五关模型、逐题配对 diff、换手分析 | T-H r2 归因 |
| `stop-loss-gate` | 止损门：未达线强制回查、不宣称无效修复 | S1 止损、T-H 判定 |
| `dual-caliber` | 口径变更：新版本流程、双口径并列、历史不覆写 | 判据 v1→v2→v3 |
| `review-loop` | 多 AI 评审环：正链复审 + 化学评审 + 互证注记 | Codex/mimo 流程 |
| `anchored-numbers` | 一切数字带锚（commit + 口径 + 批次 SHA） | 10-22 成绩核查 |

这九条就是 bible 的骨架。每条写成：规则 + 反例（历史上踩过的坑）+ 检查清单 + 模板。

## 三、Agent 迭代回路设计

```
观察（读封存产物+归因）→ 假设（立项候选）→ 探针（零 LLM 验证门）
  → 修复实施（代码+测试）→ 离线重放验证 → 凑批
  → 【授权门：人工批准付费跑批】→ 跑批 → 归因 → 回环
```

**自主层（agent 全权）**：只读分析、探针、文档、代码修复、测试、离线重放、归因报告。
**授权门（必须人工/CC 拍板）**：付费跑批、判据版本变更、金标相关、新模型/新渠道引入、对外数字发布。
**禁区**：修改金标、覆盖封存批、绕过判分纪律、自行扩大 API 权限。

这个分层与弓赛线现行人工流程同构——agent 化只是把"人已验证的纪律"写成机器可执行的约束。

## 四、验证出口（没有它整个构想不成立）

- **mibPOPdb 闭卷题集是前置条件**：agent 的每次"提升"必须在闭卷题集复验才算数；298 已见题只作开发参照。
- 双轨读数纪律：开发集（298）与验证集（mibPOPdb）数字分列；只有验证集的提升被承认为能力进步。

## 五、风险与防线

| 风险 | 防线 |
|---|---|
| agent 对着已见题卷过拟合（自我刷分） | 闭卷验证出口 + 授权门 |
| 方法论 skills 写成空洞口号 | 每条必须带真实反例与检查清单（从实际 postmortem 提炼） |
| 迭代方向漂移 | 每轮迭代的目标线来自任务书，agent 不自立目标 |
| 多 agent 评审链断裂 | 评审环节（Codex/mimo 角色）在 skills 里显式定义为必经步骤 |

## 六、实施步骤（建议）

1. **第一步**：从既有文档提炼九条 skill 初稿（patch 自 postmortem/归因报告/裁定文档——素材全在仓里）；
2. **第二步**：定义 agent 的工具面（只读仓、探针执行器、跑批触发器带授权门）；
3. **第三步**：用 T-I（模型配对）作为首个 agent 驱动迭代的试点——它有现成预注册、判定线已写死，是最安全的试验场；
4. **第四步**：复盘试点，修订 bible，再扩大自主范围。
