## 【Q1】判据改法是否站得住

**结论：有条件成立。风险等级：中。**

支持面很硬：

- 审计模块见 `partial` 声明判 `CHECK_UNKNOWN`（"我不知道完整清单"），判分模块却要求与这份不完整清单"恰好相等"——同系统内互相矛盾（`audit.py:636-666` vs `evaluation.py:2438-2505`），判据缺陷报告已定性；
- extras 的 75%（40/53）来自系统自己喂的池条目，等于教模型多写、再因多写罚它；
- 104 道骨架不同的真错理论上不受影响，"0 变差、0 位次退化"有重放支撑。

两个未闭合条件（阻塞级）：

1. **"分子身份严格相等"没定义是否含立体/电荷。** 129 道真错里有 25 道是骨架同、仅立体/电荷不同——如果 v3 的身份函数比 v2 松，这 25 道会混进 37 道转正里，那就是超范围的化学放宽，不是判据修正。必须书面声明 v3 与 v2 用同一身份函数，并给 37 道转正的逐题清单。
2. **37 道转正题未过化学评审。** 按仓库规则（mimo 触发点 1：判据变更），这应升级为 v3 冻结前的**阻塞条件**，不能只作脚注。

## 【Q2】退化激励

**结论：本批退化风险低，自迭代循环里中等。**

本批是 post-hoc 已见题，模型读不到判据、不会为它改行为；真正的风险在长期——判据就是循环的奖励信号，"少写不扣分"会把迭代推向"只写主产物"。

建议采纳被裁文件里已给出的选项：**完整性作独立披露指标**（逐题参与物覆盖率 + extras 来源分层），不作判对条件；同时 v2 双列保留，v2/v3 差值本身就是退化的量化监控。

## 【Q3】reaction_type 人话字段

**结论：值得做，但先小样本对照 + 命名质量门。风险等级：中。**

"看名字选"不是 bug 是 feature——这个改动的目的就是把人类语义给模型。真风险是**名字起错 = 注入错误知识**（531 条 LLM 批量命名）。缓解三件：

1. 低置信条目降级/留空，不硬写；
2. 命名结果送 mimo 化学抽审（抽 50 条量级）；
3. **先跑 50–100 题对照**（同池同模型，唯一差异 = 有无 reaction_type），看 hit@1 变化再决定全量——这个对照同时就是 Q7 那 47 题杠杆的先行实验。

工程上须显式声明新字段**不进** hypothesis_id/身份哈希（保持跨批身份可比），写进预注册。

## 【Q4】混合模式 pool agent

**结论：混合模式可行，但两分支风险完全不同，须分开对待。干跑门对"正确性"够，对"收益"不够。**

- 挑（from_database）分支：候选本来就带编辑协议，无可执行性问题，低风险。
- 写（synthesized）分支：8.6% 是实测天花板。"干跑不过即丢弃"能保证进池的都做得出正确产物（fail-closed，够），但后果是**存活极少**——60 道空池题就算 agent 全写，按 8.6% 期望存活约 5 题。这不是致命阻碍，但预期收益应先按个位数题写进预注册，别当主杠杆宣传。

更强的做法：让 agent 直接输出**原子级编辑协议**（而非反应式）再过干跑门，并把被丢弃条目落盘披露，攒数据供下轮判断是否值得投入解决可执行率。

## 【Q5】顺序

**结论：分三步。** 最小可归因方案：

| 步 | 内容 | 成本 | 验证口径 |
|---|---|---|---|
| 1 | v3 判据落码 + 身份口径写死 + 37 题化学评审 + 重放冻结 v2/v3 双列基线 | 零（离线） | 298/298 逐题复现 v2 基线（86/112/119）；v3=156/109/148；化学评审 PASS |
| 2 | 池 + reaction_type（不上 agent），全量一批 | ~50min + 4M | 对第 1 步基线，唯一变量 = 人话字段 |
| 3 | + 池 agent（rerank 为主，synthesized 带干跑门），全量一批 | ~50min + 4.5–5M | 对第 2 步，唯一变量 = agent |

每批披露批 tag 与时间窗（本仓有时间窗漂移影响配对归因的先例）。若 CC 坚持合并，底线是 **B 与 C 不同批**。

## 【Q6】更简单的替代方案

**结论：有。** 信息/成本比最高的组合 = A（确定性收益 156/109，零成本）+ 完整性独立披露 + C 定位 rerank；B 缓做或只以小样本验证。A 是本轮唯一确定且零风险的收益，C-synthesized 是收益最小、风险最高的部分——资源紧时从后往前砍。

## 【Q7】排序 vs 生成

**结论：反差成立，重心应转向排序——但"rerank 吃 47 题"要打对折看。**

47 题确实是最大的可量化杠杆（对比：空池 60 题 × 8.6% 可执行率，合成期望仅约 5 题），方向判断同意。但要指出被裁文件没写透的问题：**这 47 题是主模型（DeepSeek）自己排错的；rerank agent 还是 DeepSeek、看同样的信息，凭什么排对？** rerank 收益不会自动兑现，除非 agent 拿到不同的信息——而那正是改动 B 的 reaction_type。

更准确的定位：**B 提供信息、C-rerank 消费信息，B+C 联动才打那 47 题；单独上 C 大概率原地打转。** 两种定位的收益人群不重叠（rerank 打 47 题"池里有对的"，synthesized 打 60 题"池里没东西"），预期应分别记账。
