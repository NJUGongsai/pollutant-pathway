## 三、前置规范化(v43-norm-1)

解析 → **去盐(剥离带电单原子 spectator 反离子)** → 电荷归一
(Uncharger) → 含 H 分子式计数(逐元素计数差,不用集合差;解析失败
转"不可审计"不按零)→ 互变规范化(TautomerEnumerator.Canonicalize,
仅 SMARTS 匹配侧;分子式计数对互变天然不敏感)→ DoU 由分子式。
去盐**先于**电荷归一:带反离子的盐整体净电荷为零,Uncharger 不会
中和组分;先剥离再归一,酸/盐两形态才同计数。

## 四、实现侧修订四处(请逐处裁定)

- **R1 C1/C2 脱除族放行不降位**(上一轮原文:碎片未列 ⇒ 不可审计
  降位):主产物 ΔC∈{−1,−2} 且碎片未列时,实现为 fragment_inferred
  归因**放行**。理由:程序证据显示合法 C1/C2 脱除与"降位信号"同
  分布时,把脱除族压到 ΔC=0 候选之后是反向先验(上段 11/22 分布);
  且 ΔC=−1/−2 族与违规族在全局计数上不可分。**问**:该放行是否会
  放过真违规?若会,哪些 ΔC∈{−1,−2} 形态应保留降位?
- **R2 芳环不作为碳损失裂解的放行键型**(上一轮原文:双加氧开环
  要求芳环):双加氧开环产物保留全部碳(ΔC=0),"芳环"作为 C 损失
  裂解键型会把整体矿化式答案误放行。实现取严格子集(β-羟基羰基/
  1,3-二羰基/α-羟基酸)。**问**:是否存在真实单步、主产物 ΔC ≤ −3、
  且只能由"邻接不饱和位 C–C 断键"解释的形态,被该严格子集误降位?
  (代价已实测:两个该形态金标被降位,见 §六)
- **R3 供体登记表新增 coa/辅酶A 泛关键词 + C4 上限**:酰基-CoA 家族
  按上限 C4 放行(不放大),避免逐个酰基链长枚举。**问**:C4 上限对
  苯甲酰-CoA(+C7 苯甲酰至无芳环受体)一类是否够?是否应改为
  "按关键词分别定值"?
- **R4 编目补全(环氧化物/醚/胺-亚胺)**:初版编目缺此三类(环境
  降解经典:环氧化物水解酶、醚断裂、脱氨/转氨),经失败案例分析
  补全——**属已见开发集数据的工程补全**。**问**:25 条编目对环境
  降解题域还有哪些**常见**缺口(如谷胱甘肽缀合的供体登记、磷酸
  泛解、硫代硫酸盐多加酶)?缺口按 G3-b 语义只降位不剔除,但
  编目覆盖偏差会系统性偏向已知化学。
