## A 计数口径 — **需改**

**增侧规则在当前门禁次序下是惰性代码;G1-b 允许集与供体表、减少侧白名单各有一处内部矛盾;②的硬剔边界受关键词措辞与 CO₂ 组分口径双重支配;R1 方向可接受但触发条件过宽。**

1. **增侧不可达(结构性,冻结前必须写死)。** 既有元素白名单"一步只允许 O 增加 ≤2,其余任何元素增加一律拒"先于 G2 运行,则任何 +C/+N/+P 候选在到达 G2 前已被杀。于是 **G1-a①、G2-a 增侧拒、供体登记表的"放行"三者在同一方向上都不可能触发**——请求里"剔除侧零触发(既有门禁在答案路径上已比 G2-a 更紧)"正是这件事的对称面:不只是"拒不掉",而是"放也不放"。"原子凭空出现可证明"这个论证在流水线上取不到证据。冻结文本必须二选一:
   - (a) 声明这三处为惰性 no-op(那 §四 B/R3 本不该占评审篇幅);
   - (b) 承认 G2 会改写上游门禁的放行条件——那它就不是"纯后处理、单变量、与现状逐字节一致",需要按新干预重新过判定线。
   请求把"剔除侧零触发"只当工程读数披露,没有意识到它同时宣判了增侧权限侧。这是本轮**最大的实现-文本背离**。
2. **G1-b 允许集缺正向 ΔC。** 允许集 `{0,−1,−2, 键型裂解}` 不含 `+n`,而供体表明确授予 SAM +C1(甲基化)、CO2 +C1(羧化)、UDP-glucose +C6(糖基化)。一旦增侧真的放行,**每个合法的甲基化/羧化/糖基化答案都会被 G1-b 降位**。目前靠第 1 点的惰性掩盖,是颗雷;须写成"允许集 ∪ 供体授予增量"。
3. **②的闭合性(误杀面有三条)。**
   - **子串陷阱**:`complete` 会命中 `incomplete` / `not completely`。朴素子串扫描会把"降解不完全"判成完整性声明 ⇒ 硬剔。需词边界匹配 + 否定前缀排除。
   - **措辞缺口**:`mineralized / mineralization / fully degraded / completely converted / quantitatively / 彻底降解 / 矿化 / 完全转化` 全不在封闭表内——而这些恰恰是"整体矿化式答案"的惯用措辞。**R2 想防的矿化放行,实际防线完全压在这个关键词表上**;表漏了,R2 把裂解子集收得再紧也守不住。这是 R2 的论证漏洞:收紧的是 C 损失侧,漏洞在声明侧。
   - **与判分口径的接口未对齐**:②的误杀取决于金标组分集是否要求 CO₂/H₂O。若金标省略 CO₂(常见做法),模型写"sole product X(完全降解)"且恰好命中金标 ⇒ ②把**正确答案硬剔**,再经"剔空→hold"变成空答,直接打在判定线的"空答不升"上。此接口我无法定(不看金标),但必须在冻结前显式对齐。
   - 建议最小改法:②只有在"**声明完整 + 总 C 减少 + 缺碳无可重构碎片**"三者同时成立时才硬剔;否则降降位。这样②保留了"声明 vs 构造"的证伪力,又不与 CO₂ 口径抢判。
4. **③与 G1-b 的"键型裂解"必须是同一定义,且当前严格子集与减少侧白名单互相打架。** 见 D/R2。白名单明文放行"脱糖基、脱酰基、醚断裂、酯/酰胺水解"族,而这些族的碳损失(G6、G4+ …)在 G1-b 的三 motif 子集里一个都不在 ⇒ **同一份规则,杂原子侧白名单放行、碳侧降位**。这不是风格问题,是闭合性问题。
5. **主产物平票未定义。** "候选组分中碳数最大者"在对称裂解(C3+C3 retro-aldol、二聚体对称水解)时无唯一解;若只检一个,另一个可藏违规。须写成"对全部并列最大 C 组分逐一施加 G1-b"。
6. **R1 裁定(见下)。**

**R1 裁定:方向成立、条件需改。** 放行 ΔC∈{−1,−2} 不会"放过一切真违规",但当前条件(仅凭 ΔC 落在族内 + 碎片未列)会放过以下形态,**这些应保留降位**:
- **碎片不可重构**:ΔC=−1 但母体无可断的羧基/甲酰基/端基 C(即"少一个碳"没有任何键能解释);
- **跨元素不一致**:ΔC=−1 同时 N/S/卤同步减少(如 HCN 脱除 C+N、CS₂、CH₃SH)——这不是"脱羧族",却会被 G1-a 放行、G2-b 的"脱氨/脱硫"白名单一并放行;
- **ΔDoU 异常**:ΔC=−1/−2 且 ΔDoU 显示环收缩/不饱和度跳变,提示骨架数错而非脱除;
- **与完整性声明叠加**:ΔC=−1 且声明完整——须明确 ②优先(现在"其余碳减少"的字面顺序是对的,但要写成显式优先级,别靠读者推)。
最小改法(确定性、零成本):**放行前要求"碎片公式假设可重构"** —— 用 `底物式 − 产物式` 反查一个中性碎片(CO₂/HCOOH/CH₂O/CH₃COOH/CH₃OH/HCN…),要求 (i) 与全部元素差一致,(ii) 母体存在能给出该碎片的可断键或官能团。满足才 `fragment_inferred` 放行,否则降位。
对"理由"部分的评价:**程序证据不足以支撑放行。** "合法 C1/C2 脱除与降位信号同分布"是**聚合分布重叠**,不是逐项安全性;"ΔC=−1/−2 族与违规族在全局计数上不可分"恰恰是**保留判别特征(碎片重构)的理由,而不是放弃判别的理由**。把分布不可分读成"应当放行",方向反了。

## B 供体登记表 — **需改**(R3 裁定:**当前门禁次序下无操作意义;若增侧将来放活,须改"按关键词分别定值"**)

**封闭表的方向正确,但命中语义、值域、覆盖三处都有洞;"候选 note 不是登记源"成立。**

1. **R3 裁定(两段式)。** 第一段:**在当前门禁次序下,整张表是惰性的**(见 A-1),所以 +C4 上限对苯甲酰-CoA"够不够"这个问题**今天没有操作后果**——它既不会误杀,也不会放行。第二段:**若增侧将来放活**,则:
   - **+C4 对"酰基转移"本身已是过度放行**:CoA 硫酯作为供体时转移的只有**酰基**,乙酰基 = C2、丙二酰 = C3、丁酰 = C4。给 +C4 意味着允许模型在乙酰化上多算 2 个碳不被拒——放行侧宽松可接受(只降灵敏度),但要**登记为已知宽松**,不要写成"上限不放大"的中性表述。
   - **苯甲酰-CoA(+C7)确实超出 C4**,但**在本题域苯甲酰-CoA 是"底物"不是"供体"**(厌氧降解中苯甲酰-CoA 是被转化对象),把它当供体的单步反应基本不存在 ⇒ **不值得为它加关键词**。答案是"按关键词分别定值"(乙酰 +C2 / 丙二酰 +C3 / 琥珀酰·丁酰 +C4 / 苯甲酰若要则 +C7),并**删除裸词 `coa/辅酶A`**:它是过宽触发器(见第 3 点)且语义含混——题面出现 "requires CoA" 并不构成任何碳转移。
2. **"不叠加"需改为"按元素取 max"。** 字面"命中即放行对应元素增量,不叠加"下,SAM(+C1) 与 UDP-glucose(+C6) 同时命中时碳预算只给一份 ⇒ 双供体单步(甲基化+糖基化,或羧化+甲基化)被硬拒。应写成:**每个元素的授予 = 所有命中关键词在该元素上的最大值**(跨元素天然并存,同元素不求和)。这是可判定且无歧义的写法。
3. **子串触发器必须加词边界。** `coa` 命中 `coal/coast/coax`;`SAM` 命中 `sample/same/samsung`;`APS` 命中 …;`CO2` 大小写与 `CO₂` Unicode 需归一。全部是**过宽放行**(降灵敏度),不是误杀,但会把"拒因入账"的可审计性搞脏。
4. **ThDP 行的 `+C` 不是可判定值。** "ThDP / thiamine / … / acyloin / benzoin → +C"没有数量,程序无法计数。ThDP 依赖的安息香缩合是**二聚两个醛**,供体碳数取决于第二个醛的链长——建议要么删掉这行(它在本题域几乎不出现),要么改成封闭枚举 + 未知则不授予(不授予 ⇒ 走增侧拒 ⇒ 走 A-1 的惰性,现状无害)。
5. **对环境降解题域的缺口清单**(R4 的问题,与 D 的编目缺口分开列):
   - **碳共底物**:glucose / glycerol / succinate / pyruvate / acetate / methanol / 酵母提取物 —— 共代谢转化的常规条件文本,一个都不在表内。这些**直接打在①的硬剔上**(见 A-1:今天惰性,一旦放活就是最高频误杀源)。
   - **缀合供体**:谷胱甘肽(R4 已自认)、甘氨酸(马尿酸类)、半胱氨酸/巯基尿酸、牛磺酸、葡萄糖醛酸(表里只有 UDP-glucuronate ✓,但要确认关键词 `glucuronate` 覆盖中文"葡萄糖醛酸")、**糖基化的泛醌/核苷**。
   - **一碳单位**:formate / formaldehyde / methylene-THF(羟甲基化、甲酰化)—— SAM 只管甲基。
   - **含硫无机**:thiosulfate/sulfite 作为 S 供体(硫代硫酸盐硫加酶,R4 已提);硫氰酸生成。
   - **氨酰化其他供体**:aspartate / asparagine(转氨、酰胺转移的常规供体)。
   - **金属辅因子**:Mg²⁺/Mn²⁺/Zn²⁺/Fe-S 簇若出现在题面且产物显式配位 —— 归 C 档的金属档(见 C-1),不由本表授予。
6. **"候选 note 不是登记源"——成立。** 模型自称用某共底物是可博弈的自我陈述,不构成题面条件。两个限定必须写清:(i) 扫描范围是**全部条件文本**(含小标题"co-substrates / incubation with / 缓冲液"这类行),不只是主句;(ii) 一旦出现"note 声称供体、题面无",①会把它变成硬剔——建议留一条**降位通道**(碎片公式与某真实供体精确吻合且该供体在题面语义上隐含时,降位+标注而非硬剔),否则一个题面省略共底物的正确答案被不可逆地杀掉。

## C 处置语义 — **需改**(档位闭合性:有四处未定义/自相矛盾;四档设计本身方向是对的)

**四个触发→动作映射有漏;"hold 不作违规软化通道"的限定本身没问题,问题在它与"剔空"的耦合和缺档。**

1. **缺档:"共价金属新增计违规"没有归属档。** 白名单段落明文"共价金属新增计违规"却没写剔除还是降位。按语境应归 G2-a 硬剔,但必须写死;否则实现侧自行选择,拒因入账不可审计。
2. **"配位经去盐剥离不触发"与 §三的去盐定义冲突。** §三去盐只剥**带电单原子** spectator;多原子反离子(formate / acetate / sulfate / oxalate / Tris / TEA / HCO₃⁻)与配位型抗衡离子**不会**被剥掉,会作为组分参与硬门元素计数 ⇒ 该金属/杂原子**照样触发增侧**。句子收窄成"带电单原子 spectator 反离子"才与实现一致,并显式列一个多原子反离子的处置(建议:去盐扩展到"带电且无可断共价键连接的单组分抗衡离子")。
3. **parse-fail 分支不可达/自相矛盾。** G3-a 写"守恒侧 parse-fail 按不可审计降位,最终仍由既有门硬拒"——若 G2 的解析器与既有门同一套,parse-fail 的候选根本到不了 G2;若不同(更严,如 InChI/不同 sanitize flag),则它只能**降位**而非"最终硬拒"。两种读法给出不同档位。须写明:是同一解析器(该分支删除),还是更严解析器(则它是独立的降位来源,并说明为何不与既有门合并)。
4. **hold 的两个子类要分账。** "底物不可判定"与"剔空(5/5 被剔)"合并成一个 hold 是**语义上正确**(都不谎报最优违规者),但**诊断上不可混**:剔空是模型侧信号,底物不可判定是输入侧信号。建议 hold 内部记 `hold_reason ∈ {substrate_undecidable, all_rejected}` 并带 `reject_count`,否则②的任何过触发(见 A-3)都会静默地表现成"空答",打在判定线的"空答不升"上而不留痕。
5. **"hold 不作违规软化通道"的限定:成立,且应保留。** 它防的是"全错 → 假装弃权"。唯一漏洞:它只在**剔除**全空时触发,**降位**全空时会照常按原位次报出(等于 G2 no-op)——这是无害的(不改变名次),但要在文本里写明这一差异,别让人以为"全违规"总是弃权。
6. **金属配位不可区分的形态该不该 hold——不该,应降位。** 若产物金属来自母体迁移/去盐失败,计数上是**减少或持平**,不触发硬门;若产物**新增**共价金属,是真违规,硬剔正确;真正的模糊区是"金属配位态无法判断 spectator 还是共价"——这一形态既不该硬剔(可能误杀)也不该 hold(污染弃权语义),应归**不可审计降位 + 标注**,由 G3-a/既有价态门兜底。建议把这一句补进③处置表。
7. **档位优先级未写**(同时触发剔除与降位时谁优先)。按常理剔除优先,但必须显式,否则实现顺序会改变结果。

**做得对的部分(一句话)**:剔空→诚实弃权优于"被迫回报最优违规者";`解析失败转不可审计不按零` 避免了幻影零计数;守恒连续值不入键有程序背书;G3-c 只提示不硬杀;同分异构恒放行——这五处我不改。

## D G3 三层 — **需改**(R2 裁定:**不成立——按实现口径必须改**;R4 裁定:**缺口确实存在,优先级高于编目本身**)

**G3-a 无异议;G3-b 的"降位"语义与 R2 的严格子集是本轮误杀风险的主源;变换类签名表缺 +O 非羟化类。**

1. **R2 裁定:严格子集会误降位真实单步形态,而且是本题域最经典的那些。** 请求问"是否存在真实单步、主产物 ΔC≤−3、只能由邻接不饱和位 C–C 断键解释的形态被误降位"——**存在,且不止"邻接不饱和位"一类**,具体(全部是环境降解教科书反应):
   - **有机磷水解**:chlorpyrifos(C12)→ 3,5,6-三氯吡啶-2-醇(C5)+ 二乙基硫代磷酸(C4),主产物 ΔC=−7,断的是 P–O(芳基)/C–O–P;三 motif 一个不中 ⇒ **降位**。parathion(C10)→ 对硝基苯酚(C6),ΔC=−4 ⇒ **降位**。
   - **拟除虫菊酯水解**:permethrin(C21)→ 3-PBA(C14)+ 二氯乙烯基二甲基环丙烷甲酸,ΔC=−7,断酯键 ⇒ **降位**。
   - **糖苷水解**:苷元 vs 糖基 ΔC=−6(糖基未列时),断**糖苷缩醛 C–O** ⇒ **降位**——而"脱糖基"明文在减少侧白名单里。
   - **大离去基团酯/内酯/肽水解**:三酰甘油→脂肪酸+甘油(ΔC 可 −30 以下)、二肽→游离氨基酸(ΔC=−5)、丙酯以上酯水解(ΔC≤−3)⇒ **降位**;甲酯/乙酯(−1/−2)靠 R1 侥幸通过——**同一类反应,按离去基团碳数分成了两套处置**。
   - **醚断裂(二芳基醚/二噁英型、二烷基醚大基团侧)**:R4 明文把"醚断裂"补进 G3-b 编目,但 G1-b 不认它为放行键型 ⇒ **G3-b 允许、G1-b 降位,两层直接打架**。
   - **1,2-二羰基(α-二酮)C–C 断裂**:子集只认 1,3-二羰基,不含 1,2 ⇒ 漏。
   - **烯/炔邻位氧化断裂后只列一个羰基产物**、以及**双加氧开环的同族变体**:R2 想排除的正是这类,但"邻接不饱和位 C–C 断键"的判据应由**碎片可重构性**给出,而不是由 motif 白名单给出。
   
   **R2 的动机与手段不匹配**:防"整体矿化式答案通过"的正确防线是 ②(完整性声明)+ **碎片公式重构**(A-6),而不是收窄裂解 motif。已实测"两个该形态金标被降位"是**下界**,因为上述类别尚未全部进入封存读数。
2. **G1-b 裂解键型的最小修正(确定性)**:保留三 motif 作为快路径,再加一条**通用回退**:`底物式 − 主产物式` 是否等于母体**某一条真实可断键**单切 + H/OH 补全后的碎片式(有界键切搜索,RDKit 可算)。这条回退同时解决 A-4 的白名单矛盾、R2 的误降位、R1 的碎片重构——**三处该用同一个判据,而不是三套各自为政的白名单**。
3. **变换类签名表缺口(误杀面)**。签名 = Δ计数 + ΔDoU + 子结构差,而类目里**没有"环氧化"、"S-氧化"、"N-氧化"**:
   - 烯 → 环氧化物:+O、ΔH=0、ΔDoU=0,与"羟化"在公式层同签名,子结构差可区分,但**类目里没有这个类名** ⇒ 落 `unclassified`;
   - 硫醚 → 亚砜(+O,ΔDoU=0)、叔胺 → N-氧化物(+O,ΔDoU=0)同理 ⇒ `unclassified`;
   - 而**杂原子氧化是细胞色素 P450 / 单加氧酶 / 亚砜化酶介导的最常见首步之一**(有机磷、苯并咪唑、亚砜类农药)。
   - `unclassified` 的语义当前是"不在可进攻清单内 ⇒ key 2 靠后" —— **分类器的覆盖失败被当成化学不可能的证据**,这是纯粹的编目偏差惩罚。**必须改成:unclassified = 中性(落 key 3),只有"底物有该可进攻基团但变换类与其化学矛盾"才进 key 2。**
   - 另补:`+O 羟化 vs 醇氧化` 有类;`水解细分` 归"裂解"可以;`脱烷基(N-dealkylation)`、`偶联/二聚`、`重排` 归属要写明(二聚今天被上游元素门挡死,属 A-1 惰性,但类目要留位)。
4. **编目 25 vs 27 的对账问题。** 请求括号里枚举的是 **27 项**(羧酸/酯/酰胺/磷酸酯/硫酸酯/磺酸/砜/硫醚/亚砜/缩醛/环氧化物/醚/碳卤/硝基/N-氧化物/腈/胺-亚胺-芳族N/醇酚/芳环/烯/醛酮/β-羟基羰基/1,3-二羰基/α-羟基酸/杂原子甲基/氰醇/sp3 C-H),正文却写"25 条"。预注册文本里数字与清单不一致会让复现无从对账——要么改数,要么合并项并写明合并规则。
5. **R4:25(27)条对本题域的常见缺口**(缺口只降位不剔除,但覆盖偏差系统性偏向已知化学,这条判断我完全同意):
   - **氨基甲酸酯**(R–NH–COO–,甲萘威/涕灭威类农药)——**酰胺 SMARTS 不覆盖它**:酰胺要求羰基碳带一个碳,氨基甲酸酯的羰基碳带 O 和 N ⇒ `[C](=O)[N]` 不中。这是**最典型的漏**,因为它是环境降解第一大类之一。
   - **脲/取代脲**(敌草隆类除草剂)、**磺酰胺**(磺胺类药物)——磺酸/砜在册,磺酰胺不在。
   - **膦酸酯 / C–P 键**(草甘膦、膦酸盐除草剂):"磷酸酯"若 SMARTS 只要求 P(=O)O 则可能覆盖,但 C–P 断裂(C–P 裂合酶)是独立首步,须显式。
   - **杂芳环**:吡啶/嘧啶/三嗪/呋喃/噻吩/吡咯。"芳环"若 SMARTS 是 `a`(RDKit 感知),五元杂环覆盖;若是苯环专用,则漏一大片。**必须声明芳香性模型**,并单独列出**五元杂芳环的环氧化/开环**。
   - **硫醚 SMARTS 是否覆盖芳香杂环硫**(噻吩 S 是芳香硫,`[#6]-[#16]-[#6]` 不中)。
   - **季铵/甜菜碱 N**(百草枯/敌草快、甘氨酸甜菜碱)——胺类 SMARTS 通常不中,且 Uncharger 中和不了(见 F)。
   - **内酯**(若酯 SMARTS 无环限制则已覆盖,须写明)、**糖苷端基碳**(缩醛是否覆盖端基 C–O–C,须写明)、**过氧化物/氢过氧化物**(脂质过氧化,白名单有"还原脱 O"但编目无)、**环丙烷**(拟除虫菊酯骨架,开环会落 unclassified)、**肟/氰醇类已有**、**烯醇**(若"醇酚"只认 sp3 OH/芳 OH 则不中)。
   - R4 提的**谷胱甘肽缀合**:既有供体登记缺口(见 B-5),也有编目缺口(谷胱甘肽 S-转移酶的底物侧是亲电位点,不是官能团清单里的项)。
6. **G3-b 降位分量的误杀面(定量定性)**:它是**题内相关**的——同一道题的 5 个候选共享同一份底物编目。若底物编目漏(如氨基甲酸酯),则**该题全部候选的可进攻清单偏空或偏错**,造成两种后果:(i) 清单空 ⇒ 全部候选同档 ⇒ key 3 救回,无害;(ii) **清单部分命中 ⇒ 一部分候选上浮、正确候选下沉** ⇒ 这才是误杀。也就是误杀集中在"底物含漏项 + 正确变换类是漏项"的组合上,恰好是**偏离已知化学的题**——正是 §五 G 担心的偏差方向。故编目缺口不是小问题,它决定 key 2 的符号。

## E 自排序键 — **需改**(键序本身**成立**;需改的是 key 2 的语义与判定线的独立性)

**`处置档 > G3-b 匹配 > 原位次` 与"守恒不作正向先验"自洽;但 key 2 把编目覆盖当成化学证据,+3 读数与 dev 编目补全同源,判定线在这一点上是循环的。**

1. **键序与硬约束自洽 ✓。** 守恒连续值不入键、守恒档不作全局前置,有程序背书(金标卡罚分 5/6/11 → 升序回撤到 7/10/10,比基线差),这条我**同意并建议维持**——它证明的是"守恒分数不是正向先验",不是"守恒无信息"。稳定序在末位保证了无违规候选的确定性,符合纯后处理定位。
2. **§五 G 的两难裁定:保留 key 2,但把它从"覆盖匹配"改成"化学不可能"。** 理由:
   - 撤掉 key 2 ⇒ 过滤器退化为"纯剔除 + hold",而在当前答案路径上**剔除侧零触发 ⇒ 整个 G2 是 no-op**(见 A-1)。把一个 no-op 当干预上线、花判定预算去证明它有效,这**不比保留 key 2 更诚实**——它只是把偏差藏进"我们什么都没做"。
   - 保留 key 2 但按现语义 ⇒ 编目覆盖直接决定名次,**方向系统性偏向已知化学**(R4 自己已认)。
   - 中间形态(我建议的):key 2 只对**"底物具备该可进攻基团、而候选变换类与其化学矛盾"**的候选生效(例:底物只有饱和 sp3 C–H 而候选是脱卤 ⇒ 明确矛盾);**`unclassified` 一律中性落 key 3**;同分异构仍恒放行。这样 key 2 用的是**底物的化学约束**,不是**编目的覆盖率**——前者是先验,后者是数据泄露。
3. **判定线的循环性(必须处理)。** R4 明文"属已见开发集数据的工程补全"⇒ **编目是用 dev 失败案例调出来的,而判定线 `dev 51 分母 cn@1 净赢 ≥3` 又在同一批 dev 上读**。于是:
   - 初版读 −2~−3(G1-b 降位键 −2、G3-b 匹配键 −3),补全后读 +3,**符号在同一批数据上被编目编辑翻转 ±3** —— 一个符号能被目录编辑翻转的排序键,目前量到的是**目录,不是化学**。
   - `+3 / 0 均为单次采样 + dev 引导补全后的读数` + `@3 六批一致 −1~−2` 这三条披露是诚实的,但结论必须落到**流程**上:判定线的 ≥+3 不能在被编目反哺过的 dev 上宣布为确证。最小改法:(i) 用**第二次采样/新鲜样本**做判定读数并预先声明为 confirmatory,或 (ii) 明确标注 `in-sample, 非确证`,把 ≥+3 降级为工程验证(与离线重放同级),确证留给付费跑的双采样符号检验。
4. **key 2 的一个边角**:底物编目空 + 存在同分异构候选时,"同分异构恒放行"会把一个**可能错的异构体**顶到最前(正确但非目录化的氧化沉底)。建议:同分异构放行**仅在 key 1 同档内**生效,不越过 key 2 的矛盾判据(与第 2 点的"化学矛盾"判据配合即可自然解决)。
5. **"守恒档不作全局前置排序"与"处置档作 key 1"不矛盾**:前者指连续罚分,后者指离散档位,文本已区分,保持。

## F 前置规范化 — **需改(轻)**

**去盐先于电荷归一的顺序与理由正确;残留风险集中在"永久带电物种 + 按分子式算 DoU"与"多原子反离子"两处。**

1. **顺序裁定:成立。** 带反离子的盐整体净电荷为零,Uncharger 不会中和组分;先剥 Na⁺/Cl⁻ 再归一,酸式/盐式才落到同一计数。这个论证是对的,不要改。
2. **zwitterion 残留风险(主要项)。** Uncharger 中和得掉羧酸根与伯/仲/叔铵,**中和不掉季鏻/季铵/锍/SAM 型永久正电**。于是:
   - **按分子式算 DoU 必须带电荷项**:`DoU = (2C + 2 + N − H − X + q)/2`。若 Uncharger 后仍残留 `q≠0`(甜菜碱、季铵农药、SAM、CoA 硫酯阴离子侧、含永久阳离子的内盐),而实现按中性分子式算 ⇒ **DoU 差 0.5、非整数** ⇒ `ΔDoU` 签名错 ⇒ 变换类落 `unclassified` ⇒ 被 key 2 沉底。这是 F 与 D/E 的**直接耦合**:F 的一个小偏差会变成 E 的名次损失。
   - 建议:**DoU 改由分子图算**(环数 + π 键),或强制带 `q` 项;并加一条断言"DoU 必须为整数,否则转不可审计"。
   - 内盐两形态(如氨基酸两性离子 vs 中性式)经 Uncharger 归一后**同计数 ✓**,这条不用担心;担心的是**不可归一的永久电荷**。
3. **去盐覆盖不足(次要但要写)。** 现定义"带电单原子 spectator"漏了:**多原子反离子**(formate / acetate / sulfate / oxalate / 磷酸 / Tris / TEA / HCO₃⁻)与**中性共结晶分子**(结晶水、DMSO、甲醇、咪唑)。后果:(i) 多原子反离子被计入底物侧硬门元素/碳预算 ⇒ 与 C-2 同源;(ii) 若产物串里带中性含碳溶剂组分,会干扰"碳数最大者 = 主产物"的判定(概率低但存在)。建议去盐判据改成"**带电、无共价键连到主体、且不是唯一含碳组分**"。
4. **互变只作用于 SMARTS 侧 ✓,分子式计数对互变天然不敏感 ✓** —— 互变异构只移动 H,元素总数不变,这个说法成立;DoU 由分子式算时互变也不敏感(ΔH=0 ⇒ ΔDoU=0)✓。这两句我确认无误。
5. **含 H 分子式计数用逐元素差而非集合差 ✓**;解析失败转不可审计不按零 ✓(避免幻影零)。

## G 总裁定 — **不可原样冻结;给出必改项最小集(按误杀风险排序)**

判定线本身(先冻结再付费、离线重放只作工程验证、双采样 + 符号检验、止损 +8pp、费用帽)是**健全的**,离线重放的披露(初版 −2~−3 的分解、剔除侧零触发、+3/0 为单次采样、@3 六批 −1~−2)也**诚实**——问题不在验证纪律,在规则文本的化学闭合性与一处实现-文本背离。

**必改项最小集**(每条都可零成本确定性实现):

1. **G1-b 裂解判据重构为"碎片可重构"**(D-2):三 motif 快路径 + 通用"单键切 + H/OH 补全公式匹配"回退;并显式写明 ③与 G1-b 的"键型裂解"是同一定义、减少侧白名单族(糖苷/酯/酰胺/醚)必须在碳侧也被认。**这是最高误杀风险**,直接命中教科书反应类。
2. **②硬剔加第三条件 + 关键词修缮**(A-3):词边界 + 排除 `incomplete` + 补矿化措辞族;②仅在"声明完整 + C 减 + 缺碳无可重构碎片"时硬剔;并与判分口径显式对齐 CO₂/H₂O 是否算必需组分。
3. **key 2 语义改为"化学矛盾",`unclassified` 归中性**(E-2、D-3);同时补变换类:环氧化 / S-氧化 / N-氧化(+O 非羟化类)。
4. **声明增侧惰性(或改门禁次序并重新走判定)**(A-1):供体表、G1-a①、G2-a 增侧拒在当前次序下不可达——必须在冻结文本里写死是"惰性 no-op"还是"放活条件",否则 B/R3 是空谈,且"单变量、逐字节一致"的表述不成立。
5. **R1 放行加碎片重构条件**(A-6),并把 ②优先级写成显式。
6. **编目对账 + 缺口补全**(D-4、D-5):25 vs 27 改一致;补氨基甲酸酯、脲、磺酰胺、膦酸酯/C–P、杂芳环(声明芳香性模型)、季铵、过氧化物;声明酯/缩醛 SMARTS 是否覆盖内酯与糖苷端基。
7. **DoU 带电荷项或改由图算**(F-2)+ 去盐扩展到多原子反离子(F-3)。
8. **档位闭合性补写**(C):共价金属归属档、parse-fail 分支取舍、hold 子类分账(带 `reject_count`)、档位优先级。
9. **判定线独立性**(E-3):dev 引导补全后的 ≥+3 标注 in-sample,或用新鲜/第二次采样作 confirmatory 读数。

**我不改的(明确背书其反面意见)**:守恒连续值不入键、G3-a 不重复实现且不放宽不收紧、G3-c 只提示不硬杀、同分异构恒放行、剔空诚实弃权、解析失败不按零、去盐先于电荷归一、"候选 note 不是登记源"、"卤素新增为有意先验排除(登记非遗漏)"。

## 最值得复核的三处(按误杀风险排序)

1. **G1-b 的严格裂解子集(β-羟基羰基 / 1,3-二羰基 / α-羟基酸)对上经典水解类。** 有机磷(chlorpyrifos ΔC=−7、parathion ΔC=−4)、拟除虫菊酯(ΔC=−7)、糖苷(ΔC=−6)、大离去基团酯/内酯/肽(ΔC≥3)全部落"不可审计降位",而"脱糖基/脱酰基/醚断裂"明明在减少侧白名单、"醚断裂/环氧化物"又刚被 R4 补进 G3-b——**同一份规则三处互斥**。已实测的"两个金标降位"是这个类别的下界。改法:碎片公式可重构性判据(D-2),一次同时修好 A-4、R1、R2。
2. **G1-a②的完整性声明硬剔。** `complete` 命中 `incomplete` 的子串陷阱、矿化/彻底降解措辞全不在封闭表内、以及它与"金标是否要求 CO₂ 组分"的口径未对齐——一旦触发即不可逆,并经"剔空 → hold"变成空答,直接打在判定线"空答不升"上且不留痕(hold 需带 `reject_count` 分账)。
3. **G3-b 变换类签名表把 `unclassified` 当负信号。** 环氧化 / S-氧化 / N-氧化这三个类目缺失,而它们是 P450/单加氧酶/亚砜化酶最常见首步;分类器覆盖失败被当成化学不可能的证据,叠加编目缺口(氨基甲酸酯、杂芳环、季铵)⇒ **系统性偏向已知化学**,正是 §五 G 担心的结构性风险的实际入口。改法:`unclassified` 归中性落 key 3,key 2 只认"底物基团与变换类化学矛盾"。
