# v4.3 hit@1 → 60% 提升方案（框架师版）

- 日期：2026-09-29 ｜ 状态：规划稿，拍板后拆任务书下发
- 适用线：弓赛 v4.3（depending 仓 `v4.3` 分支）
- 节奏：不设时间限制，学生按依赖关系与阶段门自行安排

---

## 0. 一句话定位

把「提分」从试错活动升级为**一个信号完整性受控的优化回路**：测量 → 归因 → 干预 → 验证，回路的每一环都有防腐设计，防止最重要的失败模式——**在已见题上把噪声调成信号**。

## 1. 系统分层：先分清谁是被优化对象

```
┌──────────────────── 控制面（本方案设计的对象）────────────────────┐
│  归因器（失分池分析）→ 变更集（prompt/参数/gold/模型）→ dev 验证   │
│  → 止损门 → 盲测判定 → 发布决策                                   │
└──────────────────────────────┬───────────────────────────────────┘
                               │ 只读观测            │ 受控变更
┌──────────────────────────────▼───────────────────────────────────┐
│  数据面（被优化对象）：v4.3 pipeline                               │
│  底物 → 检索 → 证据分级 → 路由 → 模型裁决 → 门禁 → 答卷           │
└───────────────────────────────────────────────────────────────────┘
```

绝大多数提分失败是控制面事故（在答案上调参、拿旧归因施工），不是数据面事故。本方案三分之二的篇幅在给控制面立规矩。

## 2. 四条核心不变量（任何阶段不得违反）

| # | 不变量 | 违反的典型形态 |
|---|---|---|
| I1 | **信号源隔离**：298 只读观测、dev 集调参、盲测定论，三者永不串用 | 看了 298 结果改 prompt 再测 298 |
| I2 | **判决先于数据**：配对实验的判定规则先于跑分冻结（预注册） | 跑完挑一个让改动好看的指标 |
| I3 | **gold 盲性**：gold 复核人不见模型输出；翻转 gold 须逐题理由 + 双人确认 | 照着模型答案修 gold |
| I4 | **多维监控**：hit@1 为主指标，hit@3/5、空答率、spurious rate 同步盯 | 为 hit@1 牺牲候选宽度 |

## 3. 杠杆池的结构分析：信息在系统内 vs 系统外

失分池按「信息位置」二分，这决定修法性质根本不同：

| 类别 | 池 | 规模 | 修法性质 |
|---|---|---|---|
| **信息已在系统内** | L1 排序池（hit@5 内非首位） | 50 | 决策层优化：协议/噪声/模型，纯工程 |
| | L2 直通答错（记录≠金标） | ~39 | ground truth 治理：口径复核 |
| | L3 引擎有 agent 无 | 23 | 参数截断放开：窗口 8→16 |
| **信息在系统外** | L4 真空区（池内无金标） | 89 | 生成泛化：novel 强化（弱证据区，搭车不背指标） |
| | L5 语料无金标 | ~33 | 资源扩充（降级口径，后备） |

架构判断：**主攻"信息在系统内"的 112 题（L1+L2+L3）**——这些是系统已具备知识、只是没用好的部分，修复确定性高；系统外的两条路（生成泛化/语料扩充）一条证据弱、一条改口径，都不做主力。

三档数字预算（缺口 43 题）：

| 杠杆 | 保守 | 基准 | 乐观 |
|---|---|---|---|
| L1 排序（含模型升级） | +15 | +22 | +30 |
| L2 gold 复核翻转 | +8 | +12 | +15 |
| L3 窗口 | +4 | +6 | +8 |
| **合计 → 全局** | **+27 → 54.7%** | **+40 → 59.1%** | **+53 → 63.4%** |

基准情形差一口气是刻意保留的诚实——这口气主要由模型升级（E4）或 S3 兜底补上，方案不假装稳过。

## 4. 执行回路（阶段之间是门控关系，不是日程关系）

### S0：归因与边界划定（零 API）

- 弓赛出本轮 C0 的 162 题失分归因（沿用五关框架；首轮旧归因是旧地图，禁止套用）；
- 74 题人工化学复核（27 模型选错 + 39 直通答错 + 8 编辑被拦，按新归因刷新清单），复核人盲于模型输出；
- **产出（S1 的唯一合法输入）**：L1/L2/L4 精确边界表——排序可修池与 gold 口径池的分野。

### S1：Phase E 变更集施工（API <¥50）

冻结 dev 集（50–100 题，来源见决策 D2）上逐项配对实验，判定规则预注册：

| 子项 | 内容 | 证据依据 |
|---|---|---|
| E1 选择协议修复 | 按 S0 结论改 rank_candidates：候选呈现、证据卡密度、放弃理由约束 | 排序池主杠杆 |
| E2 噪声消除 | 显式 temperature=0；钉死「协议要确定性 vs 请求容忍抽样」的矛盾 | 复测 8 题纯噪声互证 |
| E3 窗口放开 | rank 窗口 8→16；报告宽度 5 不动（产品决策） | 引擎@5 209 vs agent 186 |
| E4 模型升级 | **等五模型裸测结果定选型**；与 E1 捆绑进同一轮配对实验 | 全局增益变量 |

并行不背指标：fable5 三 P1（FileRateGate 锁、证据卡 schema 版本、拒因字符串解耦）。

**止损门（回路的保险丝）**：dev 集累计增益 <+8pp → 停止冲刺，重估目标或转 S3——不带弱证据去碰 298。

### S2：盲测判定（API ~¥10–20/模型）

- 新题卷 100–150 题：BIOSYSMOdb 121 题拆单步 + RHEA/BRENDA 留出拼合；先引擎基线后 agent，scorer v2 同口径；
- **真 60% 的唯一判定场所**；298 同批复测一份作 post-hoc 参照，分开报告不混分。

### S3：后备降级（仅 S1+S2 不达标时启动）

语料扩充（RHEA/BRENDA 入库 + 泄漏审计程序先行），报告口径显式改为「覆盖+排序」。保数字，降科学声明——两者必须同时发生，不许只要前者。

## 5. 风险架构：三个系统性失败模式

| 失败模式 | 机理 | 防线 |
|---|---|---|
| 隐性过拟合 | 在 298 上反复观测-调整，噪声被调成信号 | I1 + 止损门 + post-hoc 标记纪律 |
| 抽样噪声误判 | reasoning 模型非确定性，小差异不可判定 | 显式 T=0 + 配对设计 + 「单次抽样不证因果」写入报告模板 |
| 指标单一化 | 只盯 hit@1，系统为它牺牲宽度/诚实弃权 | I4 多维监控 + overclaim 轴独立 |
