## W-V1. 提交序贯彻调度序（W3 收尾；工程级；本轮最高优先）

入口：`queue.schedule_hypotheses`（调度入队序与 action created_at
装配）、`runflow._inflight_action_ids`（666–676 行取任务序）、
`runflow.drive`（执行循环）、`store.submit_event`（微秒 created_at，
不改）。

1. **设计边界（先定死，防改尺子嫌疑）**：scorer 的候选序判据
   (created_at,event_id) 一字不动；修复目标 = 让"实际提交时序"忠实
   反映"调度序"（W3 已宣示"提交序=高分辨率 created_at"的排序意图
   在最后一公里失效）。可选实现（实施方选一并写理由）：
   - A（推荐评估）：调度入队按 effective_rank 序装配**单调递增的
     微秒 created_at**（同 run 内严格递增、跨 run 互不依赖），使
     既有 `ORDER BY created_at, action_id` 自然按调度序取任务；
   - B：取任务序显式带 effective_rank 排序键（需 schema/身份升版）。
   两方案都不重排已提交事件、不改 event_id、不造时间戳回填。
2. 执行语义保持：rank1 展开失败不阻塞 rank2（一坏一合法容错不变）；
   同秒 tie、重放、resume 幂等语义不回退；时间正负控必须穿
   store→native_export→原 score（W3 既有测试扩展，不只测 model_rank
   字段，必须断言**事件提交序=调度序**）。
3. 正控：8 池+首位 novel，budget8 下 novel 首提交且原 scorer 得
   rank1；首位 recorded 池候选首提交（对齐 47 题反例形态的合成版）。
   负控：调度序≠提交序的旧形态（哈希 tie-break）在新版必须红。
4. 负担披露：单驱动串行执行下严格按 rank 序提交会让"先失败重试
   下一条"的墙钟略增（无模型调用，毫秒级，不构成费用风险）；
   需如实登记。
5. 风险：与 S4a 契约族（同产物双备选）叠加时去重先于排序的语义
   核对；复审点而非阻塞点。

## W-V2. recorded 编译墙攻坚（工程级；U 主杠杆）

入口：`recorded_source.compile_recorded_reaction / infer_reaction_
mapping`（推断映射两分支）、`s5b_compiler`（stereo/charge unsupported
边界）、build 侧 `compile_failure_histogram` 聚合。

依据（尸检 §1.1 L1）：147 题 strict 记录、80 题编译失败，228 次失败
= no_structure_correspondence 116 + stereo_edit_unsupported 38 +
product_set_mismatch 28 + new_atom_charge_unsupported 14 +
charge_edit_unsupported 12 + 其余 20。

1. **先分类后修**（W-V0 同纪律）：对 116 次
   no_structure_correspondence 做分支级分类探针（裂解分支
   n_union≤n_donor 组合枚举空 vs 加成分支 vs 元素不匹配），产出
   靶点清单（哪些类可修、哪些属语料真实无对应，如实分层）。
2. 映射能力增强（通用机制，不逐题定制）：any-bond 子结构同构对
   "键连通性保持"的要求对断键/成键重排反应过紧——允许**有界键差**
   的结构对应（枚举预算/歧义披露不变；等价映射合并、异目标仍拒）。
   正控：断键重排类合成记录编译通过且产物多重集核对一致；负控：
   无对应/触顶/歧义仍拒（W2 负控族全保留）。
3. product_set_mismatch 28：枚举全部候选映射（非首个）择产物集
   可复现者；过滤缺失仍诚实拒（不冒充完整 record）。
4. stereo/charge unsupported（38+14+12）：**首版边界维持或升级须
   先交设计复审**（v2 任务书 W5 已预留该条款）；若升级，走
   "from 属性前提、to 属性、原子对应、证据重算同源且版本化"的
   有界实现，正负控覆盖全部公共入口；不因数量压力放行"乱加立体/
   中和电荷"（红线）。
5. 交付计数：exact→完整源→编译→提交→命中分层计数（新批复测后）；
   **编译通过数不冒充命中数**。
6. 风险：映射放宽引入错误对应先验——product_set_mismatch 守门
   （执行产物=库记录多重集）必须保留；编译成功率提升的 U 增益
   属外推值。
