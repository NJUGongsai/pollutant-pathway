## 1. 指标定义（机器名 `matched_product_hit`）

```text
hit_v4(q) = [ 参考可评 ∧ P ≠ ∅ ∧ ∃E ∈ Eligible(q): S ∈ R_E ∧ P ⊆ T_E ]
```

| 符号 | 含义 |
|---|---|
| `S` | 题目底物的严格身份（`strict_identity_of`，与 v2 同一函数） |
| `P` | 本受评参考边在**产物侧、角色为 `principal_product`** 的全部不同严格身份集合（计量与重复次数不进本指标） |
| `Eligible(q)` | 该题的合法事件集合（定义见 §2） |
| `R_E` / `T_E` | 事件 E 实际参与物按侧别聚合的反应物身份集合 / 产物身份集合 |

**判定**：存在**同一个**合法事件 E，同时满足底物身份在反应物侧、全部主产物身份在产物侧 ⇒ 命中。

**明确禁止**：跨事件拼答案（多主产物题不得由多个事件凑齐）；跨互斥参考替代拼目标；用候选期望产物、模型自报或未提交/被拒事件代替实际事件。

**命名纪律**：本指标**不得**称为 `strict`。报表中与 v2 的 `strict` 永远分列，禁止跨版本比较"strict 数"。
对外表述必须带限定："仅声明主产物身份命中"，不得写成"反应预测正确率"。

---

## 2. 「合法事件」定义（三家一致要求，必须写死）

合法事件 E 指同时满足以下条件的事件：

1. **同题同 run**：属于该 qid、该 run_id；
2. **同受评步骤**：`step_scope` 与参考边一致；
3. **已提交**：存在于该 run 已提交事件集合中（`store.py` 提交契约），非候选、非期望、非被拒；
4. **实际参与物可解析**：两侧参与物均可解析为规范状态身份；
5. **参考侧角色与侧别一致**：目标集合只取该参考边产物侧 `principal_product` 角色的节点，
   不得以参考图其他节点或全部 from/to 节点替换。

**合法 ≠ 参与物完整 ≠ 配平通过 ≠ audit 全 verified。** 这些是披露项，不是准入项。

## 3. 桶定义（含 partial 桶触发条件，Qwen 要求补齐）

| 桶 | 触发条件 |
|---|---|
| `matched_product_hit` | 存在合法事件满足 §1 判定 |
| `product_hit_partial` | 无事件满足全部主产物，但存在合法事件命中**部分**主产物（多主产物题专用；不记为命中） |
| `unmatched_no_event` | 无合法事件（模型未提交 / 提交被拒 / 执行失败）；留固定分母，原因单列 |
| `unmatched_reference_invalid` | 参考目标为空、不可解析、或身份许可范围不足 ⇒ `not_evaluable`；**不真空通过、不称化学真错、不事后删题** |
| `unmatched_product_mismatch` | 有合法事件但主产物身份全不命中 |

**分母固定为 298**；任何失败/无效题不得剔除，不得事后压缩排名。

## 5. 披露指标（守恒降为披露，不作判对门）

且 v2 已判对的 119 题也只剩 26 题——等于把参考声明的不完整算到模型头上。

| 披露项 | 口径 |
|---|---|
| D1 按写配平 | 逐题：事件两侧元素多重集 + 形式电荷是否相等（三种口径的权威值见 `docs/V4_CONSERVATION_DISCREPANCY_2026-10-28.md`，**待填**） |
| D2 差额分桶 | 缺氢受体 / 缺氧源 / 缺水 / 其它（四桶，Kimi 口径） |
| D3 extras 来源分层 | 来自池条目（`from_pool_record`）/ 模型自写（`from_model`） |
| D4 SMILES 记法语义 | 报表须注明：`O`=水、`N`=氨、`OO`=过氧化氢、`CN`=甲胺；裸原子写作 `[O]`。**防"裸原子"误读复发** |
| D5 参考侧声明完整度 | 298/298 `partial` 照常输出；`superset` 不得改写为物理事实上的 `exact` |

**任何 v4 数字对外出现时，必须同页给出 D1 的"156 题中 X 题反应式自洽"一行。**
