## 二、待评设计摘要（自包含复述；全文见设计书，可读取核对）

**事件表示（推荐方案）**：共底物 B 进**反应物侧参与物集合**
（role=cosubstrate、side=reactant、coefficient_status=unknown），事件
= A + B → 记录全部产物；其中产物分两半——**可执行子集**（原子全部
可溯至 A 的产物组分，如主产物 P）照常推断映射+编译+AtomTool 执行；
**B 来源整组分**（断连出现在产物侧的组分，如还原型辅因子 NAD(P)H、
AMP 类）以**声明式拷贝**进入事件（身份 = 记录产物组分严格身份、经
同源函数派生 state_id；来源字段完整：record_key/provenance_sha256/
component_source="record_declared_copy"），**不经执行通道、不产生任何
编辑**；供体诊断对拷贝组分无映射 ⇒ **中心 unknown**（判据五），决策
表 R5。参与物协议零新发明（hypothesis.py 已有 cosubstrate 角色与
unknown 系数契约；production.py 已支持 spec["participants"] 显式覆盖）。

**键合贡献保守拒**：B 原子**键合进**主产物的形态（同一连通组分混
A-可溯与 B-可溯原子；合成例 `CCO.CC→CCOCC`、配平例
`CCO.C=C=O→CCOC(C)=O`）**结构化拒**
（`cosubstrate_bonded_contribution_unsupported`）。机理：执行图 =
render(底物)（冻结 0d.1 固定链），B 不在执行图内；表达键合融合的
唯一途径是 add_atom 生成 B 原子（你 R2-2 禁止的伪装）；"声明融合
产物+只执行 A 部分"不可行（单连通组分的执行输出 ≠ 声明产物 ⇒ 诊断
真失配）。同根 LR/RL、可锚/不可锚、有机/辅因子、未知角色、配平/
不配平全覆盖无例外。

**原子级守门**：编译器把产物并集原子三分类——A-可溯（经推断映射）/
B-可溯（可对应某声明共底物组分，有界子结构对应枚举）/不可归属（既
非 A 也非任何 B——corpus 记录已声明 B 时出现即源数据不配平）。机器
规则：①B 来源整组分零编辑参与；②键合融合整候选拒；③**不可归属
原子保守拒**（`cosubstrate_atom_source_unattributable`）——子选项
i 保守拒（设计推荐）/ii 允许并按你 r31 R31-1 隐式来源披露（EAWAG
型待遇），本条交你裁；④add_atom 伪装机器断言负控（component 候选
的 edits 里不得存在可归属 B 的 add_atom 原子，触发即测试红）。

**产物多重集 gate 扩展（同源）**：`执行组分多重集 ∪ 声明拷贝组分
多重集 == 记录产物多重集`（严格身份、多重集、同源
strict_identity_of/_executed_components_strict/_record_products_strict
函数族，不另写比较器）；拷贝组分身份 ≠ 记录对应组分 ⇒
declared_copy_mismatch 拒。落点：公共编译函数加可选参数（缺省空 ⇒
EAWAG/整串路径行为字节等价，负控断言），recorded-source 版本升 2
登记（你 r31 "gate 改动须随版本登记"义务兑现）。

**T1′ 边界重申**：三条落字条款——①coproduct_ignore_tier（proposed
未实施）的 r28 九条件边界（白名单仅无机小分子、只作用产物侧差集、
反应物侧仅 H₂O 特例、辅因子恒不忽略）不得因 partial 桶压力/完整产物
集语义/供给收益放宽，任何放宽=口径级变更须 teacher+新预注册；②
composition_only_hydrogen_equivalents 补全许可**不延伸**有机共底物
组分（λ_s×Δ 对账不为 NADH 类给覆盖 full）；③声明拷贝组分是**声明
参与物**，与 ignore-tier 的"可忽略差集"身份互斥，报告并排须分栏。

## 三、评审问题（逐条作答）

**CS1（事件表示与声明式拷贝的化学诚实性）**：B 进反应物侧参与物
+ B 来源整组分产物声明式拷贝（不执行、中心 unknown、来源字段完整）。

的表述够不够）；b) 拷贝组分在事件里沿用 role=coproduct（协议枚举不扩，

标签补丁；c) 事件系数全 unknown（库记录无配平系数）⇒ 元素/电荷账
unknown——该 unknown 在共底物事件上有没有比 EAWAG 型隐式水**更多**
需要钉死的读法风险？

**CS2（键合贡献保守拒）**：B 原子键合进主产物的形态整候选结构化拒

保守拒的化学理由链是否完整（有没有你认得的键合形态其实可诚实表达
而本设计错杀——例如共底物整体作为离去基/转移基、产物侧对应组分仍
为整组分的情形是否已被"整组分拷贝"覆盖）；b) 拒因类目与披露（键合
vs 不可锚 vs 不可归属三分）够不够支撑后续"哪类该立项机制轮"的决策；
c) 1,323 里整组分/键合两子集占比未测（unknown）——你需要什么只读
聚合计数探针才能裁"保守拒的供给代价可接受"？

**CS3（原子级守门与 gate 扩展）**：三分类 + 机器规则 + union gate。

c) 负控矩阵（NC-1..NC-7/PC-1..PC-3，设计书 §五.4）缺什么你必加的

**CS4（T1′ 边界与激励倒挂）**：三条落字条款 + 倒挂如实落字。问：
a) "A→P+NADH 洗成 strict"的两步（产物侧忽略 NADH 型拷贝、反应物侧
