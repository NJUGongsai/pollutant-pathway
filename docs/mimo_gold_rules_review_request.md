# 化学评审请求 — 金标体检四条规则的判据（v4.3 HIT60 S1.5）

你是独立的生物降解化学评审人（环境化学/微生物代谢方向），与系统作者无
利益关系，直言不讳。这是上一轮 E1 排序臂评审（你曾对判定表逐行复算零差异）
的延续；本轮**只评规则判据本身**，不需要任何题目数据。请用中文作答。

## 一、背景（三句话）

我们在构建单步生物降解题卷（底物 → 一步产物集合）与评分口径。已确认两处
数据侧问题：部分金标含题面未提供的共底物（如酰基-CoA 类），部分金标碳数
比题面多（守恒不成立），另有金标与题面同一分子的退化题。现在要把"哪些题
结构性不可答/口径有问题"写成**确定性代码规则**在跑批前拦下，规则冻结前
请你评判判据。

## 二、四条规则与我们的默认答案（请逐条挑战）

**R1 不可默认供给的元素集合**：金标含题面没有的元素属于
{P, S, 金属, 核糖/核苷酸骨架}（即 CoA/ATP/FAD/SAM 类大分子共底物的特征
元素）且无共底物解释 → 判"题面不可达"。
➡️ 我们的默认：集合就这四类。请挑战：有没有该拦没拦的（如 N——但含氮
共底物罕见且氮也常来自题面自身）、不该拦却拦了的（如硫酸酯水解引入 S、
磷酸化引入 P 是否可能在"无共底物提示"下由环境默认供给）？

**R2 可默认供给的元素集合**：金标相对题面新增元素仅 {O, H} 且可指认
O₂/H₂O 来源（加氧/加氢/氧化/水合）→ 保留，不算不可达。
➡️ 默认：{O, H} 白名单。请挑战：卤素有没有"环境默认加卤"的真实场景
（我们知道脱卤常见、加卤罕见——判据上要不要写成白名单外一律拦）？

**R3 碳数守恒例外**：金标碳数 > 题面碳数且无共底物解释 → 判数据错。
碳数减少的合法集合：−1（脱羧/脱羰）、−2（β-氧化切 2C）、按金标口径
登记的裂解（对称/不对称 C–C 断裂把一个分子变两个产物）。
➡️ 默认：增加必错（无碳供体时），减少限这三类。请挑战：碳数增加有没有
合法例外（C1 供体如 SAM 甲基化、缩合反应——它们是否都必须共底物在场）？
裂解的"按口径登记"怎么写才不漏（C7+C5 不对称裂解、三元/四元环开裂算
不算裂解类）？

**R4 退化题**：金标规范化身份 = 题面规范化身份（"无需反应"题）。
➡️ 默认：单独打标不删，题卷口径里声明（原样复读算命中）。请评判：这类
题该保留（考"模型会不会识别无需反应"）还是该剔出分母（口径噪声）？
若保留，判分上"空答"与"复读题面"怎么对待才公平？

## 三、输出格式

想到的、四条规则都拦不住的坏金标形态。
