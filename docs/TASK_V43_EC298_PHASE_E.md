   Phase D 报告更正节)。r2 未完成或仍有完整性失败 → 先修阻断,不进 E1。
2. **四层失分分层**(对 r2-C0 逐题逐步,不读金标答案字段做参数、只做
   事后归因):金标 207 步按不可达原因归类,总量守恒:
   - L1 截断:该步的母体分子**从未被展开**(路线停在前面的
     awaiting_prediction/预算耗尽)→ 记停因(超时/重试耗尽/预算/其他);

2. 候选手段(全部不碰门禁,只动工程参数,逐项独立成臂):
