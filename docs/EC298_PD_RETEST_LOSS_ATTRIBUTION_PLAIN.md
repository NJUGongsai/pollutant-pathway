# 298 道题丢分原因分析(大白话版)

> 对应技术版:[EC298_PD_RETEST_LOSS_ATTRIBUTION.md](EC298_PD_RETEST_LOSS_ATTRIBUTION.md)。
> 这里不用行话;术语对照表在最后。

## 这次考了多少分

我们用修复后的系统把 298 道化学题重考了一遍(开卷、单步转化题:
给一个污染物分子,答"酶会把它变成什么")。**第一答案正确的有 136 道
(45.6%),前五答案里包含正确答案的有 186 道(62.4%)。**

丢分的 162 道,我逐题翻了系统的"做题过程记录"(每一步的草稿纸都
留档了),把每道题丢分的原因分成了六类。**全程没有重新调用模型、
没有改任何数据,只是翻旧档案,所以结论可以复查。**

## 162 道丢分题,原因分成六类

| 丢分原因(大白话) | 题数 | 打个比方 |
|---|---:|---|
| **答对了,但没排在第一个** | 50 | 正确答案写在了第 2~5 个,阅卷只看第一个 |
| **选错了参考反应** | 44 | 题库里有正确反应可查,但系统挑了另一条相似的反应照着答 |
| **题库里压根查不到** | 31 | 翻遍了系统手里的资料卡,没有一张写着正确答案 |
| **查到了却没用上** | 25 | 资料卡里有正确答案,但系统自己"创作"时跑偏了 |
| **想改个分子,改法自相矛盾,被门禁拦下,交了白卷** | 11 | 系统说"我要改成 X",但它描述的改法做出来不是 X,按规定不许交,于是弃权 |
| **正确答案被门禁误拦(仅 1 题)** | 1 | 系统声明的目标就是正确答案,却因为描述里一处元素写错被拦下 |

## 几个最值得知道的发现

**1. 上一轮的修复真的管用。** 上一轮考试发现两类"工程bug式"丢分:
"正确选项在候选清单里却没被选中"(27 题)和"正确答案被校验环节
错杀"(8 题)。这次这两类**分别归零和只剩 1 题**;有 23 道上轮丢的
题这次第一答案就对了。修复没有白做。

**2. 最大的丢分原因是"排序",不是"不会"。** 50 道题正确答案已经
在答卷上了,只是没排第一。这就像考卷上写了 5 个选项,对的在第 2
个。这个问题从上一轮到现在**没有任何一个修复环节针对过它**,是
下一步最值得投入的地方(50 题 ≈ 16.8 个百分点,全拿回来的话
hit@1 能从 45.6% 到 62%+)。

**3. "多产物题"是重灾区。** 有些题的正确答案包含 2~3 个分子
(一个反应同时生成几种产物)。这类题 45 道,只答对 11 道(24%);
单产物题正确率 49%。而且有 13 道题其实**答对了其中一半产物**,
因为没答全被判错——组装和报全产物是个明显短板。

**4. 大部分丢分不是"查不到"。** 162 道丢分题里,124 道(77%)其实
在系统的检索资料里**看得到**正确答案,问题出在后续的挑选、排序、
生成环节。真正"资料里没有"的只有 38 道(其中 31 题连检索引擎
自己也排不进前十)。

**5. 系统也有超过检索引擎的真本事。** 有 16 道题,检索引擎前十名
都没有正确答案,是系统的"自己推理生成"路线答对的。生成能力不是
花架子。

**6. 弃权的 11 题全是"改分子改法写矛盾了"。** 好消息:这次逐题
核查,11 道被拦下的题**没有一道**是正确答案被误拦(上一轮有 8 道
误拦)。坏消息:其中 4 道题检索引擎明明排第一,本来是能答对的。

## 两个实验组的丢分原因几乎一样

这次同时跑了两组(区别只在于有没有开"相似反应物推荐"新通道)。
两组的丢分结构几乎相同(选错 44/44、查不到 31/31、排序 50/50),
差别只在抽样波动上——再次印证复测报告的结论:**新通道没有带来
收益,默认保持关闭。**

## 下一步建议(按性价比排序)

1. **让正确答案排到第一**(50 题)——从没人做过,空间最大;
2. **多产物题答全、组装对**(13 题答对一半被判错,最容易先捡);
3. **recorded 反应的挑选**(31 题确定性路径选错);
4. **检索资料覆盖**(31 题,属于资料库建设,不是算法问题);
5. 类比编辑的"改法描述"质量(11 题,其中 4 题本可答对)。

⚠️ 注意:这 298 道题系统以前见过,这些分析只能用来**指方向**,
不能直接在上面调参数然后宣布"变好了"——那要换新题考试才算数。

## 术语对照表

| 报告里的词 | 大白话 |
|---|---|
| hit@1 / hit@5 | 第一个答案正确 / 前五个答案里含正确答案 |
| 金标 | 标准答案 |
| 断点(breakpoint) | 这道题是在哪一步开始丢分的(确定性事实,不是猜测) |
| reported_at_rank_2_to_5 | 正确答案在答卷第 2~5 位 |
| selected_wrong_product | 选中并提交了另一条反应的产物 |
| retrieval_absence | 系统的检索资料里没有正确答案 |
| recorded 直通 | 检索到唯一记录的反应,直接照抄它的产物(不走模型) |
| rank 排序 | 模型从若干候选反应卡里挑一张 |
| analogy 编辑 | 找一条相似反应当"样例",让模型照葫芦画瓢改出目标分子 |
| novel 生成 | 没有可照抄的,模型自己推理生成产物 |
| target_consistency 门禁 | 确定性校验:"你声明的目标"必须等于"你的改法执行出来的结果",对不上就不许交卷 |
| 空答 / 弃权 | 交卷时一个产物都没有 |
| 引擎(Engine)Top-10 | 不走大模型的检索排序基线,排前十个候选;用来对照 |
| 多产物题 | 标准答案包含 2 个以上分子 |
| 组分口径(探索性) | 答案里只要有一个分子对就算部分对的宽松数法(正式评分不采用) |
| C0 / D-3 | 对照组(新通道关)/ 实验组(新通道开) |
| 五层证据 | 翻档的五个层次:原始检索→任务候选→选中→校验→最终报告,一层层看正确答案死在哪层 |
