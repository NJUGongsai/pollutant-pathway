### 3.2 守恒复合为何回撤(重要结构性发现)

22 题金标卡的守恒罚分分布:**cons=0(同分异构/互变级)5 题、
0<cons≤1(小步)6 题、cons>1(原子数变动)11 题**。守恒优先排序把
cons=0 的"不变换/异构化"候选(大量 no-op 卡)全部前置,对 11 题真原子
数变动的金标(脱羧、酰化、断链等)是**反向先验**——预声明主口径 s3x
因此回撤到 7/10/10(比基线 S3 还差)。守恒先验只对 023-S03/002-S03 类
同分变换题成立。这与 mimo 守恒评审"G1/G2 需改"的判断一致。

### 3.3 守恒硬过滤(先决 3 预演)的误杀率

filterA 按任务书口径(ΔC∈{0,-1,-2}、杂原子限 {O,H})**杀死 22 题中
7 题的金标卡**(005/008-S01/008-S03/010-S04/053-S02/081-S03/143-S04,
即 32%)。测量实现为"垫底而非剔除",宽窗下仍测得 10/13/14、p16=0.125
(4 进 0 出)——过滤对深位排序有正贡献,但**按硬剔除语义部署会永久
损失这 7 题**。结论:先决 3 过滤器若上,必须按 mimo 建议做成
"降位 + 供体登记例外",不能做纯剔除。

### 3.4 通道结构复核(门 1 §3.3 的再确认)

hC 通道复合救 USPTO 模板金标(077-S04 12→9、124-S03 29→6、058-S01
37→14、086-S01 21→1)但把 analog 金标推深(067-S05 13→483、
081-S03 65→153、143-S04 32→463)——**通道分层在 22 题内仍是零和**
(12/12/14 追平引擎)。S2b 通道内校准(z/分位数)保持通道内序不变,
单独作全局信号与生 S2b 等价(10/10/13),价值仅在跨通道复合的对齐。

## 8. 术语对照

| 术语 | 人话 |
|---|---|
| 互变规范化指纹 | 先把分子" keto/enol 可互变的写法"统一成一种标准写法,再比分子长相——避免同一物质因写法不同被认成不像 |
| MACCS 指纹 | 只看 166 个粗粒度"结构有没有"特征(有没有苯环、有没有羧基)的比对,粒度粗但对小改动不敏感 |
| 守恒罚分 | 答案卡产物与题面底物"原子账本"的差:差几个碳、几个氮几个氧,加权求和——越小越像"单步酶反应" |
| 同分异构簇 | 分子式完全相同、结构排布不同的候选卡群体(位置异构、开环/闭环等) |
| 通道感知复合 | 按候选卡来源(USPTO 模板/类比检索/envipath 规则)分组,组内各用各管用的信号,再按组内名次对齐合并 |
| 硬过滤误杀率 | 守恒规则把真答案卡当违规卡删掉的比例(本轮实测 7/22) |
| 混合上界 | 每道题都事后在"系统排序或任一信号"里挑最好(不可部署),用来量理论天花板 |
| 多重比较 | 试了很多种组合后挑最好的成绩,运气成分会变大;须打折看或换新题源复验 |
