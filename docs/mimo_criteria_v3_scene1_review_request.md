## 二、V3 草案三轴判据（评审对象；规则级）

**轴 A 互变异构归一（14 题）**：RDKit `TautomerEnumerator()` **默认配置**
（maxTransforms/maxTautomers=1000，removeSp3Stereo=True，
removeBondStereo=True）+ `Canonicalize()`，取 canonical isomeric SMILES 为
互变归一身份；**判等=双侧归一身份逐字相等**。前置许可门：仅参考节点
声明 strict_structure 范围时生效。两档设计（未选）：
- 档 B（判据档提升）：归一相等且许可门过 ⇒ 该配对计入 strict（headline 面扩大）；
- 档 A（仅披露轴）：只产出新披露档，不授 strict、不进 hit@1。

**轴 B 质子化写法归一（6 题）**：RDKit `Uncharger()` 默认配置逐组分施加，
**保留立体**，判等=归一后 canonical isomeric SMILES 逐字相等。
边界：归一后仍不等且两侧净电荷不同 ⇒ 不授；含碳质子化对
（CO₂/HCO₃⁻/CO₃²⁻ 系）**默认排除**（与 V2 零碳构造断言同向保守，
纳入须重开 V2 裁定）。

**轴 C 记录侧形式归一（T-E，7 题）**：**仅对检索记录侧** SMILES 施加
`Uncharger()` 默认（底物侧**不施加**——来源实验 64 行恢复全部只需归一
记录侧）；对齐判据与编译层同源（记录反应物整侧多组分子结构匹配，
零匹配=no_alignment）。作用层=检索/编译侧，**判据身份面零触碰**。
三层口径分开报：①对齐恢复 64 行（上限）→②编译通过 10 行/7 题（上限）
→③严格命中（本轮 unknown，未验）。

公共纪律：fail-closed（不可解析/算子异常⇒不授，无第三态）；参数版本化
（指纹 sha256，改动=升版本号）；轴间单归属（A→B 取先+双满足披露）；
正负控（正控=14/6/7 题只读重算逐题归一相等；负控=**23 题真异构体归一后
必须仍不相等**、V2 豁免面 tier 计数逐位一致、含碳对必须不授）。

## 三、请 mimo 评判的问题（按此逐条回复）

**Q1 互变归一的化学边界**：TautomerEnumerator 默认配置+Canonicalize 判等，
「互变归一相等 ⇒ 同一化学个体」在酶反应产物身份比较上是否成立？关键疑点：
来源数据里 14 条互变配对与 19 条真异构体配对的布尔画像**几乎同形**
（参考侧有立体、预测侧多数无立体、立体盲 canonical 都相等），唯一差别
是互变枚举后是否相等——这条轴的「救回」有多少成分其实是**立体被擦除**
而非互变异构？removeSp3Stereo/removeBondStereo=True 的擦除范围是否被
限定在互变中心、会不会把非互变的立体异构也一并擦平？

**Q2 档位选择**：档 B（归一相等即计入 strict/headline）vs 档 A（仅披露）。
从化学判据评审立场，你建议哪档？档 B 要安全需要什么前置条件
（例如负控通过率、擦除范围证据、师姐确认范围）？

**Q3 质子化轴**：Uncharger 默认+保留立体+逐字相等；净电荷差不授；
含碳质子化对（CO₂/HCO₃⁻/CO₃²⁻）默认排除。「Uncharger 归一相等 =
同一化学个体」的成立面与误判面？含碳对排除是必要保守还是过度保守？

**Q4 记录侧形式归一（T-E）**：仅归一记录侧、底物侧不动。
「酸式底物匹配到盐式记录」算不算**同一反应物**（这决定 T-E 的 7 题
能否算数）？三层口径（对齐恢复/编译通过/严格命中 unknown）分开报
是否足以防误读？

**Q5 正交与防泄漏**：许可门（参考节点非 strict_structure 范围不得升严格）
+轴间单归属+参数指纹+V2 豁免面不变断言——这套设计还有没有化学判读上
的漏（例如：芳香拼写差类为 0 题缺席时不应宣称已覆盖；两轴同时满足的
排序披露是否够）？

**Q6 总体读法**：这轮归一**最可能把什么误判成「同一」**？给最大风险点
+最优先的一条负控建议；以及归一提升的 strict 计入 headline（判据口径
变化、「测量修正」叙事）你作为化学评审怎么读？
