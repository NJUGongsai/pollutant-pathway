## §0 一页结论

1. **主干架构不换**（四方一致）：编译原子编辑→执行→审计→判分的公共链已被执行链四桶全零、判分零 LLM、内容哈希封存证明是对的；119 的缺口不在范式，在**四个可修面**：唯一模型调用的信息饥饿、共底物/立体的表示能力缺口、检索名额浪费、判据 v2 未激活。
2. **一个被 Codex 实测推翻的旧假设**：novel（模型生成）通道**有重大贡献**——130 题 strict 覆盖里 57 题、92 题 hit@1 里 42 题的冻结池为空（候选全部来自 novel）。**生成不能关、不能降级为纯排序**；LOCAL 自评审"novel≈0 则全押排序"的假设分支已被数据关闭。
3. **RankLLM 争议四方裁决**：不装工具包、不加调用次数；但"单次调用内把排序提示升级为排列式+新特征注入"值得 A/B（成本极低、≥3 seed）。真 RankLLM 库的滑窗多轮调用违反每题 1 次冻结预算，排除。
4. **119 条件性可达**（四方区间收敛后）：诚实中位 **+27~40**，置信区间 112~126。四条线（表示层/口径激活/供给质量/排序）任意两条掉链子就够不着——这句话进预注册。
5. **第一优先不是写代码是跑探针**：三份评审合计提出 ~14 个零成本探针，其中三个是"总闸门"（多步路径需求、共底物双口径联动、检索化学约束重放）——它们的数字决定后面所有工程线的生死。

## §2 五个关键裁决的展开

### 2.1 生成保留 + 唯一调用增肥（吸收 Codex P0 + 三方提示注入）

- 证据：92 题 hit@1 里 42 题池空（novel 独撑）；novel 提案 1,378 条、预校验拒仅 54——通道健康，瓶颈在**判断质量**。
- 方案：`candidate_evidence_payload`（纯函数）把已在线的事实喂进现有单次 decide 调用：编辑变化摘要/完整参与物角色与来源/对齐状态与表示保真度/条件与证明范围（缺失写 unknown）+ 底物官能团/局部环境档案（RDKit 确定性计算）+ 对齐质量/枚举截断等检索信号（mimo ③）。
- 纪律：Gasteiger 电荷等是计算描述符不得当确定位点；提示词变更=PROPOSALS_PROMPT_VERSION 哈希变=新批身份；同模型同预算 A/B，信息增量与模型强弱分开测（Codex：先信息后模型）。

### 2.2 共底物两步走（工程线 + 裁定线分离）

- 工程线（Codex P1）：主底物+单一已知共底物（先水/O₂ 两个家族）的**联合执行图**，原子带来源命名空间，完整记录两侧；水解/水合、氧插入做小范围正控；缺来源/歧义/不守恒保持拒。
- 裁定线（LOCAL/mimo 联动账）：**没有"共底物侧豁免族"新裁定，真执行档的诚实参与物（O₂/H₂O₂/NAD⁺）会把 strict 变 superset，hit@1 净增益 ≈0~5**。提请 teacher（附 CS2c 式双口径联动表：454 行剥离子集 × v2 现口径 vs 扩族口径的 hit@1 差值）。
- 不采纳：mimo"剥离档"作为独立方案（编辑不触袋原子才可剥——这本质就是反应物侧豁免族的判定谓词，并入裁定线）；Claude"停用 D2"（违 teacher T-1）。

### 2.3 排序线收敛（便宜试、不上库、多 seed）

- 采纳：固定快照离线模拟新特征（负即弃，零成本）→ 达标后单次调用内排列式提示 A/B（≥3 seed）。
- 排除：RankLLM 工具包（滑窗多轮调用）、rerankers 交叉编码器（新预测模型越界）、语义熵采样（违每题 1 次预算，除非重裁）。
- 预期：+2~8（四方区间下沿为主）；排序不是主干。

### 2.4 表示层三件套（立体/互变/质子化，全部探针先行）

- 立体：记录侧立体可用性审计（密封计数：21 题的模板记录产物是否带立体）→ 有源子集做编译期立体传播扩展 → 负控钉死。
- 互变：14 题判分域内 canonical 归一重放（封存 payload 只读、判分进程内、只出计数）→ 翻转 ≥5 才立项 → CC 拍板"记录形式提交是否构成禁库直抄"。
- 质子化：领域主导形式策略（6 题），与互变同轮拍板。
- 判分侧任何归一=改尺子=禁（四方一致）。

### 2.5 检索约束前移（mimo 最高 ROI 项 + Codex 速度视角）

- 现状盲点：analog 相似度检索不做元素硬约束 → 必死候选占池宽 8 名额 → 85 题全 na。
- 方案：元素∩+骨架/子结构预对齐进**检索排序**（policy-6 等价门重放探针先验证：top-8 可对齐占位率变化、85 题池质变化）。
- 与 RXNMapper 模板捆绑（mimo：不同步做则重演 RR"加量不加分"）。
