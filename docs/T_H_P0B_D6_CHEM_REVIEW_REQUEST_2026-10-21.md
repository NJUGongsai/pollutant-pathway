## 1. 需要评审的冻结规则（自包含摘要）

**R0 身份源。** 结构相等只用既有 `chemstate.strict_identity_of`（RDKit canonical
CXSMILES 的化学事实子集；去原子映射号/坐标/atomProp/DAT，保留同位素、电荷、
立体、增强立体组、自由基层与 SGroup 化学事实）。SMILES 按 `.` 拆分后逐组分取
严格身份，**排序后保留重复项**（多重集，不去重）。解析失败 ⇒ unknown，不落
consistent/inconsistent。

**R1 装配多重集与 copy 引用。**
1. 装配轴比较使用**共同多重集**：声明的生成组分（主产物 + coproducts，copy 不计入）
   对事件产物侧参与物做多重集包含/交集计数；同一出现不得被多个重复声明复用。
   重复 coproduct 缺一份 ⇒ 判不一致（子类 `declared_coproduct_missing_from_event`）。
2. copy 的“被引用”**严格检查声明 `state_ref`** 是否出现在事件产物侧参与物；
   结构对应只作为另一披露轴（`structure_in_event_products`），**不得替代**引用轴。
   copy 合法性还要求：不在执行结果组分内、不在 expectation target 组分内。
3. 本层不引入化学计量系数：声明中的重复组分按**出现次数**计，不按配平系数解释。

**R2 缺资料保留 unknown。**
1. 缺失/非对象事件载荷、缺失/坏类型参与物、参与物状态结构不可用 ⇒ 当需要装配
   比较时输出 `unknown / event_assembly_unavailable`，写入
   `proof_scope.unverified_ranges`，不得在聚合入口归一成“已知为空”。
2. 事件缺可用 production report ⇒ `missing_production_report`；action 无 spec 或
   spec 非对象 ⇒ `missing_spec`；两者优先于“空声明”。
3. 只有声明与执行**确知为空**（来源在位、执行已核、主产物/coproducts/copy 均空）
   才 `not_applicable`。“参与物资料完整且明确为空列表”是合法的已核为空，
   按装配矛盾判不一致，不升级成 unknown。

**R3 立体子类不得覆盖同位素差。**
1. strict 身份是唯一相等来源；strict 多重集 ⊆ 执行多重集 ⇒ 主产物在位。
2. `principal_stereo_only` 仅在以下条件成立时输出：strict 不等，**且**一个
   “去立体但保留同位素及其它化学事实”的代理（RDKit `RemoveStereochemistry`
   后按 strict 身份规范化）相等。旧的非异构代理（`isomericSmiles=False`，
   同时擦除立体与同位素）**不再**能证明该子类。
3. strict 不等、去立体代理不等、但旧非异构代理相等 ⇒ 输出诚实的未细分子类
   `principal_isomeric_unspecified`（差异可能是同位素或其它异构事实，不能声称
   只剩立体差）；连接/骨架不同 ⇒ `principal_absent`。两者都不得洗成 consistent。
4. 解析失败 ⇒ unknown；不得把已证 strict 不包含降级成 consistent。

**R4 proof_scope。** 本层只证明“本事件声明的生成组分 vs 已记录的
execution.result 碎片”的局部结构对应，以及 copy 是否留在执行外、事件产物侧内；
不证明机制、酶/生物可行性、金标正确性、配平/化学计量完整性、排序或评分。
consistent 不代表化学正确，inconsistent 不代表化学错误。

## 2. 评审问题（逐条回答）

1. **多重集/出现次数口径**：把 coproduct 重复声明按“出现次数”而非配平系数处理，
   并对事件产物侧做多重集包含（缺一份即不一致），在“只披露不判分”的层次上是否
   化学上可接受？有没有应视为同一生成组分的合理形态（如对称产物、同一分子多份
   在装配侧只记一次）会被该口径误判？
2. **copy 引用轴**：以声明 `state_ref` 是否被事件产物侧引用作为唯一合法性轴，
   结构对应仅作披露，是否比“结构出现过即可”更符合记录侧声明的化学语义？
   同一结构但不同 state_ref 的情形应判引用缺失还是应另设豁免？
3. **立体子类边界**：`RemoveStereochemistry` 后保留同位素/电荷/连接/增强立体
   事实的代理相等，是否足以证明“只剩立体差”？哪些立体/异构形态（阻转异构、
   双键 E/Z、增强立体组、未指定手性中心、互变异构/质子化）可能穿透该代理，
   应按“未细分”而非 `stereo_only` 处理？
4. **纯同位素差**：目前归入 `principal_isomeric_unspecified`（诚实未细分），
   既不称 `stereo_only` 也不称 `principal_absent`；这个粒度是否合适？若同位素
   差异在酶学题域通常应视为同一化学物种，本层是否应给出更明确的披露词？
5. **连接差的措辞**：连接/骨架不同归 `principal_absent`，但不称“化学错误”。
   这一区分在规则级是否足够，还是需要把“结构不同”与“执行失败/未执行”再分开？
6. **缺资料语义**：`unknown / event_assembly_unavailable` 与“明确空参与物判
   不一致”的分界是否符合化学证据语义？有没有把“资料缺失”误当“化学矛盾”或
   反过来的风险？
7. **覆盖与限度**：以上规则是否有遗漏的化学轴（如电荷、质子化、盐/溶剂、
   保护基、互变异构）需要在本层披露，或明确写入“不证明”清单？
8. **总体**：本规则能否作为 P0b/D-6 的规则级冻结口径（仅披露层）？若需修正，
   请只列规则级修正，不要要求硬门、改判据、改评分或扩大题域。
