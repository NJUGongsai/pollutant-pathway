## 0. 总判断

四条规则覆盖的三种形态（元素不可达、碳不守恒、无需反应）彼此正交，骨架成立。
逐条 verdict：

| 规则 | verdict | 一句话 |
|---|---|---|
| R1 | **需改** | 黑名单 → 白名单补集；集合 → 计数；比较前先去盐；"核糖"不是元素要降级；N 该并入 |

| R3 | **需改** | "增必错"成立但归因要分流；"减少限三类 + 裂解登记"改写为**缺口分子式表**，登记表可删 |

## 一、R1 不可默认供给的元素集合

**verdict：需改**——拦截目标（题面不可达）成立，判据三处要改、一处降级、一处并入。

### 该拦没拦的（漏）

1. **N 应并入拦截**。任务书的犹豫（"含氮共底物罕见、氮也常来自题面自身"）是**条件错位**：
   本规则只在"题面没有该元素"时触发，"氮来自题面"意味着 ΔN ≤ 0，天然放行、不会误伤。
   所以并入 N 的代价是零，收益是把**题面无 N 而金标有 N**（胺化、羟胺化、硝化等）
   从"观察列"变成拦截。唯一要拍板的开放项：是否承认培养基 NH₄⁺ 为默认氮源——
   建议**不承认**（位点不可从题面推出）；要承认就必须题面自己给出，
   [实现] 的多组分并集已天然支持。
2. **集合 → 计数 [实现]**：`new_elements = gold_elements - surface_elements` 是**集合差**，
   **题面自带 P/S 时第二次挂载看不见**。形态：底物本身含硫（硫醚/噻吩）而金标再多挂一个 S，
   或题面自带膦酸酯再多挂一个磷酸——元素集不变、碳数可不变 → 四条全放。
   **改用计数差（Counter 而非 set）是一行改动，且严格强于集合。**
3. **核糖/核苷酸骨架不是元素** [实现]：`RIBOSE_SMARTS` 是结构检查，只有元素差为零时才可能有增量。
   但 CoA/ATP/FAD/SAM/NAD/UDP-糖/谷胱甘肽/TPP/生物素/PAPS **全都带 P 或 S**，
   计数规则已拦住；核糖检查的真实增量只剩"核苷（无磷酸）"一类，而那类同时 ΔN>0（计数也拦）。
   反面：它的假阳性是**唯一会误伤糖类同一分子不同环型书写**的规则——
   `C1OC(CO)C(O)C1O` 是呋喃糖代理、葡萄糖呋喃型也匹配（[实现] 已自认），
   葡萄糖苷（题面常写吡喃型）→ 金标写成呋喃型的纯水解题会被误判 R1。
   ➡️ 建议：**RIBOSE 降级为观察/标签列，不再独立触发拦截**；
   若要保留拦截力，收紧到核苷基序（呋喃核糖 + N-糖苷键连碱基，或 + 磷酸酯/磷酸酐），
   且要求同时 ΔN>0 或 ΔP>0 才成立。

### 不该拦却拦了的（假阳性）

4. **成盐/反离子 [实现]**：`elements_of` 数的是 SMILES 里的原子；金标常登记成钠盐/盐酸盐
   （`[Na+]`、`Cl`），题面是游离酸/游离碱 → 金属/Cl "新增" → R1 误报；
   一旦改成"白名单外一律拦"，盐酸盐的 Cl 误报会更频繁。
   **必须在比较前剥离 spectator 反离子（带电单原子），另出 `salt_form` 表示法标记**，并进夹具。
5. **任务书举的两个"放行候选"方向反了**：硫酸酯**水解**是失去 S、磷酸酶水解是失去 P，
   都是 Δ<0，本来就不触发 R1——不构成风险。真正的开放项只有两个，且都建议**不开口子**：
   - **磷酸化（需 ATP）/硫酸化（需 PAPS）**：环境里确有磷酸盐、硫酸盐，但酶用的是
     **活化形式**（ATP 磷酸化、PAPS 硫酸化），且**位点不可从题面推出**——
     无共底物提示时模型只能猜位点，这不是"可答"，维持拦截。
   - **羧化（CO₂/HCO₃⁻ 是环境默认碳源）**：同时需 ATP + 生物素，且只给 C →
     归 R3 的碳增分支做**归因分流**，不放 R1。

### 建议的判据改写（R1' 与 R2' 合并为一条：白名单补集 + 计数）

```
R1' 元素可达性（白名单补集版）
前置（规范化，先做再比较）：
  P1 电荷归一、忽略立体（与 cn_identity 同口径）
  P2 剥离 spectator 反离子（带电单原子金属/卤离子）→ 两侧都剥，另出 salt_form
  P3 任一侧解析失败（题面或某金标条目）→ 不自动判定，整题进人审桶
计算：Δe = Σ_e(金标全部产物) − Σ_e(题面全部组分)，按计数（非集合），含总 H
判定：
  存在 e ∉ {O,H} 使 Δe > 0 → 拦（gold_cosubstrate_unreachable）
      豁免口径（确定性）：题面多组分并集含该元素且 Δe ≤ 0 → 天然不触发（现行实现即此）
      （若题面另有文本字段提示共底物 → 必须同时接封闭关键词表，否则会误拦；见漏网 #11）
  Δe > 0 且 e ∈ {O,H} → 放行（R2'）
  Δe < 0 → 不拦（脱卤/脱氨/脱磷酸/脱硫酸都是合法方向），碳的减少交 R3'
输出：Δ 表 + 命中元素 + salt_form + parse_fail 全部落表供人审
```

[实现] 现行"共底物解释 = 题面按 `.` 拆分后元素并集"本身是干净的确定性口径，**予以保留**；
要改的只有：集合→计数、去盐前置、解析失败转人审三处。

### R1 例外案例（具体反应类型 + 共底物名）

- **该拦而现行会漏**：O-/N-/C-甲基化（**SAM**，如真菌对五氯酚、氢醌的 O-甲基化）——SAM 无 P，
  产物不带 S/N 时**元素差为空**，R1 全盲，只剩 R3 的 +1C；硫醚底物再上一个 S（**PAPS**
  硫酸化/硫代硫酸酯化）——集合差为空；题面无 N 的胺化（**谷氨酸/α-酮戊二酸**氨基转移对）——
  现行只进观察列。
- **该放而现行会拦**：钠盐/盐酸盐登记（表示法，不是化学）；同一糖的呋喃/吡喃书写差异
  （核糖代理 SMARTS）。
- **维持拦截（不同意开口子）**：己糖激酶 葡萄糖→6-磷酸（**ATP**）、芳基硫酸转移酶（**PAPS**）、
  **UDP-葡萄糖**糖基化、**谷胱甘肽**（GST 结合）、酰基-CoA 活化（**CoA + ATP** → 酰基-CoA +
  AMP + PPi，同时带来 P/S/额外 C/N）、生物素依赖羧化（**ATP + 生物素 + CO₂**，转 R3 分流）。

## 二、R2 可默认供给的元素集合

**verdict：需改**——{O,H} 白名单核心成立；"可指认 O₂/H₂O 来源"要降为留痕；
卤素按"白名单外一律拦"我**同意**；H 是死代码必须补。

### 例外案例

- **放行且理由成立**：顺式二醇（双加氧酶，+2O，需 O₂）、环氧化/羟化（单加氧酶，+1O）、
  水合（+H₂O）、**还原（+2H，来源是 NAD(P)H 而非 O₂/H₂O）**、水解脱卤（卤烷脱卤酶：
  +O 去卤，新增 = {O}，放行）、过氧化物酶过氧化加氧（**H₂O₂/ROOH**）、脱氢（−2H）。
- **"来源指认"这句判据本身要改**：任务书写的是"可指认 O₂/H₂O 来源"，但氢的合法来源是
  **NAD(P)H、H₂O**，氧的合法来源是 **O₂、H₂O、H₂O₂/有机过氧化物、（羧化时）HCO₃⁻**。
  把"必须指认 O₂/H₂O"写死会**把还原反应误判**。➡️ 来源指认**不当门槛**，
  改为按 (ΔC, ΔO, ΔH) 查确定性模式表打标签留痕；归不上类 → 打"未归类氧当量"进人审，不拦。
- **条件分支（可选）**：若题面有"厌氧"条件字段，则需 O₂ 的样式（+2O 且非水解、顺二醇样）应拦。
  [实现] 目前 `gold_health_labels` 只吃 SMILES、无任何条件字段——**若题面是纯 SMILES，
  这条建议直接删掉**，不要留成永远读不到的分支。

### 卤素（任务书开放项）——同意写成白名单外一律拦

环境"默认加卤"的可指认场景只有**卤过氧化物酶**（需卤化物 + H₂O₂，如氯过氧化物酶、
钒溴过氧化物酶）这类，且必须卤素在场、位点与卤素种类均不可猜；
而**脱卤**（还原脱卤、水解脱卤、双脱卤）方向是 Δ<0，本来就不受本规则约束。
所以：题面/组分含该卤素 → Δ=0 → 放行（现行并集语义已做到）；题面不含 → 拦。
**没有可接受的例外。**

### H 死代码（本条最重要的实现发现）[实现]

`elements_of` 走 RDKit 原子符号，**隐式氢不入集合**（夹具自己注明"H 永不新增"），
所以 R2 白名单里的 **H 是空条款**——{O,H} 实际等于 {O}，而**氢的增减没有任何规则检查**。
后果：重原子数、元素集、碳数全同、只有氢数不同的金标（芳环莫名饱和、该还原型给成脱氢型）
四条全放。➡️ 比较改用**含总 H 的分子式**（`GetTotalNumHs(includeNeighbors=True)` + 显式 H），
并加一列**不饱和度差 ΔDoU**（由分子式纯算术得到，零 LLM）；|ΔDoU| ≥ 2 且无合法 Δ 模式
→ 观察列进人审。这条同时补上漏网清单 #1、#2 的一半。

```
R2' O/H 新增放行 + 留痕
  前置同 R1'（去盐、解析失败转人审），比较用含 H 的分子式计数
  新增元素集合 ⊆ {O,H} → 放行（"可指认来源"改为打标，不作门槛）
  按 (ΔC, ΔO, ΔH, ΔDoU) 查模式表：
    ΔO=+1,ΔH=0 单加氧/环氧化；ΔO=+2,ΔH=0 双加氧顺二醇；
    ΔO=+1,ΔH=+2 水合；ΔO=+2,ΔH=+2 双羟化；
    ΔH=+2 还原（源 NAD(P)H）；ΔH=−2 脱氢 …
    归不上类 → "未归类氧当量"观察列 → 人审（不拦）
  新增元素含 O/H 之外任何一项 → 由 R1' 拦（即"白名单外一律拦"）
```

## 三、R3 碳数守恒例外

**verdict：需改**——"增加必错（无共底物解释时）"成立；
"减少限三类 + 裂解按口径登记"要重写；+C 的归因要分流。

### 先说一个好消息 [实现]

现行实现已经是**产物求和**（`gold_c` = 全部金标条目碳数之和，`substrate_c` = 题面全部组分之和），
夹具也钉了 C6→C3+C3、C3→C2+CO₂ 均通过。**所以任务书担心的"C7+C5 不对称裂解怎么登记"、
"三元/四元环开裂算不算裂解"根本不需要登记**——只要碎片**列全**，ΔC=0，就是守恒、不是例外；
环开裂同理（一个变两个产物、和不变 → 天然放行）。

### 要登记的不是"裂解类型"，是"按口径不列出的去向"

这是一张**纯算术的分子式表**，比反应类型表短得多也好穷举得多（反应类型要感知结构，
缺口分子式只要减法）：

```
缺口 = 题面总和 − 金标总和（逐元素）
ΔC = 0     → 放行（裂解/开环只要列全即自动覆盖，登记表里没有它们）
ΔC = −1    → 放行并标缺口分子式 ∈ {CO₂, CH₂O(甲醛), CO, 甲酰基}
ΔC = −2    → 放行并标缺口分子式 ∈ {C₂ 碎片: 乙酰基/乙醛/乙酸（乙酰-CoA 单元）}
ΔC ≤ −3    → 不直接判错，进"未列全/多事件嫌疑"人审桶
             （quarantine 只出提案、人审生效的处置口径下，桶比硬判错合适）
ΔC > 0     → 见下面的归因分流
```

➡️ 回答"裂解怎么写才不漏"：**删掉裂解登记表**，只保留上表三行缺口去向；
C7+C5（列全即 Δ=0）、三元/四元环开裂（Δ=0）都不进表。

### 碳数增加有没有合法例外——没有"合法例外"，但有"归因分流"

两者都拦，处置不同（数据错要修金标；不可达要改题面或剔题），人审提案理由应分开：

- 逐类过一遍：C1 供体（**SAM** 甲基化、甲醛/甲酸）、缩合（**乙酰-CoA**、草酰乙酸、α-酮戊二酸）、
  共轭（**UDP-葡萄糖**、**谷胱甘肽**、**酰基-CoA**）、羧化（**CO₂/HCO₃⁻ + ATP/生物素**）——
  **全部都要求共底物在场**，所以"无共底物解释时增加必错"成立，**没有绕开共底物的合法碳增**。
- 但 +1C 的成因通常是"**共底物没进题面**"（不可达，R1 语义）而非"金标碳数写错"（数据错）。
  [实现] 现行一律打 `gold_conserv_violation` → **归因错**。➡️ 分流（仍确定性）：
  - +C 且多出的原子**恰构成一个可指认碎片**：
    ΔC=+1,ΔO=+2 且产物为羧酸 → 羧化样式；ΔC=+1,ΔH=+2 → 甲基化；ΔC=+2,ΔO=+1 → 乙酰化/缩合
    → 归 `unreachable_cosubstrate`（提案：补共底物或剔题）；
  - +C 且多出部分**对不上任何已知碎片** → 归 `conserv_violation`（数据错）；
  - "羧化样式"单列**人审桶**而非硬判错：CO₂/HCO₃⁻ 确实环境默认，最可能是被出题者接受的环境羧化。
- 注意 SAM 甲基化在"题面无 S/N"时 **R1 看不见**（元素差为空），全靠这条拦——
  分流规则要排在归因第一位，别把它当"数据错"完事。

### 还要补的两处

- **多分子题面**：[实现] 已按 `.` 全组分求和 ✓（保留）。
- **减少侧现在完全没实现** [实现]：代码只有 `gold_c > surface_c` 一条，
  任务书"减少限三类"尚无对应——上面的缺口分子式表就是它的完整实现规格。

### R3 例外案例

- 放行：脱羧（−1，缺 CO₂）、β-氧化硫解切 2C（−2，缺乙酰单元）、O-脱甲基（ArOCH₃→ArOH，
  −CH₂，ΔC=−1）、醛缩合/meta 裂解一步变两个产物（和不变）、环氧化物水解（ΔC=0）。
- 分流人审：真菌 O-甲基化（SAM，+1C）、苯甲酰-CoA/2-羟基苯甲酰-CoA 羧化（+CO₂，
  厌氧芳烃降解，需 ATP+生物素+CoA）。
- 拦：题面 C₆ 而金标 C₈ 且无共底物。

## 四、R4 退化题

**verdict：需改**——"打标不删"成立；"进主分母 + 原样复读算命中"**推翻**；
旗标要拆两组子形态。

### 保留还是剔出分母——建议：数据不删、打标、主分母外单列、双轨报告

- 反对进主分母的核心理由是**分布来源**：这类题的频率是**构造产物**（通路库自环、
  同一分子登记两次、transport 步、仅差立体的异构酶被 cn 规范化抹平），
  不是预注册出来的技能分布 → 放进主分母 = 往总分里塞了一个**没人预注册过的权重**。
  它同时奖励"遇事复读题面"的退化策略；若再把"空答"算对，就变成奖励"遇事空答"——
  两个免费分还互相打架。
- 保留论点的最强版本（"考模型会不会识别无需反应"）**本身成立**，
  但前提是**故意造题、控制频率、预注册**——从数据里意外漏出来的自环不构成这种题。
  要考"识别无反应/持久性"，就作为**独立分层题**单列，不作为副产物混进主分母。
- 与本仓既有做法同构（298 post-hoc 双轨）：**主数出两份（含/不含退化题），
  预注册指定哪份是主口径；决定必须在看分数之前写死**——否则就是择优。

### 判分（只在单列层内生效，怎么定都不动主数）

- 规范化后等于题面 → 命中（"原样复读算命中"在这一层成立）；
- 明示"无反应/不转化" → 命中（**需一张封闭关键词表**，仍确定性、零 LLM）；
- **空答 → 未命中**：空答与"没答/解析失败"不可区分，宁可保守；
  空答若算对会给"永远空答"送分。
- 主分母不含该层，所以以上任何选择都不改主口径。

### 旗标要拆——现行一面旗盖了两种形态 [实现]

`gold_ids & surface_ids` 是**交集**语义，于是：

- `degenerate_full`：金标（规范化集）= 题面集 → 真"无需反应"题（上面对待的是它）；
- `degenerate_mixed`：金标 ⊋ 题面，产物集**混了未反应的底物**（夹具 64–68 行正是这个）→
  **另一形态**：分数影响与 full **方向相反**——full 给"复读"送分，
  mixed **惩罚"只答新产物"的正确答案**（模型答对了转化，却因没复读底物被判 partial/错）。
  两者不能共用处置。

### 再拆一组（raw vs cn）

- `R4a`：规范化**前**原始 SMILES 就相同 → 构造自环，基本是 bug；
- `R4b`：原始不同、cn 规范化后相同（差立体/质子态/互变异构被抹平，夹具
  `C[NH3+]` vs `CN` 正是）→ 可能是**真实一步但不可判**（差向异构酶、异构酶）。
- 关键：**判分口径本来就把 R4b 当与题面相同来比**（cn 立体盲、电荷归一），
  所以模型在 R4b 上**无法表达被抹掉的差异** → R4b 在评分上与 R4a 等价、**必须同待遇**；
  但归因上报两个数（R4a ≈ bug、R4b ≈ 真实不可判），否则 quarantine 提案理由会错。

### R4 例外案例

纯 bug 自环（通路步前后同一分子）；差向异构酶/异构酶步被 cn 抹平（R4b）；
残留底物混入产物集（degenerate_mixed）；葡萄糖苷水解但环型书写不同
（**不是** R4——cn 不抹环型，反而会被 R1 核糖代理误伤，见 R1）。

## 五、四规则合用的漏网清单

按"会不会真进分母"排序，每条附确定性缓解（全部为算术/集合/SMARTS/封闭关键词表，零 LLM）：

1. **隐式 H 全程不可见** [实现] → 等重原子、错氢数的金标（错饱和度/错氧化态、芳环莫名饱和）
   全放。**缓解**：改含 H 分子式 + ΔDoU 观察列（R2'）。
2. **同分子式错骨架/错位点**：ΔC=0、元素差=0，但羟化位点（邻/对）、开环方式、重排、
   环收缩、片段配对错 → 四条全放。E1 评审里位点/键选择是主要错因，
   **没有分子式差异撑着的版本最危险**。**缓解**：规范化后"同式不同连接"单列计数桶
   （能确定性判定"存在"，判对错仍需人）。
3. **多酶事件压成一步**：脱卤+羟化+开环+脱羧同时出现，各元素/碳都在允许范围 → 全放。
   **缓解（半确定性）**：按 Δ 模式归"反应类别"，类别数 ≥2 → 打标人审。
4. **解析失败绕过** [实现]：`elements_of("junk")→set()`、`carbons_of→0`——金标里某条目
   不可解析时它对元素/碳**贡献为零**，R3 可能假通过；题面不可解析时元素并集为空 →
   金标所有元素都"新增"，R1 全面误报。**缓解**：任一侧 `parse_fail > 0` → 整题进人审桶，
   不可解析按"未知"而非"零"。
5. **成盐/反离子**：金标登记成钠盐/盐酸盐 → R1 金属/卤素假阳性；"白名单外一律拦"会放大它。
   **缓解**：比较前剥离带电单原子 + `salt_form` 标记（R1' 的 P2），并进夹具。
6. **核糖代理过宽**：匹配一切呋喃糖（含葡萄糖呋喃型），同一糖的呋喃/吡喃书写差异会被误判。
   **缓解**：降级观察列，或收紧为核苷基序。
7. **产物集内部与卷级结构**：金标产物集**规范化后内部重复**（部分命中口径下白送分）；
   同一题面+金标在卷内重复（重复计权）；金标只列多个合理产物之一（四条都不看"完整性"）。
   **缓解**：集合内去重 + **T0 卷内查重**（纯身份比较）；完整性留给组件级判分口径 v3 的 partial 通道。
8. **R4 两组子形态**（full/mixed、raw/cn）混在一面旗里（详见 R4）。
9. **共底物豁免是元素级不是反应级**：题面只要自带某元素，该元素的**任何**新增都被豁免
   （硫醚底物 + 任何 +S、膦酸底物 + 任何 +P）。计数差能补回大部分，但"题面元素恰好覆盖
   金标挂载"仍只能靠 +C（R3）兜底，兜不住就漏。**缓解**：接受为已知残差，出计数列（不判）。
10. **电子当量/外部电子受体**：等式抵消的氧化还原错配（该还原给成脱氢型、脱卤却没有对应
    受体）四条都不看——这归守恒那条线（`mimo_conservation_rules_review_request.md`）。
    **提醒：别两边都以为对方在查。**
11. **题面信息通道**：若题面除 SMILES 外还有文本（条件、共底物提示），现行"共底物解释"
    只读 SMILES 多组分会**误拦**；若接文本关键词表，必须用封闭表
    （CoA/ATP/NAD(P)/FAD/SAM/PAPS/GSH/UDP/biotin/TPP/NH₄⁺/HCO₃⁻…）保持确定性。
    **先确认题面字段结构再定。**
