### Phase 1 配对骨干与闭合对账

以全 **298 个合格 qid 配对**为基础，只消费既有 v2 main 口径。定义 hit1 为 `main.rank==1`；S/P/U 以既有 `main.match_status` 映射，映射写入 schema，不重判化学结果。

- **L（损失集）**：A hit1、B 非 hit1；预期 **14**。
- **G（增益集）**：A 非 hit1、B hit1；预期 **8**。
- **L_strict**：L 中 B 仍为 strict 且 rank>1；预期 **10**（rank 2/3）。L 中另 4 题非 strict。
- 闭合：`|G|−|L|=8−14=−6`；首位翻转 `|L|+|G|=22`；strict-rank>1 为 33→37。
- 状态迁移：S→P 5、S→U 8、P→U 12；P→S 2、U→S 9、U→P 9；合计 **45**，下降 **25**、上升 **20**。strict 流出 `5+8=13`、流入 `2+9=11`，净 **−2**。
- 主分析展示全 298 配对；L/G 仅为按结果挑出的描述性对照，不单独据此做机制显著性判定。不使用未定义的 G_strict。

任一锚数字对不上就停止并报告。产物可在唯一写目录保留必要的本地配对台账；对外只报聚合，不外发逐题身份。

### Phase 2 线索甲：出处/完整度与首位变化

前提：Phase 0 已确认有获准、安全、可配对的首位候选特征；否则整项 unknown。

- 对全 298 配对核对可用率，以每题 A/B 首位候选构成一对；描述 `source_kind` 转换、participants 行数差、coproduct 非空状态的配对变化，分别报告合格对数与缺失原因。L/G 只附描述性分层。
- **A 已有 `transformation_ref` 与 `coproducts`**，不能把 B 的出处/共产物信息当作从无到有。先区分已有字段与新增字段，避免把共有信息归因给证据卡。
- participants 数量与真实反应组成、候选种类等混杂；即使 B 首位偏向参与物更多或某一来源，也不能证明模型使用了“出处先验”。
- 使用配对汇总：二元特征列两臂不一致对数，数量特征列逐题 B−A 分布。若报告探索性检验，采用题内交换 A/B 标签的配对方法，登记假设、固定种子与次数；不使用忽略配对的独立样本 Fisher 作为主检验，不设 P<0.05 的机制成立门。
- 差异小、不显著、方向不一致或样本不足，均如实描述及记录 unknown；不写“甲否”。候选身份/池不可比时停止增量归因，只保留可核对的事实。

### Phase 3 线索乙：位置暗示

前提：已有获准安全导出，同时包含完整编辑原子端点、描述符命中原子及二者一致的原子映射；否则位置关联 **unknown**。

- 当前 `edit_summary` 的断/成键项缺端点，单靠摘要不能计算编辑位置与电荷极值/FG 命中的重合。不得把“原子级不可算”改称“候选级降级”后继续假装能判断位置。
- 只有完整安全映射可用时，才按 Phase 0 写明的定义计算同题 A/B 首位候选的位置重合配对差，报告全体合格配对、缺失原因，附 L/G 描述性分层；不从题面、SMILES、SMARTS 或封存 run 重建缺失映射。
- 若已有安全字段能识别 `gasteiger=unknown` 或 FG 空表，可描述这些分层内的配对结果；这些分层并非随机分组，样本小或差异不显著不能证明位置机制消失/不存在。
