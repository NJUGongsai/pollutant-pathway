## 7. 架构可动点

### 7.0 现状流水线

```
记录源 / 编译池
   ↓
一次模型调用（模型自报 rank_hypotheses）
   ↓
合并 / 去重 / 按模型位次（+ 未排名 fallback）提交
   ↓
零 LLM 判分（strict / partial / unmatched）
```

关键事实：**提交序 = 模型自排位 + fallback，系统没有独立的校验/重排层。**
所有“捞分”的架构空间都挂在三个接口上：模型看到的证据、提交前的确定性守门、编译池的供给。

### 7.1 A. 选择层（打 32 题排序）

**A1. 证据卡 v2（已设计，未实施）**

- 改法：删卡内重复的 source 对象（source_kind / transformation_ref / origin_group_key /
  alignment_ref），participants 改保真紧凑，FG delta / 分子式 delta 增补；顶层
  transformation_ref 保留（非盲臂）。
- 证据：chain14 A/B 整卡 on/off 干预下开卡臂比关卡臂 **−6 题**（91→85）；归因探针看到
  **novel 被挤出第一位 15:2（p=0.0024）**；participants 行数更多 10/14（p=0.078，方向）。
  这些足以重议 source/完整度呈现，但**未隔离单字段因果**。
- 上限：32 题（非空池）；含空池的 strict 非首位共 37。
- 成本：一次 298 A/B 批；实施 + Codex/mimo + 预注册。
- 状态：设计任务书 2026-10-18 已冻结（`docs/TASK_EVIDENCE_CARD_V2_DESIGN_2026-10-17.md`），
  实施未开始。
- 风险：A/B 估计的是整包差异；必须带既有停点（任一分族 v2 strict 净失 ≤−3）和 token 门。

**A2. 零模型排序回放（建议先做）**

- 改法：不改生产代码；把已存的事件按另一套预注册顺序重放、在 HPC 上重判，先测
  “模型位次 / 池优先 / 最小编辑优先”等规则能否把 32 题里的 rank2 翻到第一。
- 成本：零模型；需要 HPC 只读事件 + 重判（金标不出 HPC）。
- 价值：如果简单规则就能翻几题，再决定要不要进生产；如果翻不动，说明只能改证据/模型，
  不要写一个没有证据的 ranker。
- 状态：未建。

**A3. 不建议现在做的**

- 用“参与物越多越优先 / 来源优先 / 完整度优先”的确定性规则重排。chain14 已经看到这类
  完整度/来源信号会把正确答案挤下去；在没有新证据前不要加。

### 7.2 B. 覆盖层（打 41 题 partial）

**B1. 零模型缺口分诊（先做）**

- 对 41 题（优先 19 题旧口径第一）逐题看：缺的是反应物侧共底物、产物侧共同产物、角色、
  系数，还是 step scope。
- 数据：native_result 只有候选侧 participants / step_scope；评分侧 per-event /
  per-participant 的 coverage 缺口明细未留存（Stage 0 已确认），所以**不能**只靠
  native_result 定缺口类型。需补评分侧明细，或做候选级对照；不读金标，不输出候选 SMILES。
- 输出：在补齐评分侧明细后，才分“可确定性补全的子集” vs “只能改结构/匹配的子集”；
  当前可行动子集 = unknown。

**B2. 提交前覆盖校验 / 同源补全（分诊后再决定）**

- 改法：模型返回后、提交前，用记录侧已声明的参与物清单做确定性校验；只补**记录侧明确声明**
  的缺失参与物，不造化学；补不进去就保留 unknown，不硬凑。
- 边界：必须尊重 NC-9 的 copy-in 与执行期望区分；不能把拷贝组分塞进执行期望。
- 上限：41 题；转化率 unknown。C 线 0/13 的教训是“模拟能解锁 ≠ 实际能兑现”。
- 成本：原型零模型；化学评审 + 小批验证。

### 7.3 C. 供给层（打 47 题无候选 + 40 题空池）

**C1. remap 对齐审计**

- 对象：41 题 remap + 旧口径无候选；remap-only 17 题（1 hit）。
- 改法：对 remap 产物做底物身份 / 反应中心 / 对齐一致性的后置审计，把错对齐拦在模型之前，
  或生成多个对齐备选；属于编译工程，不是新化学能力。
- 证据：关联缺口约 18 题（按非 remap 命中率外推 54.4 vs 实际 36），**不是因果**。
- 成本：中高；先做零模型审计面数。

**C2. 空池兜底**

- 改法：唯一 spec 被身份门拒时，退到“无新增原子、身份安全”的 remap，而不是直接空池。
- 上限：新增 7 空池里仅 1 题已证实损失；低优先级。

**C3. 不能顺手开的**

- 深位召回、类比编辑、窗口扩大、温度调整、多轮调用：任务书死路清单，需老师批准 + 新证据。
