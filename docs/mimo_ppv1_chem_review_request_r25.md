## 0. 背景(一段)

298 题来自 V6 外部题卷:每题一条**数据库方向化反应记录**
(RHEA/EnzymeMap/BRENDA 源,微生物酶促污染物转化,经筛选确认

## 1. 判断面一:单步参考边的 step_scope

**规则草案**:`每题一条参考边:底物根节点 → 该题全部金标产物节点`;
`step_scope=net_reaction`(候选保守值 `unknown`)。理由:源记录是
数据库 master/directional 反应(总包转化),不是机理基元步;
标 `elementary_step` 过度声明机理,标 `multistep_summary` 又与
"单步题"卷面语义冲突(每题只判一步转化,不组装多步路线)。

**合成例**:底物 `CCO`,金标产物 `CC=O`(醇→醛形状)——一条边
`CCO → CC=O`,step_scope=net_reaction;模型若给出
`CCO → CC=O` + 中间体 `CCO` 氧化路径细节,评测器只按该边判
净转化命中,不要求机理步骤对齐。**问**:对"数据库方向化记录"
统一标 net_reaction 是否合适?是否有题类(如水解/异构化)在
该口径下被误松或误紧?

## 2. 判断面二:共同产物与主/共产物角色口径

**规则草案候选**:
- (a) **全 principal(proposed)**:每题全部金标产物节点 role=
  `principal_product`(与旧判分口径"全主产物组分命中"同构:
  候选组分集合 ⊇ 金标全部产物组分才算命中);
- (b) 规则分主/共:小分子副产物(如 CO₂/水/氨)标 `coproduct`,
  命中判据只核 principal。

**合成例 A(单产物)**:`CCCCCC → CCCCCCO`(己烷末端羟化形状),
产物唯一 ⇒ 该产物即 principal,两口径无差异。
**合成例 B(双产物,共同产物语义)**:某裂解形状
`底物X → 有机酸P1 + 有机酸P2`(同一反应事件同时生成两个含碳
产物):口径 (a) 下 P1、P2 都是 principal,模型只报 P1 不报 P2
⇒ 不算全命中(共同产物不被报告 K 删除——参考图两产物都在
同一条边的 to_node_ids 上);口径 (b) 下若 P2 被规则判成
coproduct,则只报 P1 即命中。**问**:(a) 是否把"裂解双产物都算
主产物"收得过松/过紧?(b) 的"小分子=共产物"规则级切法在酶促
转化里是否站得住(例如脱羧放 CO₂:CO₂ 对"污染物转化"评测算不算
应召回的主产物)?有没有不该用元素/大小启发式分的反例?

## 3. 判断面三:参与物列表口径(辅因子剥离的如实声明)+ 匹配身份范围

**规则草案**:`participant_list_status=partial` + 覆盖声明显式披露
"参与物=剥离后含碳组分;辅因子/共底物(NAD、ATP、GSH、水、金属、
大分子辅因子)按 2026-09-22 提取规则未列"(候选 (b)
`source_complete`:把原始反应全组分解析进参与物,共底物与金标
主产物混列)。`coefficient_status=unknown`(题卷无配平系数)。
匹配侧 `identity_scope`:根/产物节点全部按**严格结构身份**为主、
CN(charge-normalized stereo-blind)仅作旁证封顶(评测器既有
实现:声明 cn_only 的节点不得授严格命中)。

**合成例**:原始反应(示意)`CCO + NAD+ >> CC=O + NADH + H+`;
提取后金标只留含碳有机产物 ⇒ 参考边 participants =
{底物 CCO(reactant/substrate),产物 CC=O(product/principal)},
NAD+/NADH/H+ 不在列表,participant_list_status=partial,覆盖声明
记录"辅因子未列"。模型输出 `CC=O` ⇒ 结构严格命中;模型输出
`[CH3-]C=O`(电荷差异形状)⇒ 严格身份不命中,CN 一致只作旁证
披露,不授严格命中。**问**:partial+披露是否如实且足够?
source_complete 会不会把"共底物被剥离"的信息优势变成
"共底物参与判分"的口径漂移?严格为主+CN 旁证的封顶对单步
酶促题是否合适(电荷/互变异构体在酶学记录里常见,严苛会不会
系统性低估)?

## 4. 判断面四:known/unseen 轨道与 recorded 语义

**规则草案**:298 题对系统是"已见题"(2026-09 首轮+Phase D 复测
跑过,分数在案;题卷反应源与检索语料的重叠未经审计)⇒ 主报
**轨道 A known_evidence_reconstruction**(已见题、已知证据重建,
结论句式"在已见 298 题、冻结配置下的重建成绩");轨道 B
unseen 需先冻结排除清单(把源记录从语料排除),本轮不做。
节点/边 `status=reference_only`(recorded 只表示库中有记录,
不自动升格实测;候选 `observed` 留给 teacher 若认定卷面
microbe-confirmed 筛选构成已观察)。`source_group` 一题一组
(跨题记录 ID 重叠极小,计 5 个 enzymemap ID 标 related 披露);
53 个跨题重复底物按 distinct occurrence 保留(不按结构首现合并)。

**合成例**:两题同底物 `CCCCCC` 不同产物(一题 `CCCCCCO` 羟化
形状、一题 `CCCCCC=O` 氧化形状,纯示意)⇒ 两个参考图各自根节点
occurrence 不同、互不合并;两题各自算独立样本(同底物多反应)。**问**:"已见题+语料重叠未
审计"标轨道 A 是否如实?一题一组的独立性口径在"同底物多题"
(53 底物/89 题重复)下会不会虚增独立性(同底物两题算两个独立
样本是否偏乐观)?reference_only 会不会过保守(数据库记录+
微生物确认筛选的证据等级是否够 observed)?
