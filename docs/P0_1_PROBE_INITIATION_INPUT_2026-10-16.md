## 一、有效候选定义（什么算「本应通过编译/对齐却被机械拒绝」）

**通用定义**：S2 池编译站以拒因 R 拒绝的候选行，称为该拒因下**有效候选（潜在误拒）**，当且仅当：

1. 由该候选行**自带证据记录**（语料 / recorded / analog 侧的底物-产物 SMILES 与反应描述）出发，
2. **存在**一条化学上成立的原子映射方案，使该候选对应的净反应（含该证据要求的方向与辅底物处理）能被现行编译规则判定为「可编译」；
3. 即：拒绝不是化学/结构上的必然，而是现行判据（对齐搜索策略、枚举上限等）的产物。

约束（对所有通道通用）：

- 判定**只看候选行自带证据**，不读金标、不读 `questions.jsonl` / 参考图（金标盲性，继承漏斗探针同款纪律）；
- 「化学上成立」属化学实质判断，**一律师姐确认后生效**；本设计只定流程，不执行任何裁定；
- 每件判定输出**三值**：`pass_expected`（应通过=有效候选）/ `reject_correct`（机械拒绝正确）/ `uncertain`（证据不足或写不出映射要点）。三值定义见第四节流程。

### 通道A（analog | no_alignment，机械拒 2818 件）有效候选判定条件

Ai. 该行 analog 证据描述的底物-产物对应与该候选行的底物一致（同底物前提成立）；
Aii. 存在可行的原子映射：底物→产物在原子/键级守恒意义上可配平（水/质子的增减性豁免口径以现行编译规则文件为准，判读材料包里随件附该规则条目出处）；
Aiii. 拒因确为 no_alignment：失败点是「找不到对齐」，而非电荷编辑/立体编辑/产物集不匹配（后三者属各自拒因面，归不进本通道，不得为凑合格样本挪到本通道）。

**排除（不算有效候选）**：对齐仅能对到证据里非本题范围的部分；结构本无对应；电荷/立体编辑不可行但另有明确归属的拒因；证据记录本身缺失关键结构信息到无法判读（三值归 `uncertain`，不硬判）。

### 通道B（mapping_enumeration_truncated，机械拒 224 件）有效候选判定条件

Bi. 该候选行所本的语料/recorded 证据存在化学上可行的映射组合（判定条件同 Aii 配平标准）；
Bii. 该可行映射位于枚举器的**截断面之外**——即被枚举上限/顺序截断丢弃，而非枚举优先序内已被正确排除；
Biii. 不存在其他独立成立的拒因（辅底物 bonded contribution、产物集不匹配等属各自拒因面）。

## 二、分母口径（哪些机械量不能当分母，逐条列明）

**被估量定义**：通道内**有效误拒率** = P( 判「应通过」 | 该 channel×reason 的机械拒绝件 )。
分母 = 该 channel×reason **机械拒绝的总件数**（A: 2818；B: 224），**条件在「已被机械拒绝」之内**——这是定义使然（误拒率本来就是「拒绝之内」量的率），不是拿机械量冒充误拒量：机械量只充当**抽样框大小**（条件分母），分子（误拒量）必须由抽样+人工化学确认测出。

**不能直接当分母的机械量（显式清单，逐条说明）**：

| 机械量 | 出处 | 为什么不能当分母 |
|---|---:|---|
| **5266 件 / 292 题** | 漏斗 S2 站 | 全通道混合 14 种 (channel,reason) 的机械拒绝总量，任何单通道分母都不是它；叠用会把 corpus/analog/recorded 各拒因面混出一锅 |
| **249 / 50 / 55 / 34 等「损耗题数」** | channel×reason 表 | 「该站至少有 1 件损耗的题数」，**件级计数≠题级计数**；误拒率按件定义，题级不能直接当分母 |
| **analog 原始检索条数** | 漏斗 unknowns | 漏斗明确 unknown：analog 原始检索面未逐件记账（前门跳过 analog_pregate_skipped 未计数）→ 「本应产出候选但前门就跳过」的分母**构造不出**；该面归 unknown，本设计不测、不硬算 |
| **5540 / 5473 / 5540−5266** | 漏斗闭合账 | 这些是检索面/谱系行总量与闭合算术，对应「全候选面漏损率」这类**另一指标**（分母是未被拒的候选全体），不是「拒绝之内」的误拒率；本设计不测该指标，留作 unknown 说明 |
| **2818 / 224（抽样框 N）** | channel×reason 表 | **可用**，但有一个前置核验：若同一 (record_key, 候选行) 因多题/多目标被重复计入，须先去重；N 以物化后的抽样框实际行数为准（执行阶段先物化清单再钉 N；样本量设计按 2818/224 上界预留） |

**件级率 → T-G 消费口径**：T-G 的 ≥10% 判定线按**通道**分别消费件级误拒率估计（±95% CI）；「多少题至少有一件有效候选被拒」的题级影响作为附带统计随报告给出，**不参与 ≥10% 判定**（题级会因一题多件受扰动，件级口径更稳）。

## 三、抽样方法（本地、零成本、可复现）

### 3.1 抽样框物化

抽样框 = P0 漏斗配备的逐候选谱系行中，`channel/reason` 逐行匹配目标组合（A=`analog|no_alignment`，B=`corpus|mapping_enumeration_truncated`）且终态 `compile_rejected` 的行清单。物化方式：**只读复用** `p0_funnel.py` 的 `extract_funnel/classify` 路径（同款 import 零改口径），输出逐行清单 `(row_id, question_id, record_key, channel, reason, family)`；这是确定性本地只读脚本，属**实施阶段的最小执行件**，规范见附录A（本单不执行）。

### 3.2 抽样框去重与 N 钉值

物化后先按 `(record_key, 每行的底物-产物对)` 去重出真实 N；若去重后 N 明显小于 2818/224，抽样量按去重后 N 重算（下式），并在报告里披露原始计数与去重后 N 两个数。

### 3.3 分层与样本量

**通道A（analog | no_alignment）**：按 [拒因固定为 no_alignment × 族（FamilyMarker 11 族）] 分层**比例抽样**，层内件数 n_h ∝ N_h（向上取整）。族层内件数以物化后的抽样框为准（漏斗族分栏 547/543/413/3247 等是全 S2 拒量 5266 的族分栏，仅作方向参照，**不得**拿来当 A 通道层权）。

**样本量计算（A 通道）**：
- 精度目标：p=0.10 处 Wilson 95% CI 半宽 ≤±5pp → 需 n ≥ ⌈1.96²×0.09/0.05²⌉=139；
- 叠加预期 10% 「存疑/无法判读」→ n=155；
- 有限总体修正 FPC(N≈2818)：155/(1+155/2818)≈147 → **取 n=150**。

**通道B（mapping_enumeration_truncated）**：N=224（约 50 题、每题约 4.5 件），总体小，**建议直接全查（census）224 件**——人工判读量与 A 通道单个通道相当、消除抽样误差；若人工预算不容，退化为按题+件分层随机 n≥110（FPC 后 95% CI 半宽在 p=0.10 附近约 ±6pp，边界精度略松，报告中如实注记，由主会话/CC 拍板取舍）。

### 3.4 抽样方式与种子（可复现）

- 全局固定 **seed = 20261016**；
- 层内排序：按 `(record_key, row_id)` 字典序升序；
- 抽取：`random.Random(20261016).sample(层内有序列表, n_h)`；
- 抽中/未抽中清单**整个落盘**（未抽中清单是分母审计材料），材料清单 SHA-256 记录；
- 全程零模型零网络；抽样结果可由第三方用同一 seed 与物化清单**复现重放**（重放比对为验收动作之一，写进实施阶段交付）。

### 3.5 复核材料包生成

对每件抽中行生成材料包，字段全部来自候选行自带字段与语料/资产侧：候选行 ID、channel/reason、底物/产物 SMILES、证据记录要点、现行编译规则对应条目（Aii/Bii 豁免口径的出处）。**不含**金标、不含判分参考答案、不含模型输出（本面在 S2，模型尚未出场）。

## 四、化学确认流程（流程设计；本单不执行裁定）

三段接力，角色分离，禁止同一人兼判读与确认：

| 段 | 角色 | 做什么 | 不做什么 |
|---|---|---|---|
| 1 | 执行者（implementer） | 物化抽样框 → 去重钉 N → 按第三节抽样 → 生成复核材料包 → 落盘记录框架 | 不做任何化学判定；不读金标/题面 |
| 2 | 化学判读者（judger） | 对每件按第一节三值判定（`pass_expected`/`reject_correct`/`uncertain`）+ 一句话判定依据；判 `pass_expected` 必附**映射要点**（哪条对齐方案可完成）| 不见执行者结论、不见金标、不读判分参考；不修改编译器代码 |
| 3 | 律师姐（确认人） | 化学实质判断**逐件确认后生效**：判 `pass_expected` 的件经律师姐确认方可计入误拒率分子；`reject_correct` 件抽检；`uncertain` 件单列（不入分子分母，原因如实记） | 不做执行/不跑批/不接触代码库 |

判读一致性与抽检（进入判读流程的门槛条件）：

- `uncertain` 处理：如实记录原因（信息缺失/化学判定两可/证据不收敛），单列报告；`uncertain` 件不进分子不进分母（见第五节口径）；
- 二次判读（一致性保障）：A/B 各通道抽 n=15 个判完件做第二遍独立判读（换判读者或同判读者隔 ≥1 天），agreement<90% 或 Cohen κ<0.6 → 判读流程回炉重训（含判定条件补细化），全部样本重判一遍后才可出率；κ≥0.6 才视为判读可用。

**记录格式**（每件一行 JSONL，字段固定）：

```json
{"case_id": "...", "question_id": "...", "record_key": "...", "row_id": "...",
 "channel": "analog|corpus|recorded", "reason": "...", "family": "...",
 "judgement": "pass_expected|reject_correct|uncertain",
 "judgement_basis": "≤2句",
 "mapping_anchor": "判pass_expected必填：对齐方案要点；其余件 null",
 "judged_by": "...", "second_read": {"by": "...", "verdict": "..."} 或 null,
 "confirmed_by": "律师姐确认人（pass_expected件必填）或 null",
 "confirmed_at": "...", "materials_sha256": "..."}
```

**留档位置**：判定记录 + 抽样/未抽样清单 + 正负控锚记录入新批次根 `reports/ppv1_s5b/p0_1_initiation_input_<执行日期>/`（误拒复核材料不含金标，可入仓；若执行中出现任何金标/题面相关材料，按仓库红线移送 gitignored 目录并汇总去题面后回仓）。机械量/分母/分子/存疑四栏齐报，机械量不得充当误拒量。

## 五、分通道正负控设计（A、B 各自独立测量与报告，不合并）

### 正控（确认应通过的样本 = 潜在误拒阳性件）

1. 判 `pass_expected` 件须**双锚**：①judger 写出映射要点；②律师姐逐件确认（第四节）；两锚齐才算确认应通过；
2. **本地重放正控（可离线第三方验证）**：把该件映射要点重放回现行编译器（本地确定性、零模型）——预期转为「编译通过」；若重放仍拒，该件**降级进存疑面**（说明现行编译规则另有缺陷面），不进分子；重放动作零成本、附证据哈希；
3. 判读可用性负锚（判读者能力面控制）：从编译**通过**件（S2 通过 274 件中同族抽 n=15）盲判——若判读者把明确可行件误判成 `reject_correct` 的比例 >20%，判读流程不采率、回炉。

### 负控（确认应拒绝的样本 = 机械拒绝正确件）

1. 判 `reject_correct` 件须给出**明确化学不可行/不适用理由**（一句话），经律师姐抽检（抽检比例 n=15/通道）确认后在分母内正常计；
2. 抽检不通过 → 该件返工重判；返工后再不通过 → 判读一致性警报（同第四节二次判读处理）。

### 估计与输出格式（直接喂 T-G）

每通道输出一行：

| 字段 | 含义 |
|---|---|
| `err_rate_est` | 有效误拒率点估计 = 确认应通过数 / (确认应通过 + 确认应拒绝)（`uncertain` 与二次判读仍不一致且未解决件单列，不进分子不进分母） |
| `wilson_ci95` | 95% Wilson 区间 |
| `n_total / n_pass / n_reject / n_uncertain` | 分母构成全披露 |
| `census_or_sample` | census（B 建议全查）或分层抽样 + seed + 物化清单 SHA |
| `posneg_ctrl` | 正控/负控抽检结果与一致性 κ |
| `domain_tag` | 298（RHEA 通用酶学/已见题）——题域标签随数走 |

T-G 消费：`err_rate_est`（含 CI）≥10% 才立项该通道修复，低于则降维护；**两通道各自判，不设「两通道同时过线」的附加条件**（任务书 #7 原文）；本设计执行后产出的这份表，就是 T-G 判定的输入；此外任何解读（如「修复杠杆排序」）不得越过本表数字。

## 六、纪律段（随身摘要 + 反滥用红线）

1. **机械拒绝量 ≠ 误拒量**：5266 件/292 题、2818 件、224 件全部是机械拒绝量，只充当抽样框大小与条件分母；误拒量（分子）必须靠抽样+人工化学确认测出。任何以 2818/224/5266 本身直接说出「误拒率 X%」的表述都是违规、不采。
2. 本设计**输出的只是「有效误拒率估计」的测法**；执行后产出的估计供 T-G（#7）立项判定消费——**≥10% 才立项、低于则降维护**；本设计本身不宣布立项或不立项，也不构成 T-D/E/F 的触发条件。
3. **零模型、零 API、零费用**：本单全文未执行任何运行；后续执行阶段（若有）也只动编译/枚举的本地确定性环节（抽样脚本、重放正控），不调用模型、不跑批、不付费；判分/评测零 LLM 边界不受影响。
4. **题域标签不外推**：全部引用数字带 298（RHEA 通用酶学/已见题）标签；不外推 dev、不外推其他批、不外推闭卷。
5. **金标盲性**：判读全程不读金标、不读 `questions.jsonl` / 参考图；证据只来自候选行自带字段与语料/资产侧；金标产物不入仓。
6. **化学实质判断一律师姐确认后生效**：判 `pass_expected` 未经律师姐确认不得进分子；本设计不执行任何一步化学裁定。判据若涉及变更走 criteria 版本流程；预注册先于付费；**探针 ≠ 预注册 ≠ 成绩**。
7. **不改写任务书口径**：第〇节对「recorded 映射枚举截断」的措辞出入做的是**如实注记**（漏斗数据中该拒因位于 corpus 通道），不是口径改写；测量面以拒因为准，T-G 若需 recorded 整体口径另立测量面。
8. reports/、runs/ 只读；金标与题面永不触碰；执行阶段的证据归 `docs/review_evidence/` 的规则照旧（本单零运行，不新增任何运行产物）。

```
  3 全量写 frame 清单用、未抽中清单用 (供分母审计)
  4 for (channel,reason) in TARGETS:            # a: 2818上界; b: 224全查或n>=110
        strata = group_by(frame, family)
        for s in strata: n_h = ceil(N_h * n / N)  # census通道: n_h=N_h
        sample = concat([random.Random(seed).sample(sorted(strata[s]), n_h)])
  5 输出材料包 (仅候选行自带字段+规则出处; 零金标零题面零模型输出)
  6 落盘: 抽中/未抽中清单、seed、各输入 sha256、脚本 sha256
```

验证：抽样重放 = 以同 seed + 同清单重跑得同抽中集（第三方可复现）；闭合核对 = 未抽中数 + 抽中数 = 去重后 N。
