## 一、一句话

**v6 = v4 原样不动，只改一处：比较"是不是同一个分子"时，把只差质子化状态的两种写法视为同一个化合物**（例如羧酸与羧酸根、胺与铵、磷酸的各级解离形式）。其他所有判定规则、排位规则、分母都不变。

---

## 二、现行 v4 是怎么判的（不变部分）

`ppv1-criteria-v4`（`matched_product_hit`，2026-10-28 预注册）：

1. **命中定义**：存在**同一个**合法反应事件 E，同时满足：
   - 题目底物的身份 ∈ E 的反应物身份集合；
   - 参考答案中所有**主产物**（`principal_product`）的身份 ⊆ E 的产物身份集合。
2. **禁止跨事件拼答案**：底物和全部主产物必须在同一个事件里一起命中。
3. **不要求共产物完整**（v2 → v4 的主要区别）。
4. **排位**：Hit@k 看第一个命中事件在提交序列中的位置。
5. **分母固定**：失败题、无效题都不剔除。
6. **身份函数**：`strict_identity_of`，即严格结构身份（区分电荷、质子化、立体等）。

## 三、为什么要改：v4 被"写法"误伤

- 同一个代谢产物在数据库里有时写成**带电形式**（生理 pH 下的解离态，如 `R–COO⁻`），有时写成**中性形式**（如 `R–COOH`）。在 v4 的严格身份下，两者被判为不同分子，即使模型给出的化学结构完全正确也算错。
- 证据（同一份模型答卷，只换身份比较方式；严格 v4 → 质子化不变）：

| 题域·分集 | v1.1 存档 | v1.2 存档† | 新采样 R | 新采样 T |
|:--|:-:|:-:|:-:|:-:|
| `[biosysmodb121·调参集 N=261]` Hit@1 | 54 → 90 | 66 → 99 | 58 → 88 | 61 → 92 |
| `[dev-298·调参集 N=196]` Hit@1 | 77 → 78 | 91 → 94 | 82 → 84 | 84 → 86 |

  † v1.2 存档复用了 v1.1 的模型回复（同一份采样），仅供参考。

- **关键观察**：B121 每份答卷都多出约 30 题，298 只多出 1–3 题。如果是模型能力的问题，两个题域不该差这么多；更合理的解释是 **B121（环境污染物数据库）的参考答案在电荷写法上不统一**，而 298（RHEA 通用酶学）比较统一。
- 增益来源：B121 上约一半来自产物侧写法差异，另一半是底物和产物两侧都有写法差异。
- **参考答案写法审计**（调参集题卷原始字段，T5 §2，零调用）：

| 指标 | `[biosysmodb121·调参集 N=261]` | `[dev-298·调参集 N=196]` |
|:--|:-:|:-:|
| 底物写成带电形式 | 167（64%） | 44（22%） |
| 产物中有带电形式 | 190（73%） | 37（19%） |
| **同一题内底物、产物一个带电一个中性** | **53（20%）** | 17（9%） |
| v6 多算命中的题（三份样本并集，Hit@1） | 38 | 3 |
| 其中产物官能团 | 羧酸根 23、磺酸 / 磷酸等其他带电 9、磷酸 3、中性 3 | 羧酸根 2、其他 1 |

  → B121 的参考答案大量采用带电写法，而且同一题内前后写法都不一致（20%）；v6 增益集中在羧酸根这一明确的写法差异上，不是把所有分子都"中和"换来的。

## 四、v6 的规则

### 4.1 唯一改动：身份函数
```
身份_v6(x) = strict_identity_of( 质子化归一(x) )   —— 若通过全部护栏
           = strict_identity_of( x )                —— 否则（保持 v4 原样）
```
- **对称作用**：参考答案和模型预测**两侧都**做同样处理；**底物和主产物都**做处理。
- 质子化归一的实现：RDKit `rdMolStandardize.Uncharger`，外面套下面的护栏。

### 4.2 允许合并的（只差质子）
| 类型 | 示例（通用官能团，非题目结构） | v6 |
|:--|:--|:-:|
| 羧酸 / 羧酸根 | –COOH 与 –COO⁻ | ✅ 同一个 |
| 胺 / 铵（可去质子的） | –NH₂ 与 –NH₃⁺ | ✅ |
| 磷酸各级解离（含磷酸单酯 / 二酯） | –OPO₃H₂ / –OPO₃H⁻ / –OPO₃²⁻ | ✅ |
| 硫酸单酯、磺酸 | –OSO₃H 与 –OSO₃⁻；–SO₃H 与 –SO₃⁻ | ✅ |
| 两性离子（如氨基酸） | 两性形式与中性形式 | ✅ |
| 烯醇负离子 / 酚氧负离子 | –O⁻ 与 –OH | ✅ |
| 质子化的芳香氮（如吡啶鎓） | 有可去的 N–H⁺ | ✅ |

### 4.3 明确不合并的
| 类型 | 原因 | v6 |
|:--|:--|:-:|
| **小分子与无机物**：碳酸体系（CO₂ / HCO₃⁻ / CO₃²⁻）、NH₃ / NH₄⁺、CN⁻ / HCN、SCN⁻、H⁺ / H₃O⁺ | **CC 2026-11-13 拍板：不算**。它们更像不同物种，碳酸体系还涉及水合，不是单纯差一个质子 | ❌ 保持 v4 |
| 季铵等永久正电荷（N 上没有 H 可去） | 无质子可去，不存在"写法差异" | ❌（本来就不变） |
| 硝基、N-氧化物等形式电荷结构 | 整体中性，电荷是结构的一部分 | ❌（身份不变） |
| 盐、带反离子的多组分写法 | 多组分一律不归一，单独计数 | ❌ |
| 互变异构（酮 / 烯醇等） | 不在本次范围 | ❌ |
| 立体信息 | 不放宽 | ❌ |
| 游离酸 vs 辅酶 A 硫酯、辅因子加合物 | 是不同化合物，不是写法差异 | ❌ |

### 4.4 护栏（按顺序执行；任何一条不通过，就退回 v4 的严格身份）
1. 在小分子排除清单中 → 不归一；
2. 多组分（盐 / 反离子）→ 不归一，记 `salt_not_normalized`；
3. 本来就是中性 → 直接沿用原身份；
4. 归一后**结构不变量**必须全部相同：重原子连接、键级、元素组成、同位素、立体（含增强立体）、自由基、组分数，**只允许形式电荷和对应位点 H 数变化**；
5. **净电荷只能变得更中性**：出现"从 0 变成非 0"、符号翻转、绝对值变大中的任意一种 → 退回；
6. 归一后的身份必须能被 v4 同一套身份函数稳定复现（幂等：归一两次 = 归一一次）。

每条记录都留痕：参考侧、预测侧各自是否被归一、原因、归一前后的净电荷，翻转题标注是"产物侧 / 底物侧 / 两侧"导致的。

### 4.5 不变的部分
事件合法性、禁止跨事件拼答案、主产物定义、不要求共产物、排位规则、Hit@k 定义、固定分母、失败桶：**全部与 v4 相同**。

## 六、采用流程（建议）
1. **CC 已拍板**：确定采用后，v6 **代替** v4 作为主口径。
   - 说明：按仓库 G1 条款，历史 v4 数字保留存档、不覆盖。采用 v6 后，需同步修订 AGENTS.md 中"永久基线 = v4"的条款（由 CC 决定）。
2. **先冻结、后开留出集**：v6 规则冻结并登记（含脚本版本哈希）之后，才允许开留出集。
3. **全部历史成绩一起按 v6 重算**：在调参集上先重算 v1.1、v1.2、Exp-1b/2、消融各臂等。全集历史基线（如 B121 113/417、298 156/298）因为含留出题，**等开留出集时一并重算**，避免提前偷看。这样 v6 带来的整体抬升对所有方法都一样，比较的仍然是方法之间的差距。
4. **对外数字**：标注 `ppv1-criteria-v6`，带题域与分集标签，并附一句"相对 v4 仅改为质子化不变身份"。
