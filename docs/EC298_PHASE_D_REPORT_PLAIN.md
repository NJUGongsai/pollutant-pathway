# EC298 Phase D 大白话版:给供体"找亲戚"的两条新路,值不值得用?

> 技术版:`EC298_PHASE_D_REPORT.md`。这一版用日常语言讲清楚做了什么、
> 结果如何、哪些话不能说。术语对照表在文末。

## 一句话结论

三条新东西都做出来了、质量也验过了,但真实对照实验说**先别用**:新找亲戚的方法让成绩**变差了一点**(20 题里 2 题退步、0 题进步),按事先定好的规矩,系统保持原样(结论:no_release)。

## 背景:上一阶段留下的三个问题

Phase C 的体检发现:66 个类比任务里,只有 23 个供体"结构上站得住",
其余 43 个进不来。原因分三层:

1. **找错方向**(39 次):老办法是"拿预测的产物去找谁能造它",找到的
   反应跟当前底物八竿子打不着 —— 类比推理的出发点(结构相似)根本
   不成立;
2. **说明书缺页**(12 个):资产里的反应模板只标注了不变的部分,真正
   发生变化的地方没标 —— 模板等于没写;
3. **名额太少**(预算 3):每步最多看 3 个候选供体,可能好供体排在
   第 4 名以后。

Phase D 就是修这三件事,然后**用同一套考卷(dev 20 题)做对照实验**,
看修完到底有没有用 —— 不是"感觉有用"。

## 做了三件事

### 1. 找亲戚新路(D1):按"长得像"找供体

新检索:拿**当前底物**的分子指纹,去 17183 个已知反应的**反应物**里找
结构相似的(相似度 ≥ 0.45,最多取 16 个)。找到的供体照旧要过全套
化学安检(氢够不够、价态成不成立、有没有两个打架的答案),**相似只
管"叫到号",不管"录不录"**。

参数怎么定的?只看资产本身的统计(多少钱条、相似度怎么分布),**没有
看任何考题和答案**。所有参数写死在卡片里,改动会被系统发现并拒绝。

### 2. 补说明书(D2):给缺页模板重新标注

用确定性算法(找两边分子的最大公共骨架,骨架对骨架、多出来的原子
各自标注)重新给 2828 条"缺页"模板画标注:

- **767 条修好了**(机器八项检查全过:两边能解析、编号不重、元素对
  得上、化学内容没被改、变化非空……);
- **2059 条修不了**:其中 1162 条是"两边根本是同一个分子"(电子转移、
  离子配对这类"假反应")—— 这是我们抽样复核时**自己发现的错误并
  修掉的**:第一版把这些错当成了"修好";
- 人工抽查 100 条:0 错。

**但有一个诚实的问题**:做复核的是我(实施模型),不是独立的人。任务书
说没人复核就不能上新资产。所以 **v2 新资产只用来做了免费离线对照,
真正花钱的实验没敢用它**。复核工作表已经备好,等真人(或外部审查)
点头后才能上。

### 3. 对照实验(D3):同一套题,四种配置

- **免费预演**(不花一分钱,不碰答案):资格数 11 → 14(新路)/
  19(新资产)/ 22(两个都开)。方向对,但这只是"进考场的人数",
  不是"答对的人数";
- **真实考试**(Chenyu,同模型同考卷同预算):四个组 ——
  老配置(C0)、新检索+预算3(D-3)、预算5(D-5)、预算10(D-10)。
  结果(数字 = 答案排第 1 位的比例,越高越好):
   - 老配置 **20.8%**
   - 新检索+预算3 **19.3%**(2 题退步:pb_0459、pb_0471,0 题进步)
   - 预算5 **16.9%**、预算10 **12.6%**(预算越大越差,10 的时候
     "编造产物"的比例也翻倍了)
   
   **为什么变差**:新检索让更多步骤走了"类比照抄"这条路,其中一部分
   照抄失败或者抄歪了,反而挤掉了原来能蒙对的路径。免费预演里"能进
   考场的人变多了"(11→14),但真正答对的变少 —— 这正是任务书坚持
   "不能拿资格数当成绩"的原因,这次实验就是活例子。

## 钱的账

四组加起来 2.75 元,上限 120 元,没超。每组跑之前先做了
一次几厘钱的连通测试记账。

## 哪些话不能说

1. **"资格变多"不等于"答对变多"** —— 最终只认真实考试的报告产物命中;
2. dev 只有 20 题,差 1 题不算数;门槛(净赢 ≥2 题)是工程约定,
   不是统计证明;
3. 新资产 v2 没过人工关,任何"v2 带来 X 提升"的说法都不存在 ——
   花钱实验里根本没用它;
4. 老资产 v1、以前的所有跑分产物,一个字节没动。

## 术语对照

| 报告用语 | 大白话 |
|---|---|
| 供体 (donor) | 已知反应,拿来当"参考答案" |
| reactant_similar 通道 | 按底物长得像来找参考答案 |
| 变换/映射 (transform/mapping) | 反应模板里"哪根键怎么变"的标注 |
| applicable / ambiguous / inapplicable | 能用 / 两个答案打架(弃权) / 化学上用不了 |
| 预算 (budget) | 每步最多核查几个候选 |
| cn@1 | 主评分口径下,正确答案排第 1 位的步数 |
| 净赢 ≥2 题 | 配对比较里,赢的题数减输的题数至少 2 |
| fail-closed | 拿不准就拒绝/弃权,绝不猜 |
