## §2 裁定问题正反两面

### §2.1 背景与机制（自包含，六条事实）

1. **corpus 记录形态**：RHEA 组分级记录是"底物 A + 共底物 B → 产物们"的净方程——全部参与物在反应物侧**明确写出**（NAD⁺、水、磷酸、ATP、CoA 等；本文称"**已声明共底物**"）。供给面 267 题中 204 题携带此类对象（碳数零否代理统计）。
2. **现行实现**：有共底物的 component 候选一律编译前结构化拒（诚实拒，mimo r31 裁定"满足最低要求"）；检索面 1,323 条候选在该拒因下。
3. **诚实表示的判分后果**：若按设计书选项 a 诚实放行——B 进事件反应物侧参与物（role=cosubstrate）、B 来源整组分产物以声明式拷贝进产物侧、中心 unknown——事件两侧相对参考边均为超集，落 `matched_participant_coverage_partial`。**rank 只认 matched_strict，partial 不进 hit@K**。
4. **P1 参与物集合语义（冻结判据）**：事件与参考边双侧参与物 state_ref/state_id **集合**相等 ⇔ exact（matched_strict）；事件多出组分 ⇒ superset ⇒ partial；少写 ⇒ partial_subset ⇒ partial。
5. **参考边剥除口径**：参考图提取时系统性剥除无机/辅因子（r28 请求 P3 口径）——单底物题参考边 from={A}、to={剥除后产物}。事件协议则要求完整产物集。**两边都自称"完整集合"，含义不同**。
6. **r28 A1 错配定性（已裁）**：partial 桶的归类是"诚实正确的"；错的是把 partial 读成模型错误——这是"参考图声明语义 vs 判分比较语义"的口径错配，**不是模型错**；但主口径 hit@K 在此口径下实际测的是"模型对提取口径的服从度"而非净反应预测力（r28 A1 误导风险，原文）。

**裁定对象**：预注册新字段 `co_substrate_participant_tier`，P1 比较时豁免"已声明共底物"（反应物侧）与"其来源整组分产物"（产物侧）——比较"净共底物"参与物集合（设计书 §9.2 语义草案）。**该变更触碰 P1 冻结口径邻接面**：判据正文或评测语义的任何改动须走 ppv1-criteria-v2 起的新版本流程（冻结稿"冻结后变更"条款）；本文件只是裁定请求，不构成任何现行批的判分依据。

### §2.2 正面（解锁论）

1. **204 题供给面的 strict 通路（唯一路径）**。设计书 §4.1 选项 c 原句："唯一能让 204 子集回 strict 的路径"。工程侧已证穷尽（§一）：不触碰判据无解；这是 43 题缺口（119−76）面前仅剩的口径级手段。辅以量化上界提示：204 题中部分题可能已有 strict 供给（同题双形态，r28 B4 位次效应），豁免收益须分离"纯位次效应/新覆盖效应"。
2. **P1 的"声明完整"版本——写全不是漏写**。事件如实声明了记录净方程的全部参与物（组分级供给的完整转写）；参考边没写共底物是**参考侧提取史的口径差**，不是化学差异（r28 A1：错配定性"不是模型错"；r30 G2：参考边剥除是提取口径）。现行 P1 把"写全"判 partial、把服从剥除口径的简写判 strict——保守方向正确（r28 A1 同意 partial 归类诚实），但作为主口径时**指标与化学脱钩**：诚实转写净反应的候选永远拿不到 strict，反而省写共底物的候选可以。这是 r31 H1b 点名的激励倒挂（声明=罚、省略=赏），方向上鼓励判分面与化学诚实度对齐。
3. **与 r28 T1′ 的边界关系：互补不冲突，但必须一致不重叠**。T1′（coproduct_ignore_tier，proposed 未实施）管**产物侧**：忽略档只作用于事件产物侧多出的无机小分子差集（白名单+元素可追溯）；本裁定管**反应物侧**：已声明共底物参与物的豁免。两者覆盖的侧面不同，互补成立。但注意两处真实交叠：①数学上单侧豁免到不了 strict（exact 要求两侧集合同时相等，r32 CS4a 证）——所以本裁定天然是双侧的（反应物侧 B + 产物侧其来源整组分），**产物侧那半恰与 T1′① 的作用面重叠**：同一名产物组分（如 B 来源的无机小分子整组分）在两个档下的待遇必须一致，不能在忽略档里"可豁免"、在共底物档里"不可豁免"（或反之）——边界须联合定义。②r32 CS4-2 已标记读法分叉（设计书 D-T1′-3"声明参与物与忽略差集互斥" vs T1′①"extras 定义含声明拷贝"）——两种读法行为相反（诚实声明水的 strict 可达性相反），**必须在 T-1 裁定记录中二选一落死，不得留给实现者**。
4. **与长线方案的关系（豁免是过渡件不是终态）**。r28 C1 ⑤ / 设计书 §9.3 已登记根治路径：参考图提取对每边显式声明 `omitted_coproduct_scope`（剥了什么），判分只豁免参考**自己声明剥掉**的那类——两侧口径对齐后豁免不再被需要（r32 CS6a："正确的修复路线自动取消该需求"）。本裁定若立项，正确定位是**以参考侧落地为退出条件的过渡件**（r32 CS6-4 退出条款），不是对 T1′/参考口径的替代。

### §2.3 反面（风险论）

1. **以放宽换通过——三轮评审反复设防的滑坡高发带**。本裁定的方向正是 r30 G4-2 警告的原句滑坡："反应物侧豁免有机共底物 = 系统性主张'脱氢酶反应不需要电子受体'"。r28 T1′② 已明确设防：**反应物侧仅 H₂O 特例**（溶剂活度 ≈1，净反应簿记噪音），其余反应物侧无机（O₂/NADH/NH₃/Pi）一律不豁免——理由是"**共底物 = 机制主张**"（r28 A2）；有机共底物更不在任何已裁定豁免面内。辅因子侧 r28 A6 裁定更硬：辅因子（AMP/ADP/ATP/NAD(P)(H)/FAD/FMN/CoA/THF）**恒不忽略**，"留在 partial 是对的，它们是目前判分里少数还有效的机制信息压力"。本裁定若把已声明共底物（大头正是 NAD(P) 系：组分级频次 1,138+245+111 次）拉进豁免面，等于正面推翻这三道已裁边界——除非 teacher 明确改判并说明判据依据。
2. **r32 CS4 激励倒挂（豁免后"多写共底物"的供给激励）**。现状倒挂：声明共底物 = partial、省略 = strict 可达（r31 H1b；r32 CS2-2 的同句披露义务——同一"酯→酸+醇"化学，corpus 面（记录写了水）拒、EAWAG 面（没写水）照旧 strict 可达）。**豁免落地后倒挂翻向**：声明 = strict 可达——"给候选挂共底物"成为洗 partial→strict 的最便宜供给动作，模型/供给侧会系统性倾向多写。主闸是白名单内容：实际滑坡方式就是"往 `exempt_identity_hash` 里加一个身份"（r32 CS4a 风险 1："文本封死 + 一台未装配的机器"），必须配机器挡板（含碳身份构造非法断言 + 辅因子硬拒绝表，R32-CS4-1）。且 r32 CS6-3 风险 3：短线档先落地、长线方案（参考侧声明）无限期挂起——豁免档的存在本身给"参考侧不要动了"提供惯性，激励倒挂被永久化成"靠每批 teacher 裁定维持的平衡"。
3. **post-hoc 性质（已裁条款点名）**。该档是在看过 partial 分布（v1 15 题、v2 40 题、38/40 超集迹象）之后提出的——r28 C1 ④ 原文点名"教科书式 post-hoc"。首批生效批的数字必须以"敏感性表 + post-hoc 标签"并列披露，**不得回填/覆盖主口径 headline**；headline 恒为现行口径直到裁定与新批生效（r28 C2：未裁定期双口径并列不得作默认）。
4. **对老口径历史锚的解读影响**。主口径序列（v1 39 → v2 29 → chain10 73 → chain11 76，298 题域）全部在 P1 语义下测得，是"排序修复+供给工程"两条工程线的归因账本。口径变更后：新旧数字不可比（同批须双口径标注）；v1/v2 历史 partial 的成因归因（postmortem §1.5 定性"口径级问题，teacher 裁定项"）**事实不变但叙述更新**——从"挂账待裁"变为"已裁口径的旧口径痕迹"；若豁免面较宽，76/103/106 作为"工程天花板"锚的解读被稀释（该天花板是 P1 语义下的天花板）。
5. **量级不可外推（诚实上界）**。204 是碳数零否的**代理统计**，不证明 204 题已 partial、不证明全部无 strict 通路、不可外推命中（Codex v4 复审 §6 订正）。三层折损在案：①整组分/键合二分占比 **unknown**（1,323 内，CS2c 探针未跑——只有"整组分贡献+来源字段完整"的子集是豁免可达面，键合贡献子集在现行执行契约下无诚实表达、继续拒）；②豁免清单窄度——若辅因子按 r28 A6/r32 CS6 不进清单，高频大头（NAD(P) 系 1,138+245+111 次频次所对应的记录族）被排除，可达面显著小于 204；③同题已有 strict 供给的部分是纯位次效应非新覆盖（r28 B4）。**"119 可达"不可承诺**——本裁定是唯一口径级手段，不是充分手段。

### §2.4 一句话对撞

正面说：partial 桶里锁着的是**写全了净方程的诚实候选**，锁它们的尺子量的是提取口径服从度。反面说：豁免它们等于判分面宣布**这一类机制主张（电子受体是谁、共底物是什么）不再计入判定**，而这类主张恰是现行判分里仅存的机制信息压力（r28 A6）——且豁免档一旦落地，供给侧的最优策略就从"写全"滑向"给每条候选都挂共底物"。两面的证据都是仓内程序+评审证据，采信到互证为止。

## §3 裁定选项（三档）

> 以下各档利弊如实并列，不预支结论。**仓内工程侧倾向**（标明：工程倾向、**非化学裁定**）：设计书 §十一/§十二 T-1 默认档为"暂不立项"（先落选项 a 观察 partial 分布；登记为"主会话默认、待用户/teacher 随时改判"）；mimo r32 对 T-1 不预支批准，且对辅因子进豁免清单持明确否定（CS6a："类别错误"）。teacher 的化学裁定权不受工程倾向约束。

**a) 不立项（维持 partial，观察首批 D2 分布）**
- 内容：判分面零变更；设计书选项 a（整组分声明式拷贝 + 键合保守拒）照常落地，204 题中整组分子集解锁为**诚实 partial 供给**（不进 hit@K）；观察首批 D2 批的 partial 通道归因分布、CS2c 探针（1,323 四分类 + 题级 distinct 覆盖）跑出后再议。
- 依据链：r28 A1（partial 归类诚实正确）+ r28 A6（辅因子留在 partial 是有效机制信息压力）+ r30 G4-2（滑坡警告）+ r32 CS6（长线正解在参考侧）。
- 代价：204 题缺口持续锁死；hit@1 停在 76±，119 线本轮不动（除非 v4b 编译墙另线兑现——那是另一面墙，与本缺口正交）。

**b) 有条件立项（沿设计书 §六/§九四元组 + r28 T1′ 九条件式护栏）**
- 内容：预注册 `co_substrate_participant_tier`，四元组 = tier + exempt_identity_hash（cn 身份层版本化哈希，**豁免身份集逐项 teacher 拍板**）+ direction_policy（双侧绑定：反应物侧已声明共底物 + 产物侧其来源整组分；H₂O 反应物特例 carve-out，R32-CS6-2）+ traceability_switch（r28 T1′⑦ 恢复，R32-CS6-1——设计书 §9.1 曾以披露开关顶替追溯开关，r32 判为与已裁条款冲突）。豁免范围**仅限**"来源记录字段完整 + 声明式拷贝 + 中心 unknown"的共底物事件；无来源字段的共底物声明永不豁免。
- 条件清单（r28 T1′ 九条件式，逐条）：
