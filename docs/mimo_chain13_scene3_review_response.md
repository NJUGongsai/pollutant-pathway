## Q1（氰醇事件的化学读法）

**(a) 结论：成立（附底物范围注记）。**

化学论据：执行输入 `CCC(C)=O.C#N`、产物 `CCC(C)(O)C#N` = 丁酮的氰醇（2-羟基-2-甲基丁腈），原子完全闭合（C₄H₈O + HC≡N → C₅H₉NO，纯加成不造不丢原子）。酮/醛 + HCN → 氰醇正是羟腈裂合酶（HNL/oxynitrilase，EC 4.1.2.10/4.1.2.11）类反应，RHEA 收录 HCN 参与的 HNL 反应，净反应类别读法成立。注记：HNL 天然方向多为氰醇裂解（氰苷防御），底物偏好醛，酮类氰醇酶法较窄（工业丙酮氰醇是碱催化）——"对应 HNL 类反应"作为净反应类别成立，"该酶天然就干这个"不要过度读。
另一层（与 Q3 呼应）：C#N 并入产物 = 正是"共底物键合贡献"形态，本例编译成功说明**映射机械能证明归属时门是放的**；且 C#N 属 T1′ 恒不忽略族 + 含碳被零碳断言挡在豁免面外 ⇒ 氰醇事件永远不可能被 v2 洗成 strict，它只具诊断价值、不产覆盖。

**(b) 结论：认可（且面貌表让保守读法更站得住）。**

化学论据（我核对 attr JSON focus 行）：原命中面貌是"胺化产物 `CCC(C)N` + 丙酮共产物 + O"三件套；chain13 里**胺化产物本身还在**（`CCC(C)N` + O），丢的是丙酮共产物，同时新增氰醇事件、丢一个酯面貌。丢丙酮共产物与"供给介入"没有因果关系（供给只往执行输入加了 C#N），只能归扩展/采样面变化；新增氰醇面貌才是供给介入的直接产物——**两个因子各有实证、各自独立在场**，多因素叠加、不单因子定责是唯一诚实读法。无重复批对拍，逐题定责不可能（报告已如实声明，同意）。

**(c) 结论：部分成立——"记 partial"和"视为错答"两个选项都不对。**

化学论据：本口径 partial 有精确定义（与参考边的子/超集关系，预注册 §二原文），"合法但不同"（面貌与参考边不相交）挤进 partial 会把"部分命中"稀释成"化学上说得通"；而本协议根本没有"错答"判分态（零 LLM 集合比较，无罚分轴），氰醇在化学上合法，叫它错答是化学上错误的措辞。正确做法：分数口径不动（不贡献覆盖 = uncovered face），**加诊断标签 `legal_alternate_face`（合法但非目标面貌）**与幻觉/化学非法事件区分开供归因；若想奖励化学合法性，开独立指标轴（客观价态/配平检查），不与正确性混轴——混轴会被"刷合法小反应"钻空子。场景 3 纪律：以上均为下一轮预注册候选，不改本轮冻结判定。

## Q2（H₂O 豁免未触发的排除逻辑）

**结论：部分成立——作为"可能性收窄"有效，作为"排除"不成立；你们自己给的反例确实击穿它。**

化学论据：
1. v2 触发是窄条件（预注册 §二/§三原文，我核过）：事件须 **superset 形态**（partial_subset 缺物种恒不救）+ 每个 extra 按**身份+侧+角色**三谓词全过（pred1 声明链可判且真 / pred2 元素账 / pred3 身份在集）+ **事件级全部 extras 都 v1_exempt**（任一非豁免即一票否决）。非触发至少有五种原因：缺物种、同事件共存别的非豁免 extra、pred1 unknown（链缺席/悬空/方程缺）、侧/角色错绑、pred2 fail（无中生水）。
2. **反例成立**：缺口 = 另一事件上无声明链的 H₂O 多余物 ⇒ pred1=unknown fail-closed ⇒ 不触发，但缺口恰恰在共底物参与物面上 ⇒ "未触发 ⇒ 缺口不在共底物面上"在该情形为假。且更糟：即使缺口在共底物面上，若是**机制身份 extra**（如 NH₃/C#N 同事件共存）也会不触发——所以"在不在共底物面上"都可能为真而不触发，只是不在"可豁免的那一类"上。
3. 本例旁证（attr JSON focus 行，我核过）：RXNG_654cc41… 4 个事件中**仅 1 个**带 cosub 参与物、`provenance_records`=1 ⇒ 其余 3 事件大概率无链；"本事件带链"≠"判决定键的事件带链"。且"链可解析"≠ pred1=true（还须同侧集合含该 cn + 角色一致），"可解析"只排除了 unknown，没证明 true。

## Q3（键合融合贡献保守拒的边界）

**(a) 结论：部分成立——拒绝本身化学上对，边界落点错了半步。**

化学论据：
1. **例子先校正**：PLP 暂态共价**不进净反应**（PLP 循环再生、净方程不出现），不是本门靶子；贴切的是**净键合转移**——SAM 甲基并入产物+SAH 离去、THF C1、生物素羧化、乙酰-CoA 乙酰基、糖基转移、转氨中供体氨基酸的 N 转入产物胺。这些确实会被"拆不开=拒"罩住，覆盖盲区是真的（25 件实证）。
2. **"化学上拆不开"是伪命题**：净反应原子归属化学上永远良定义（同位素级记账）；拆不开 = 表示/映射层失败（枚举截断、歧义位点、通配），不是化学不确定。所以边界应划在"**证明得出来 vs 证明不出来**"，而不是"放行 vs 拒绝"。单候选 fail-closed 宁拒不造归属是对的；错在把"机械没证明"当覆盖天花板。
3. 实证对照：本批氰醇（C#N 并入产物）编译成功 ⇒ 能证明归属时就放行；25 件是"证明不出"的部分——需程序证据分辨**真歧义（对称/多位点）** vs **机械缺口（截断/通配/已有映射未消费）**，两者修法完全不同。
4. 风险提醒：无键级证据放行 = 把归属当事实造数据，正是"局部正确不得扩大证明范围"（AGENTS 返工教训 3）的反面；错归属会造出错误产物结构（partial 虚增/覆盖误判）。
5. 预期管理：参考侧若剥离共底物（`omitted_coproduct_scope` 现状），键合贡献事件的多余反应物**永不能豁免**（含碳被零碳断言挡死）⇒ 放行最高到 partial；除非参考方程含该共底物（RHEA 全方程风格）才可能 strict。

**(b) 结论：最小声明面 = 以下 8 条，缺一条即维持拒。**

1. **键级 donor→product 原子映射**（每颗并入产物的原子溯源到共底物具体原子）——pred2 已明注计数级不证键级（known gap 2），计数不够；
2. **余基闭合**：共底物未并入部分必须以明名共产物出现，多重集原子平衡（cosub = 并入 + 共产余基）；
3. 事件级元素账**扩到 C/N/S/卤素**（现 pred2 只有 O/P）；
4. pred1 升级为**带原子映射的记录方程**（identity+侧+角色+映射可解析）；
5. **歧义即拒**：归属不唯一 ⇒ fail-closed，禁"取第一个映射"；
6. 键合贡献身份**永不入豁免面**（含碳已构造性挡住；非碳并入身份如 NH₄⁺ 胺化须确认在不豁免面）——防洗白通道；
7. **参考可见性聚合计数前置**（该共底物身份在参考边出现的题数）→ 设定 U→P 还是 U→S 预期；
8. 逐事件 `bonded_contribution` tier 披露标签（审计）。

**Q3 需补程序证据（列名）**：25 件按子原因分布（真歧义/枚举截断/通配/已有映射未消费）；25 件对应参考边的共底物可见性聚合计数；`donor→product` 映射字段是否存在但未消费（机械现状）；若放行的探针级投影（strict/partial/错归属三桶计数）；豁免面∩键合贡献身份交集断言现状（应=∅）。

## Q4（13 题钥匙重设计方向的风险提醒）

**结论：方向化学上站得住（C 净零+净赚 2 的账我同意读法），但有 6 个风险点，其中第 1 条最重要。**

最容易产生"合法但不匹配参考面貌"事件的化学形态排序：

| 风险 | 形态 | 例子 | 为什么 | v2 兜底 |
|---|---|---|---|---|
| **最高** | 小分子亲核加成 | C#N→氰醇、NH₃/[NH₄⁺]→亚胺/胺化、CH₂O→羟甲基 | 羰基底物在 298 里几乎无处不在，加成类原子闭合、全合法、面貌=**新产物**；本批 S→U 就是它 | **无**（含碳零碳断言；CN⁻/NH₃ 恒不豁免）⇒ 封顶不计覆盖 |
| **高** | 氧化还原对 | O₂→环氧化/羟基化、H₂→还原、H₂O₂ | 机理身份、位点选择多样 | 无（硬拒绝表） |
| **中** | 有机第二底物 | 丙氨酸/谷氨酸（转氨）、2-氧酸 | 真共底物且**可能参考可见**（是收益面），但化学选择性多面貌 | 视身份；我上轮 P1：参考可见性未证 |
| **低** | 簿记四件 | H₂O/H⁺/Pi/PPi | 水合/水解面貌通常参考在含或可豁免 | **有**（声明链+三谓词） |

净负面重演的三条机制（本批全部实证在场）：①执行输入字节变 ⇒ 模型输出分布变（胺化丢丙酮共产物这种与供给无直接关系的面貌重组就是证据）；②池宽固定 8 ⇒ 新候选挤占位次（我上轮坑 5 已预警）；③机制身份无 v2 兜底 ⇒ strict 题原命中面貌一旦被重组，掉下来只有 partial/U、没有豁免回程。

六个风险点提醒：

1. **最大的风险不在 13 题（它们是 P/U，只有上行空间），而在放宽后暴露到 C 线的现有 strict 题**——资格面越宽暴露面越大，S→P/S→U 重演概率越高。放宽前必须先出"新资格面会新开 C 门的现有 strict 题数"聚合。
2. **单变量纪律**：chain13 四变量叠加导致归因困难（报告 §七自认"不能把超额部分单归 C 线"）——重设计轮别再叠新变量，留 A/B 对照（hpc2 34/298 是波动基线）。
3. **先发声明链再放宽**：v2 兜底依赖 pred1，13 题面 provenance 覆盖未知——无链放宽 = 上行打不开、下行照吃。
4. **分族记账进预注册**：按簿记/第二底物/机理类分别记 exposure→面貌变化→S 得失，设停点；不分族会重演"净零但主损失在别处"的归因困难。
5. **硬拒绝表与零碳断言别动**（NAD/ATP/CoA/FAD/THF/O₂/NH₃/CN⁻ 等）——动了 v2 就变洗白通道，触发退出条件（预注册 §九）。
