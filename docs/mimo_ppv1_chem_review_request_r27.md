## 1. 判断面一：S5B-L01 real 档配对守卫（evaluation-5）

## 2. 判断面二：S5B-L02 订正后的口径（请复核订正是否忠实）

### 2.1 老 scorer 老侧行为按**候选包装分形**（订正原"整串≠金标"
单向描述）

- **展平分串**（答卷/复刻表实际形态，每组分一条候选串）：候选
  整串 cn ∈ 金标 cn 集合即命中（any-one）；**额外字符串不破命中**
  （合成例：候选 `['CCO','CO']` 对金标 {cn(CCO)} 老侧 rank=1；
  `['CO','CCO']` rank=2）。
- **点串融合**（一条候选含 `.`）：融合整串 cn ≠ 单组分金标 ⇒ 主
  口径不命中（合成例：`['CCO.CO']` 不中；组分敏感性另表中中）。
- 由此差异表第 4 行（单产物金标 + 事件多报）方向改为：**分串下
  新更严（老 any-one 容忍额外串——新对多报降档是新增更严约束）；
  融合下同向**。"新主口径不含 superset 命中"处置不变，与
  HIT60 caliber v3"超集不破"异向不变。

### 2.2 补两轴 + 细化两行（原差异清单漏轴）

- **K 单位轴**：老 rank 槽=1 条产物字符串；新主口径 rank 槽=1 个
  候选事件（可含多产物）；敏感性表展平后与老同单位（锚对齐
  前提）——主口径 hit@K 与老 hit@K **不可逐档对读**。
- **报告可见性/宽度轴**：老=答卷可报告串（≤5/步）；新主口径=
  全部已提交事件无宽度过滤；敏感性表=投影可报告产物，生产
  cap=`max(1, min(width, 4))`，cap 外 `report_rank=None`。
- **反应物侧细化**：事件反应物侧参与物状态集合须与根参考必要
  节点集合**相等**（非仅"含根"；reactant 超集 ⇒ coverage partial）。
- **多产物跨事件分散**：金标产物分散在多个事件、无任一单事件
  全集 ⇒ 各事件均 partial 不中（分散不能拼成一条严格边）。

### 2.3 None 消费规则写死（原冻结稿最大定义洞）

`report_rank=None`（宽度 cap 外）的投影产物**不进**敏感性表候选
序列：只消费非 None 位次（= 老"答卷宽度上限外的产物本来就不在
答卷里"的最小对齐）+ 被省略产物计数级披露；**不**尾随占名次。
合成互证（复审执行）：投影 `[extra, target]` cap=1 时 extra=rank1、
target=None ⇒ 排除 None ⇒ 敏感性表 miss；尾随 None 则 rank2——
两选一已冻结为**排除**。请复核该选择是否忠实于老口径语义。
