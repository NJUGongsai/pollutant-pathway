## 0. 结论

1. **22 题 onlyA 的分类**：**rank 差 12 题**（B 也 strict 命中，但排第 2/3 位）、
   **未严格命中 5 题**（B 生成了 3–4 个事件但没命中）、**partial 5 题**（覆盖差）。
   **没有一题是调用失败/未形成事件**（22/22 model_calls=1、无 run_error）。
2. **4 题 onlyB**：A 侧 2 题 unmatched、2 题 rank=2——B 偶尔也赢，量级远小于 A。
3. **时间窗漂移证据弱**：两臂输出 token 分布几乎相同（p50 6,793 vs 6,676；
   p90 17,656 vs 17,840）；调用分布几乎相同（A：296 题 1 次 + 2 题 0 次；
   B：294 题 1 次 + 2 题 0 次 + 2 题 2 次）。输入侧 B 更小（p50 4,434 vs 3,547）
   ——这是 v2 卡更小的**预期效应**，不是漂移。
4. **主要损伤在"选择/排序"层**：12/22 是 B 把对的候选排到第 2/3 位；
   这与 P2 预注册的设计假设（证据卡整包会同时改变提案与排名）一致，方向为负。
