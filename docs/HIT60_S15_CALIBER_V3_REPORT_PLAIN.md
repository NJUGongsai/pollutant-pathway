## 一、这次干了什么（三句话）

1. **改了判分规则**：以前模型答"甲醇.磷酸"这种**一条答案里有两个分子**
   的题，机器只拿整串去对标准答案，对不上就判错——明明两个分子都答对
   了。新规则（口径 v3）改成**拆开对**：标准答案要的所有分子都在答案
   里才算对；只对一部分算"partial"（单独记一笔，不算对）；"对了一个
   就算对"（any-of）被老师明令禁止，两边都禁了。
2. **用新规则把所有老考卷重算了一遍并封存**：dev 六批 + 298 两臂，
   全程不花一分钱（零 LLM）、不碰任何封存数据、老数字一个不改。
3. **给题库做了体检**：用四条确定性规则扫了 dev 56 题 + 298 全卷，
   把"题目本身有毛病"的题列成隔离提案——**只是提案**，等人审和化学
   评审点头才生效。

|---|---|---|---|

| dev C0-b | 9/56 | 15/56（26.8%） | 同方向 |
| 298 复测 C0 | 136/298（45.6%） | **136/298（45.6%）** | 老师说 ≈149 —— **没对上，如实登记** |
| 298 复测 D3 | 132/298 | 132/298 | 同上 |

**为什么 298 没涨？**（这是本轮最需要人脑消化的发现）：298 里有一批
题的标准答案本身就是"两个产物"。旧规则下，模型只答出其中一个也算对
（这就是被禁止的 any-of）；新规则把它降级成 partial。同时，多分子答案
救回了 11 题。**救回 11 ↔ 降级 11，正好抵消**。所以 298 在新规则下
@1 不动（45.6%），@3/@5 略降。这不是口径坏了——是老师那条"只对一个
不算对"的禁令在 298 上起了作用。老师说"实际和参照不符时以重刷实测
为准"，我们照办并把差异写清楚了。

**dev 为什么 E1 是 +5、E2-b 是 +4 而不是 +6？** 同一个原因：那两批
旧读数里各有一两题是"双产物题只答对一个"混进来的假对，新规则剔掉
了。剔除的题救回的题都不变，只是把假对摘了。发车前预注册里就把这
个登记了，实测和登记完全吻合。

## 三、怎么证明新规则不会把错答案"洗"成对答案

老师要求做"故意答错"的测试（假阳性义务），我们做了两层，全过：

1. **纸上测试（进测试套件长期钉住）**：故意造四类错答案——缺一个
   分子、多一个错分子、只对一半、全对。错答案全部判错、全对判对，
   22 个用例全绿。
2. **往真考卷里注毒**：在六批真实答卷上做手术——把对的答案删掉一个
   分子（必须从对变错）、给错的答案塞一个错分子（必须还是错）。
   六批 × 56 题全做，**零次洗白**。

有一个边界如实报告：如果答案把标准答案的所有分子都答齐了、**还多带
了一个错分子**，按新规则仍算对（"包含"语义）。为什么这么定：金标通
常只登记"主产物"那一半，水解另一半（甲醇、磷酸这种）模型一起写出
来是化学上更完整的答案，苛求一字不差会把本该救回的题又冤枉回去。
这个边界写进了预注册，测试里专门钉住，报告里有披露列（dev 每批 5 题
属于这种情况）。

## 四、题库体检结果（只出提案，不生效）

- **dev 56 题，5 题有毛病**（和老师说的 3+2 完全对上）：
  - 2 题：答案要用到 CoA，但题目里没给 CoA（模型靠题面不可能答出）；
  - 1 题：答案比题目多了 1 个碳原子（碳不守恒，无处来碳）；
  - 2 题：标准答案就是题目自己（退化题，不用反应）。
- **298 全卷 298 题，26 题打标**（约 9%，和 dev 缺陷率同量级）——
  只打标，分数和金标一个不动。
- 处置建议：dev 这 5 题剔出分母（56 → 51）。**注意：这是提案**，
  等人工审核 + 化学评审（mimo）确认后才生效。生效前主封存仍是全
  56 分母。有趣的是这 5 题模型本来一道都没答对——模型从不复读题面，
  所以剔了也不动分子。
- 剔掉后的数字（仅供参考、标"待生效"）：C0-a 14/51 = 27.5%。

## 六、术语对照表

| 术语 | 人话 |
|---|---|
| 口径 / caliber | 判分规则（怎么算答对） |
| 整串比对 | 把"甲醇.磷酸"当成一整个字符串去对答案 |
| 组分 / component | 点号拆出来的单个分子（甲醇是一个、磷酸是一个） |
| 全主产物命中 | 标准答案要求的每个分子都在答卷里 |
| any-of（禁） | 答对其中任意一个就算对——老师明令禁止 |
| partial | 答对了一部分：单独记数，不算对 |
| scattered | 每个分子都出现过、但分散在不同候选里、没在同一条里凑齐 |
| 超集不破命中 | 答案比标准答案多带了分子，只要要求的都齐，仍算对（已注册的边界） |
| hit@1/@3/@5 | 答案排在第一位 / 前三位 / 前五位之内算命中 |
| 金标 | 标准答案 |
| quarantine | 隔离区：题目本身有毛病的题，提案剔出分母，待人审生效 |
| R1/R3/R4 | 体检规则：答案元素题目给不了 / 碳数变多 / 答案=题目本身 |
| R2 | 答案只多了 O 或 H——水、氧气环境默认供给，保留不扣 |
| 题域标签 | dev 是环境降解题、298 是普通酶学题，两边的数字不能互相推 |
| 锚点 fail-closed | 重算前先复现官方旧数字，对不上就停，防止算错批次 |
| `--check` | 封存后用同样输入重算一遍，必须和封存件一字不差 |
| 双轨 | 同一批考卷，旧规则和新规则各出一份读数，并排看 |
| I1 | 298 只许当参照看，不许拿它调参挑最优 |
| 预注册 | 先把规则写死落盘、再跑数，防止看分改规则 |
