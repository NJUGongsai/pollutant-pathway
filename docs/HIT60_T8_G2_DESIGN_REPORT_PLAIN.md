# T8 G2 守恒过滤:大白话版

> **v2 修订轮(2026-10-05)已追加**,见文末"v2:评审回来之后改了什么"。
> 下面 §一~§红线是 v1 原文,读数保留作对照。

## 一句话结论

按老师批准的设计,我们把"novel 出题后的守恒过滤 + 候选自排序"整条链
做完了:规则写死、代码落地、测试全绿、又在封存的六批旧答卷上免费
"预考"了一遍。**预考结果不达标:两个采样一个 +3、一个 0,离"净赢
3 题"的及格线还差得远,而且那个 +3 有"对着答案补规则"的水分。**
所以建议:**先别花钱跑正式实验**。

## 我们做了什么(五步)

1. **写规则(预注册)**:先把"怎么数原子、什么算违规、什么算拿不准、
  什么情况干脆弃权"逐条写死,连及格线(净赢 3 题、@5 不降、错答/
  空答不升)一起冻在跑分之前——防止看完成绩再改规则。
2. **写代码**:一个纯函数模块(零模型调用),挂在 novel/analogy 出题
  落账的环节,带一个总开关,**默认关 = 和现在的系统逐字节一模一样**
  (有测试钉住这一点)。
3. **防误杀测试**:化学评审列的 11 种"容易把真答案误杀"的坑(脱羧、
  脱卤、成盐写法差异、金属配位、"全矿化"式答案、剔空弃权……)逐个
  造了假例子验证规则行为,29 个测试全绿;全仓 606 个测试全绿。
4. **免费预考**:拿六批已经封存的旧答卷(都是已经过现有门禁筛过的
  答案),离线把新过滤+重排套上去重算分数。原始分数和封存记录逐数
  对上(证明算法没跑偏),金标答案只在本机进程里比对,仓库里一个
  分子式都没落。
5. **交报告**:预注册、逐题表、配置差异表、给化学评审(mimo)的终版
  规则复核请求、本报告。

## 预考发现了什么(重点,如实说)

- **好的一面**:零误杀(没有任何金标答案被硬剔除)、@5 六批全部不变
  (证明"纯重排"承诺是真的)、错答数和空答数一分没动、需要弃权的
  情况一次都没触发(因为现有门禁其实已经比新规则更严)。
- **不好的一面**:把规则拆开量——两根"排序信号"都在**帮倒忙**:
  "碳骨架越界就降位"一根净亏 2 题,"反应类型对不上就靠后"一根净亏
  3 题。原因是老问题:真答案里原子数变化的比例很高,而"看起来守恒
  的错误答案"总是能排到它前面——跟上一轮门 1 的教训一模一样。
- 后来发现规则目录漏了三个常见化学类目(环氧化物水解、醚断裂、
  脱氨),补上后一个采样 +3、另一个 0。**但补目录就是对着 dev 的错
  处补的,这个 +3 不能当独立证据。**

## 建议(下一步选项)

1. **不发车**(推荐):预测在线下,而且证据是单采样 + dev 引导,
  按纪律也不能回头调权重硬凑——改规则就要重新走"评审→拍板→冻结"
  一整轮。
2. 把终版规则送去 mimo 化学复核(请求文件已写好,规则级、不含任何
  题目和答案数据),重点裁四处我们偏离原评审意见的实现细节,和
  "反应类型匹配这根排序信号该不该撤"。
3. 真要出正式判定,费用帽建议维持 ¥6(最省的形态是纯离线重放,
  实际 ¥0);本任务已花 ¥0。
4. 最终的对外结论还是要等新盲测题集;dev 上的数字只当开发期参考。

## v2:评审回来之后改了什么(2026-10-05,依然 ¥0)

**一句话**:化学评审把 v1 打回("不能原样冻结"),列了 9 条必改;
我们全部改完、测试加到 50 个、又免费预考了一遍——**上一轮被误杀的
两道真答案救回来了,读数变成两个采样 +2/+1,但离及格线还是差一点,
所以结论不变:先别花钱,等最后一轮确认。**

### 9 条必改都干了啥(挑重点说)

- **最大的坑(评审排第一)**:老规则只认三种"断键花样",导致教科书
  里最常见的几类反应——有机磷农药水解(毒死蜱)、菊酯水解、糖苷
  水解、大酯/肽水解——全被当成"碳丢了"压到后面,连真答案也被压。
  v2 换成"看缺口能不能拼回一个真碎片":先查三种老花样,再查一张
  小碎片清单(CO₂/HCN/甲醇…),最后干脆在底物上"剪一刀试试"
  (只剪碳-杂原子键,最多同时剪 4 刀,超时就老实说"算不了"并压后,
  绝不瞎放行)。
- **"唯一产物"关键词**:老规则用子串匹配,"降解不完全"里的
  "完全/complete"会被误当"声明完整"然后硬删答案;v2 用词边界 +
  否定词回看,还补上了"矿化/彻底降解/fully degraded"这一族说法。
  硬删只发生在"声明完整 + 确实少了原子 + 缺的部分拼不回任何碎片"
  三件事同时成立时。
- **排序信号瘦身**:老规则把"规则目录里没见过"当成减分项——目录
  没覆盖不是人家的错;v2 只有"底物明明没有这类基团、候选却硬说是
  这类反应"这种真矛盾才减分,没见过的中性处理。还补了环氧化/
  S-氧化/N-氧化三个常见类目。
- **增侧干脆声明不用**:既有门禁在答案路径上比新规则更严,新规则的
  "增原子就删"永远轮不到触发(六批旧答卷 0 触发是证据)——写死成
  "惰性",供体表降级成参考资料。这一条是二选一,我们选了保守的
  (a),**等用户拍板**。
- **修了两个真 bug 性质的口径**:不饱和度(DoU)算法对含磷农药会算出
  半整数(毒死蜱按新算法=5,正好是环+磷硫双键),改成按分子图算;
  去盐从"只剥单个带电原子"扩到"也剥甲酸根/硫酸根/三乙胺这类带电
  大离子"(只要主体碳更多)。
- **账本补齐**:剔空弃权和"底物解析不了"分开记账并带删除数;档位
  优先级(删>压>弃权)写死;规则目录从"写着 25 条实际 27 条"对齐成
  34 条逐条可数,补上氨基甲酸酯/脲/磺酰胺/膦酸酯/季铵/过氧化物等
  环境降解常见类目。

### 新预考结果(六批旧答卷,免费)

| | v1 | v2 |
|---|---|---|
| 两个采样 @1 | +3 / 0 | **+2 / +1**(加起来一样是 +3,但两边都是正的、一道真答案都没伤) |
| 被误杀的真答案 | 092/101 两道被压到第 3/4 位 | **两道全部回到第 1 位**(四个 E 批也一样) |
| @3 反压 | −1~−2 | 清一色 −1 |
| 降位数 | 16/18 | 6/6 |
| 误杀金标/空答/错答数 | 0 | 0(全部持平) |

**要坦白的一点**:v1 那个 +3 里有一题(125-S08)其实是运气——老规则
碰巧把一个"缺口其实拼得回来"的错答案压下去了;v2 按化学道理把它放
回来了,真答案回到第 2。也就是说 v2 的放行是对称的(能救真答案也能
救错答案),v1 的 +3 有水分。两版加起来都是 +3,但 v2 的分布更健康。

### 还差什么(为什么还是"先别花钱")

1. 读数还是没到及格线(净赢要 ≥3、错答降要 ≥3;现在 +1.5 均值、
   错答降 0)——不过这些数字本来就是"对着开发集调规则"之后的自测,
   不算数,正式判定要等新题;
2. 增侧惰性这条的选择 (a) 等用户拍板;
3. 给 mimo 的最后一轮确认请求已写好(`docs/mimo_g2_v2_confirmation_request.md`,
   只讲 9 条怎么落的 + 新读数,不含任何题目答案),等回复 + 用户
   拍板才能冻结。
