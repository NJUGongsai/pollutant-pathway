## 4. 工作线（P0 → P3，有先后关系）

### P0：补齐关键诊断（先做；不改候选、不改提交顺序、不改原判分）

直接复用已完成 Stage 0（120 题已核对：32/41/47 分组；32 个 strict matched 事件无 fallback；
覆盖组的模型自评不能代替评分缺口）。新增四个工作包：

| 包 | 内容 | 验收/交付 |
|---|---|---|
| **P0-A 候选谱系** | candidate→prepared hypothesis→action→event→评分位次；新增排名**原始来源**、通道、折叠与拒绝原因 | 覆盖全部 298 的可用条目；计数闭合；旧资料缺项写 unknown，**不伪造显式 rank** |
| **P0-B 产物对账披露** | 声明产物 vs 执行碎片 vs execution expectation；按 origin、首位/后位汇总；适用/不一致/unknown 分开 | 合成正负控：多碎片、合法 copy、立体差、明确矛盾、解析失败；**原提交与判分不变** |
| **P0-C 评分缺口诊断** | 53 partial 与 119 unmatched 分开；必要节点 gap、两侧 extra/missing/mixed、豁免原因、scope 独立统计 | 用冻结 scorer；**不拿模型自报 partial 推缺口**；聚合能回对既有桶数 |
| **P0-D 供给漏斗** | 检索命中/超阈/截断、F3/F5 预门跳过、真实编译失败、remap 加/减/未尝试/失败、执行失败、去重与预算 | 保留旧 reason 兼容字段并增加细分维度；**选中候选身份与顺序不变**；分别报 spec/题/事件分母 |

**P0 完成门（future acceptance，本轮未执行）**：在独立复制/隔离环境，用冻结历史输入与
已保存模型响应等载荷、冻结 scorer 做诊断开关回放；**排除新增诊断字段后，候选成员、事件、
位次及判分语义零漂移**，并复现 **hit@1=89、strict=126、partial=53、unmatched=119**。
此门不重新调用模型；新模型运行按配对统计验收，不要求逐事件相等。

> **成本口径**：零模型 ≠ 零成本。仍需计算、存储与工程时间；不得对外写“零成本”。

### P2：第一个选择层实验（优先证据卡 v2）

理由：32 个非空池排序题已有 strict matched 事件，排序元数据已核过；证据卡 v2 有**已放行、
已冻结**的设计合同，所需改动比凭来源优势另造 ranker 更明确。

**按现冻结设计实施，不重新打开 v1**：删 Gasteiger 与冗余来源/数组呈现，保留真实参与物，
增加限定主产物 scope 的 FG 类集合 delta 等；不得把 unknown、行数或系数改成假信息。

| 项 | 冻结要求 |
|---|---|
| 先决条件 | 通过 v2 实施审与既有化学评审；真实 tokenizer 离线测量；schema/descriptor/prompt/RDKit 身份登记 |
| 唯一变量 | 同一模型、建池输入、判据及配置，比较证据字段方案；两臂按冻结任务书共用新版 prompt，novel 输出允许随输入改变 |
| 明确解释 | 这是**整包证据呈现实验**，可能同时改变提案与排名；不能称纯重排因果，也不识别单字段贡献 |
| 已有门槛 | 离线 token 增量 ≤13%；全局或任一分族 v2 strict 净失 ≤−3 既有停点优先；预注册冻结“v2 的 novel 首选占比不劣于 A”，按解析规范化后首位计、分母全部 298，弃权/无首位留分母不入分子；hit/strict 优先，不靠来源配额过线 |
| 主读数 | 全部 298 题配对新增/损失/净增、hit@1、strict、rank>1、分族、调用失败及实际 token/usage |
| 后续决策 | 有正向线索再确认；无收益按四象限如实收口，不通过连续改字段追同一批分数 |

- **recorded 优先 = 待证假设，不是本轮动作**。49% 对 24% 来自不同题群；历史“14 题在场未排首”
  不能迁移为 T-H 上限。只有 P0 给出**可在预测时取得的新信号**，才构造候选排序规则。
- 固定历史事件的零模型重排**仅用于探索**；必须复现原顺序基线、固定事件集、确认 strict 总覆盖不变；
  评价全部 298 题，不能只在 32/37 个失分题上展示提升。

### P3：覆盖与供给（按证据拆项，不按拒绝条数排投资）

不能只修一处消费点。电荷操作、立体设置、对齐降级、多对齐、remap 扩触发均为**新候选项**，
只有证明具体能力缺口才排期。

## 5. 判据研究：v3 归一（另立测量议题，不做提分快刀）

v3 当前 **47 个适用配对**中，**13 对获互变轴归因、10 对获质子化轴归因**。
这些数字支持研究表示差异；**不证明化学个体相同、整个参考边可 strict、候选恰在首位或净增 23 题**。

若另立新判据，最低需要：

| 关口 | 必须闭合的内容 |
|---|---|
| 化学语义 | 同一母体的质子化归一 ≠ 同一完整离子物种；互变、原子手性、E/Z 逐项界定 |
| 立体保全 | 当前 sp3 保留臂仍可能擦除 E/Z；未核范围保持非 strict，默认互变臂不具 strict 资格 |
| 两侧同源 | 参考/预测同算子、同参数、同引擎；不能只在生成侧改写后假称 strict |
| 完整计分 | 去重题数 → 必要节点完整覆盖 → 边 exact → 首位；不能用配对数代替题级收益 |
| 版本与对照 | 新旧判据并列、旧成绩不回写；正负控与正式裁定后才冻结新版本 |

**相反立体或仅缺失立体不直接升 strict；T1′ 也不作为本轮提分捷径。**
