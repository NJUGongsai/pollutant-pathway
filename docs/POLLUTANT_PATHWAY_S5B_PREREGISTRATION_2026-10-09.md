## 3. 参考边转换规则四面（冻结；mimo r25 收口 #1/#2/#4/#5/#7 全部落字）

1. **step_scope = `net_reaction`**（mimo r25 有条件同意）：
   - 规则文字：源记录为数据库方向化总包反应（RHEA/EnzymeMap/
     BRENDA master/directional），非基元步；标 elementary_step 属
     机理过度声明。**本字段只声明净转化口径；参考边不附配平与
     守恒声明**（`coefficient_status=unknown`，不作元素/电荷/电子
     供体计量声明，不构成守恒已核）。
   - **逐题例外规则**：转换时若发现某源记录实为多酶/多步拼接才
     成立的复合转化，该题标 `multistep_summary` 或 `unknown`，
     不强行全卷统一；例外题数按计数披露（各源记录是否全为单步
     未逐题核，如实披露为未核）。
   - **命中前提披露**：评测器要求存在一条同时命中 from/to 侧的
     候选事件（必要节点覆盖）；**纯基元步分解、没有任何净形事件
     的输出在本口径下不命中**——这句写进 coverage_statement，
     不让"不要求机理对齐"被读成"任何路径形状都算命中"。
   - **不得滥用**：`step_scope` 一致轴不得当作任何机理/机制覆盖
     证据（生产侧默认也是 net_reaction，一致率近乎常数对常数；
     audit 侧对 net_reaction 直接 CHECK_VERIFIED 的事实如实知悉）。
2. **共同产物与角色：全部金标产物 = `principal_product`（+未区分
   披露）**（mimo r25 (a)+(c) 有条件同意）：

     该边 `to_node_ids`（判分按必要节点集合严格命中，S5A-03）；
   - 固定披露句："本卷金标无角色标注，全列主产物是**口径选择，
     不是化学认定**；小分子共产物不豁免召回"；
   - **禁止**按元素/大小启发式降级任何金标产物为 coproduct；
   - 相同结构的共同产物（对称裂解）按**结构集合**匹配，**份数不
     在判分面**（一份预测 state 可同时严中两个 occurrence 节点；
     不得据参考图声称模型漏报第二份）——coverage_statement
     披露。
3. **participant_list_status = `partial` + 固定披露句**
   （mimo r25 同意）：
   - 固定披露句："参与物 = 提取后的含碳组分；辅因子/共底物

   - 逐参与物 `coefficient_status=unknown`。

   （mimo r25 同意）：
   - 节点/边 status=`reference_only`、`evidence_basis=

state 可严中两个 occurrence）——共享盲区披露，不进差异表。

**结论（S5B-L02 限定后）**：在**命中存在性**（同输出能否中）与
**指定报告映射**（§5.4 None 规则写死后的事件投影展平映射）层面，
新主口径相对老官方主口径系统性更严（身份、金标覆盖方向、事件
双侧结构、step_scope 四轴），宽向不存在。**该"更严"不外推到
hit@K 的逐档数字**：排序源差、K 单位差（事件槽 vs 字符串槽）、
候选输入宇宙差（全部已提交事件 vs 答卷/投影可报告串）可使任一
档数字双向移动——两口径逐档差只按上表清单解释，**不作"逐 K

1. **不得宣称"参考边召回 hit@K 与老 hit@K 同构"**（prep §5 第 1

   superset 命中**（superset 一律落 `matched_participant_coverage_
   partial` 披露桶）。与老官方主口径的关系**按候选包装分形**
   （S5B-L02 订正）：展平分串下新更严（老 any-one 容忍额外串——
   新对多报的降档是**新增的更严约束**，不是旧官方也惩罚多报）；
   点串融合包装下同向；与老 HIT60 caliber v3"超集不破"异向——

### 5.3 通过线（冻结；S5B-L02 订正口径列与四象限规则）

### 5.4 老口径敏感性表（第二口径，必报，冻结定义；S5B-L02 补
None 消费规则与两处纠错落字）

- **用途**：与 116/128/130（首轮）/ 136/182/186（复测 C0）历史
  锚**同口径可比**；把"达到老系统首轮水平"的判定落在与锚同口径
  的数字上。
- **判据（复刻 v43-ec298-scorer-2 官方主口径）**：
  - 候选序列（每题）= 该题配对导出的候选事件按 §5.2 报告序，逐
    事件取其**报告投影产物**（`report_projections` 的
    `product_ranks` 按 `report_rank` 序）的产物 SMILES 展平——
    单步题即"该题有序可报告产物"的新系统对应物；
  - **`report_rank=None` 消费规则（冻结写死，S5B-L02；不得留给
    得分后实现临选）**：`report_rank=None`（report_width_cap 外）
    的投影产物**不进**敏感性表候选序列——只消费非 None 位次的
    可报告产物（= 老"答卷宽度上限外的产物本来就不在答卷里"的
    最小对齐）；被省略的宽度外产物**计数级披露**（逐题省略数 +
    总数），不尾随占名次、不当命中。合成互证锚（复审 caliber
    专项）：投影 `[extra, target]` cap=1 时 extra=rank1、target
    =None ⇒ 排除 None ⇒ 老敏感性表 miss；若尾随 None 则 rank2
    ——两选一必须冻结，本稿取**排除**；
  - 逐候选整串 `cn_identity` ∈ 该题金标产物 cn 身份集合 ⇒ 命中
    （任一相等即中，首中位次）；不可解析候选占名次不命中
    （复刻表内候选全部经状态契约，该规则实际不触发，对称保留）；
    **重复身份跳过**沿老 scorer 判分处 `seen` 规则执行——**投影
    helper 本身不自动去重**（复审 §6 mimo 纠错互证：
    `build_report_projection(['a','a','b'])` 实给 1/2/3、重复共产物
    保留重复 refs；docstring 是调用方输入前提）——**不采纳
    "投影先去重再排名 ⇒ 固定乐观偏差"断言**，去重语义只发生在
    判分处且与老 scorer 同向；
  - 分母 298 固定，空候选/失败全算未命中。
- **宽度/cap 披露（如实）**：生产侧投影 cap = `max(1, min(width
  if width>0 else 1, 4))`，与老答卷 ≤5/步**不同源**——cap 外产物
  进不了复刻表（对老可报告宽度为悲观向，如实披露）；`width` 为
  冒烟后冻结值，本稿不预支数值。**cap ≥ 金标最大产物数（3）不是

  matched_strict、其可报告金标产物仍可给老 any-one rank1——
  cap<3 只影响"全部金标产物可报告"这一用户可选披露项，不影响
  两侧命中存在性）；若冻结的 width 使 cap<3，确认读时按可报告
  性角落显式披露（主口径命中而敏感性表缺该金标串的可能角落），
  不新增强制 cap3 科学门。
- **多组分 any-of 敏感性（第三张表，沿老规矩）**：含 `.` 候选任
  一组分 cn 命中即中——只作探索性另表，不与主分/敏感性表混算。
- **不进主结论**：敏感性表数字不用于通过线判定的主口径主张，
  只用于历史锚对齐表述；两表差异按 §5.1 清单解释（K 单位轴：
  敏感性表展平后与老同单位，是锚对齐前提）。**CN 旁证防护句**

  不得被读成"CN 命中即化学正确"（判据五"旁证不叠加升格"精神在
  评测报告层同样适用，不升格）。

## 7. 独立性与置信区间（冻结；mimo r25 收口 #8）
