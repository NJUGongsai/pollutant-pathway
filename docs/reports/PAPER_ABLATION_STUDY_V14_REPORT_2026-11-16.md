- **与单路臂的逐题交叉记录（描述性事实）**：这 `61` 题在单路 `DB-2 NoSelf (all)` 中命中 `45 / 61`（按 `DB-2 ex-self` 命中 `20 / 61`），在单路无池 `T1-0 bare` 中命中 `39 / 61`（`T1-0a bare+门` 命中 `37 / 61`）；全集 `261` 题上，`DB-2 ex-self` 独胜 `T1-6 ex-self` 的 `26` 题中有 `20` 题在 `T1-6 all` 原居 Rank 1，`T1-0 bare` 独胜 `T1-6 ex-self` 的 `46` 题中有 `39` 题在 `T1-6 all` 原居 Rank 1。
- **方法学结论**：上述交叉仅说明“含 `rec-` 池上的事后 `ex-self` 因同义候选去重而不可直接当作无记忆泛化率”，因此**评价真实无自记录能力必须看输入端 `self=0` 的实测干预臂**——单路层面看 `DB-2 NoSelf`（`single-route`, `all=96 / ex-self=69`）与 `DB-6 MNXOnly`（`single-route`, `102`），全系统层面须待配额恢复后补入 `T1-6 NoSelf`（`11-pass, self=0`）实测值。
