# 化学评审请求 — novel 产出守恒过滤的判据（v4.3 HIT60 S1-R2a）

你是独立的生物降解化学评审人（环境化学/微生物代谢方向），与系统作者无
利益关系，直言不讳。这是 E1 排序臂评审与金标规则评审的延续；本轮评的是
**生成链路的确定性守恒过滤器判据**，不需要题目数据。请用中文作答。

## 一、背景（三句话）

我们的 agent 在无检索证据时会走 novel 生成（自由提案 5 个产物），上一轮
评审你已指出其失分根因是"确定性约束被卸掉"（无守恒检查、模型从常见代谢物
里挑）。现在要在 novel/analogy 的**产物验证环节加一层确定性守恒过滤**：
规则由代码从题面分子直接算出、零 LLM；违反者剔除或降位。规则冻结前请你
评判判据。

## 二、三组判据与我们的默认答案（请逐条挑战）

**G1 ΔC 允许集**：单步酶促事件里，产物总碳数相对题面只能
{不变, −1（脱羧/脱羰）, −2（β-氧化切 2C）, 按口径登记的裂解（一变多）}；
碳数增加一律违规（除非题面/条件提供碳供体）。
➡️ 请挑战：这个集合对"一步"是否完备（有没有漏的合法减碳场景——异构化
不变碳、脱甲基算 −1 还是裂解、丙二酰类 2C 单位转移要不要算供体）？
裂解类怎么写才可判定（C10 → C6+C4 与 C10 → C7+C3 都要放行吗，还是
只按已登记金标口径放行）？

**G2 杂原子增删白名单**：单步新增杂原子仅限 {O, H}（O₂/H₂O 来源）；
N/S/P/金属的新增一律违规（题面含共底物登记时除外，如 CoA 硫酯化）；
杂原子**减少**按具体反应类型判（脱卤、脱硫、脱氮各自的合法场景）。
➡️ 请挑战：白名单外有没有环境可默认的新增（硝化引入 N？硫酸化引入 S
在微生物降解里真实出现吗）；减少侧的合法清单怎么写（脱卤素是"减 X"，
还有哪些"减 N/S"是真实单步）？

**G3 可进攻位点白名单**：给模型/过滤器的"题面哪些位点可被一步进攻"标注。
我们担心纯代码算不出电子/位阻（你的上轮意见：判据应落在被进攻原子的
电子云/位阻 + 酶类区域选择性，不是产物整体像不像）。
➡️ 请给建议：确定性近似能做到什么粒度（官能团级"这有酯键可水解"？
原子级"SP3 碳上有 H 可羟化"？）；做不到的粒度是否干脆不进硬过滤、
只进降位/提示层？有没有你建议的现成反应类型→位点映射的编目方式
（如按 EC 大类列可进攻键型）？

## 三、处置语义（顺带评）

违规候选的处置三选：**剔除**（不占报告位）/ **降位**（排到末位仍可报告）
/ **hold**（触发诚实弃权）。我们的默认：G1/G2 违规=剔除（守恒是硬门槛），
G3 违规=降位（位点判据不完美不该一票否决）。请评判这个分档。

## 四、输出格式

每组判据给：**verdict（成立/需改/推翻）+ 漏网案例（具体反应类型）+
建议改写**；末尾给"过滤器合用的风险清单"——你预计会误杀的合法单步形态
（误杀比漏放更伤诚实性，请重点找）。

## 五、约束

- 只评判据；不提供也不需要题目/金标数据；
- 回复将原文落盘（`docs/mimo_conservation_rules_review_response.md`），
  采纳与分歧逐条登记；过滤实现为确定性代码、零 LLM；**只加约束不放宽
  既有门禁**的红线不变。
