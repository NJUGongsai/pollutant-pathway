## 二、 核心机制设计：零束宽 `Catabolic-Progress B=1`

在严格维持 **零束宽 $B=1$（每个含碳分支每步只选 1 个反应事件，绝不发散分支）** 的前提下，当步候选事件（`Event #1..#5`）选择逻辑在 **Non-Backtracking（禁祖先倒车）** 基础上增加确定性化学进展规则：

### 2.1 硬门禁（第 0 层：禁祖先倒车）
- 先过滤掉所有含碳产物会与当前分支祖先集合 $\mathcal{A}$ 发生环路碰撞的候选事件（与 `non_backtracking_b1` 100% 相同）。若全部候选均倒车，则诚实判为 `CYCLE_ABORTED`（`all_candidates_backtrack`）。

### 2.2 规则 A：临门一脚直达终点 / $C_1$ 氧化递进优先（Sink-Closing & $C_1$-Oxidation Priority）
- **全碎片直达终点优先**：在当步非倒车合规事件中，若 `Event #1` 未能使当步所有非货币含碳产物全部进入 A0/A/B 矿化终点池，但同一步存在某个非倒车合规事件 $E_k$ ($k \ge 2$) 能使当步产生的**全部含碳碎片 100% 一步落入 A0/A/B 矿化终点池**（例如短链酸一步裂解入汇，或甲酸一步氧化为 $\text{CO}_2$），则直接优先选用排名最靠前的该直达终点事件！
- **$C_1$ 一碳有机物正向氧化优先**：当当前分支底物为 $C_1$ 有机分子（如甲醇、甲醛、甲酸等）且 `Event #1` 未进入 $\text{CO}_2$/碳酸盐终点池时，优先顺延选择能将 $C_1$ 碳氧化态提升（甲醇 $\to$ 甲醛 $\to$ 甲酸 $\to \text{CO}_2$）的非倒车事件，防止 $C_1$ 分支在门口反复发生无效修饰。

### 2.3 规则 B：抗等碳漂移顺延（Anti-Iso-Carbon-Drift Fallback）
- **零回退保护机制**：芳环双加氧开环前常需 1~2 步羟基化（$\Delta C = 0$），$\beta$-氧化硫解前常需水合+脱氢（2 步 $\Delta C = 0$）。因此设定漂移阈值 **$K_{\text{drift}} = 3$**（经离线验证对既有 38 条已闭合路径 **0 退化**）。
- **精准触发条件**：仅当当前分支满足以下条件之一，且当步 `Event #1` 依然是一个**“无结构突破的等碳修饰事件”**（即 `Event #1` 的最大含碳产物碳数 $= C_{\text{curr}}$、未减少芳环/杂环数、未减少外源毒害基团数、且无任何新产物进入终点池）时触发：
  - 条件 ①：该分支已连续 $\ge K_{\text{drift}}$（默认 3）步碳原子数未下降（$\Delta C = 0$）；
  - 或者条件 ②：当步 `Event #1` 会导致碳原子数逆向增加（$\max C_{\text{child}} > C_{\text{curr}}$）。
- **顺延目标（Substantive Catabolic Progress）**：
  在同一步非倒车合规事件 $E_2..E_5$ 中寻找第一个满足以下任一实质性降解进展的事件：
  1. **切减碳链**：主含碳碎片碳数显著下降（$\max C_{\text{child}} < C_{\text{curr}}$），或分裂为 $\ge 2$ 个更短含碳碎片；
  2. **劈开环系**：芳环数或总环数减少（$\text{Rings}_{\text{child}} < \text{Rings}_{\text{curr}}$）；
  3. **拔除毒基**：外源毒害基团（卤素、硝基、偶氮、磺酸、有机磷）数量减少。
  若存在上述实质性进展事件，顺延选用排名最靠前的该事件；若不存在，则退回保持选用 `Event #1`（绝不盲跳）。
