## 三、评审问题（逐条作答）

+立体盲）口径（覆盖 209/273 vs 严格 159/231），检索命中后仍按严格

**G2（组分级 donor 匹配 + 共底物声明）**：多组分记录（RHEA 净反应
常为"底物 A + 共底物 B → 产物们"）按组分级匹配——我们的题目底物

（不冒充单底物反应），编译仍按该记录完整净产物集合核对。
问：a) 把共底物组分声明为"条件/共底物参与物"是否语义诚实（相对
参考边的参与物集合比较，这些组分算什么角色）？b) 产物侧的完整性
要求（记录的全部产物都须出现）与共底物参与的组合是否会产生"程序
诚实但化学误导"的匹配（例如记录方向 RL 的产物集在酶学上不可逆）？
c) 共底物声明是否需要在事件参与物里显式列出（而非仅条件字段）——
对 P1 参与物集合比较的影响？

**G3（RHEA 双方向行 + 通配原子行）**：18,550 master 的 LR/RL 双行
保留为双方向候选（方向是记录声明，分层引用不合并）；8,502 条含
