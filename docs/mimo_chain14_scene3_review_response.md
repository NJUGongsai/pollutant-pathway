## Q1 字段误导面排查

**结论**：七类里真正能把**第一位排序**带偏的不是"字段说错了什么"，而是两类结构——**底物级字段（题内全候选同值）只能做全局先验、不能做区分**，以及**候选级的"可信度/完整度"字段被当化学用**。四句边界补丁（已读核对 `real_model.py:185-192` 在位）压住了"unknown=弃权""记账=机制"两条语义事故，但补丁压不住"这个数字该不该参与排序"这一层。

| 字段 | 误导风险 | 一句化学理由 |
|---|---|---|
| ① `edit_summary` | **中** | 有真区分度（逐候选不同），但"改键少=更可信""0 断 0 成账不平"两条启发式都不成立（隐式氢不计，`candidate_evidence.py:97-120`）；patch 后仍可能被读成"转化强度"排序 |
| ② `participants` | **中** | cosubstrate SMILES 是同底物面最强的真信号（NAD⁺/NADH 定氧化还原方向），但"参与物表更全"极易升格为完整度=可信度先验；role unknown 词面碰撞经 patch 降为中 |
| ③ `source` | **高** | `recorded_inferred` vs `analog_template` 是**出处**不是**化学**；`transformation_ref/alignment_ref` 的记录号还能触发预训练记忆反查——用记忆替代底物适配判断，是纯排序偏置不是区分度 |
| ④ `alignment_quality` | **中** | `n_alignments_total/n_equivalent/mapping_origin` 是程序与表示诊断；小整数与 "inferred" 枚举会被模型读成"该候选含糊/推断不可靠"的降权噪声，化学上不承载任何反应可行性 |
| ⑤ `conditions_and_scope` | **低** | 三键基本常值（requirements 常 unknown、partial、net_reaction，`candidate_evidence.py:215-229`），题内区分度≈0；patch 后弃权联动已堵，主要成本是 token |
| ⑥ 官能团表+元素计数+分子式（底物级） | **高** | 同题全候选同值＝零区分，却把模型全局推向"表里命中的基团"做反应（伪支持）；且 SMARTS 按所绘质子化形态算——羧酸根 `[OX1-]` 不中 `carboxylic_acid`、质子化胺不中 `amine_*`（`candidate_evidence.py:58,65-67`），**缺命中会被读成"该基团不存在"的假阴性**；`smarts` 字符串与 `matches` 原子 ID 数组是纯噪声；绝对分子式+系数全 unknown 还会诱发模型自发配平论证 |
| ⑦ Gasteiger 参考电荷（底物级） | **高**（min/max/lowest 3 原子）；**低**（mean） | 中性分子 Gasteiger 和≈总电荷 ⇒ mean≈0 近恒值、零信息；而 min/max 与最低 3 原子 ID 充当**位点猜测锚**，把第一位拉向"反应中心与电荷图吻合"的候选——酶位点、溶剂、质子化环境都不在模型内，方向可反（`candidate_evidence.py:324-359`） |

你点名的两个，我的读法与你一致并各加一句：**Gasteiger 均值是最典型的"看起来像证据的常数"**，它不区分题内候选却占注意力；**官能团命中表的问题不是噪声而是方向性**——它会单方面改变模型对"哪种转化受支持"的基线判断，等于给全体候选统一加了一个底物侧反应类型先验。

## Q2 选择面恶化机制（strict-rank>1 +4）

**结论**：最可能的两个机制都是**先验挤位型**，不是理解失败型——hit@3 持平、hit@5 +1、严格覆盖只 −2 说明正确候选还在前三，是**被挤下去**的，这正是"注入了排序先验"的指纹。

**机制甲（可能性最高）：出处/完整度先验替代底物适配判断。**
`source_kind`+记录号（③）与"参与物表更全"（②）让模型把记录感更足、字段更满的候选提到第一位，化学上更贴底物的那个被挤到第二。
可证伪表述：取 B 臂 strict 的 37 题中 A 对 B 错的题，比较"B 第一名 vs A 第一名"的 `source_kind` 分布与 participants 行数/coproduct 非空率——若被提升的候选系统性偏 `recorded_inferred` 且行数更多，支持；分布无差，否。**（需读两臂载荷与排序产物，未核对。）**

**机制乙（次高）：底物级描述符做位点/基团锚。**
⑦ 的最低/最高 3 原子 ID 与⑥的命中表合起来给出"该动哪儿"的暗示，模型选了反应中心与之重合的候选，挤掉原第一名。
可证伪表述：比较 B、A 两臂第一名候选的 `edit_summary` 编辑原子与 charge 极值原子/FG 命中原子的重合率——B 显著更高则支持；另看 `gasteiger=unknown` 或 FG 空表的题子集里 rank>1 是否不再恶化。**（同上未核对。）**

三者不互斥；若只能先验一个，我押**甲**，因为 ③/② 的区分度是"哪条记录更像真的"，与"哪条对这个底物更对"是两个变量，而本任务要的是后者。

## Q3 v2 裁剪与增补

**结论**：FG delta 首选**确认，且优先级应提到第一位**——它是本清单里唯一"逐候选不同 + 化学必需 + 系统内可确定性算"三项全占的字段。v2 应先做减法再做加法。

**砍（4 项）**

| 砍什么 | 理由 |
|---|---|
| ⑦ Gasteiger 全字段 | 零题内区分 + 位点猜测锚 + 所绘形态依赖；`_reference` 后缀和纪律句只防"当证明"，防不住"当排序锚" |
| ⑥ 中的 `molecular_formula`/`element_counts` + FG 的 `smarts` 串与 `matches` 原子 ID 数组 | 底物级常值；绝对式在系数 unknown 下诱发假配平；SMARTS/ID 对 flash 档是不可消化噪声。**FG 只留类名（+n_hits）** |
| ④ `alignment_quality` 小整数块（可整块砍） | 程序/表示诊断，非化学；留 `status` 一枚即可 |
| ⑤ `requirements`（常 unknown 时）与 `step_scope`（常 net_reaction）并成一行 | 零区分度字段占位；`participant_list_status` 必须留（防"列表完整"误读），显式 `requirements: unknown` 留一个词防"无条件"断言，不回退 scene1 立场 |

**留（每候选四块 + 底物两行）**：① `edit_summary`（紧凑版：n_edits/op_counts/bond_order_changes）+ ② `participants`（side/role/smiles，砍 `coefficient_status`，`coefficient: unknown` 留一词）+ ③ `source_kind` 单行（`transformation_ref` 建议砍——它本就是既有载荷白名单字段，证据卡重复呈现只添记忆触发面，scene1 注意项①）+ 底物 FG 类名列表与 `participant_list_status` 各一行。

**加（按优先级）**

1. **FG delta（首选，确认）**：逐候选 gained/lost 官能团类 + 本次编辑原子落在哪个基团——把⑥从底物级常数变成候选级区分度。
2. **候选侧负证据（Q4 联动，与 1 同批做）**："该候选在底物侧必需的官能团 ⊆ 底物命中表？缺 ⇒ `requirement_missing`"。这是 FG delta 的"必须"半边，机制上等价、成本几乎为零。
3. **Δ 分子式/氧化度（product−substrate）**：中性、确定性、直接给"−2H=氧化、+O=加氧"的方向线索——绝对分子式无用，**差值**有用；不涉 EC 不涉条件。
4. 队列中不新造：donor/cosubstrate 匹配层级（待完整恢复证明）、中性转化家族标签（应由 1 的 delta 直接渲染，**别做第二套实现**）。

**最小有效集（GLM-flash 消化约束）**：候选级 4 块 + 底物级 2 行，且把 token 增量压到 v1（+26% input）的一半以内作为**设计约束**——v2 若做，先按这个上限发车，再谈收益。另注：负证据与 FG 表共用 SMARTS，**必须先做质子化容忍修正**（羧酸根/质子化胺当前会漏），否则 2 会把假阴性放大成硬否决。

## Q4 歧义面为何没获益

**结论**：v1 在歧义面零收益，根本原因是**它喂的证据在题内是同质的**——电荷、FG 表、分子式对同底物的所有候选完全相同，`participants` 若池内各行也几乎一样（未核对），那 v1 对这 108 题的有效新增信息≈0。能区分"同底物不同合法目标"的证据形态必须**逐候选不同且指向"走到哪个终点"**：

| 证据形态 | 能区分什么 | 评价 |
|---|---|---|
| FG delta（得/失） | 醇→醛 vs 醇→酸 vs 酯化这类"终点分叉" | **必要不充分**：区域选择性异构、净结果相同（氧化 vs 脱氢同终点）的候选 delta 相同，仍无区分力 |
| **候选侧负证据**（该反应要求底物没有的官能团 ⇒ 否决） | 直接排除"底物根本没有酯键却提酯解"这类候选 | **够便宜且强**——它把底物级 FG 表第一次变成候选级区分度；是 FG delta 的互补半边，建议同批做 |
| Δ 分子式/氧化度 | 同一 FG 上走到几步（醛 vs 酸） | 中性方向线索，补 FG delta 的"深度"维 |
| 共底物/参与物方向（NAD(P)+/NAD(P)H、O₂/H₂O） | 氧化 vs 还原的方向 | 化学上最强单信号，v1 已带——若仍无效，先核 participants 的题内方差（未核对），再谈是不是被挤位 |

**FG delta 够不够：不够**，需 1+2 组合（Δ 分子式做第三优先）。且要诚实标注上限：无 EC/无酶名/无条件时，部分同底物歧义在零金标约束下**原理上不可判**——参考目标只是"记录当时选了哪一个"，任何能完全区分的字段都等于把记录身份或预训练记忆 smuggle 进来。建议下一轮预注册写明"歧义面只期望部分回收"，避免把没到位读成失败。

## Q5 负结果的读法边界

**结论**：我读成**字段设计问题（可修）为主**，证据强度**不足以**下"该档模型对信息注入普遍不适（不可修）"的定论；两者也不互斥——砍掉零区分字段本身就是对该档模型的适配。

**判断依据（四条）**：

1. **形态是重排不是塌方**：hit@1 −6 但 hit@3 持平、hit@5 +1、严格覆盖仅 −2、rank>1 +4——正确候选仍在前三，被挤下去；"消化不良"的预期指纹是覆盖掉/弃权升/格式轮消耗，结果报告未见这些（双臂零失败、3 调用预算零格式轮消费，`CHAIN14_EVIDENCE_AB_RESULT §三`——**未核对**）。
2. **先验源具体可指**（③出处完整度、⑦位点锚、⑥基团方向），不是泛泛"信息变多"——可修对象明确。
3. **−6 单独不构成证据**：与本批 45/298 翻转、历史 34/298 参照同量级；是 hit@1、rank>1、目标面三个同向读数叠加才够支撑"不装载"这个**决策**，不够支撑效应量这个**科学结论**。
4. **可证伪分界**：v2 砍到最小有效集后同协议重跑——rank>1 不再恶化且 hit@1 不再负 ⇒ 设计问题确认；砍光噪声仍负 ⇒ 才升级为档位不适，且那时的出路是改结构（更少字段/候选两两比较式），不是继续修剪字段。

不确定处：单批、单模型档，跨模型外推未核对。

**总体读法（≤5 行）**：v1 的问题不在纪律线（四句补丁方向对、在位），在**证据的"题内方差"**——底物级三件（电荷/FG 表/绝对分子式）零区分却能改全局先验，候选级两件（source/完整度）是可信度不是化学，正是这五件最可能把第一位带偏。v2 顺序：先砍这五件，再做 FG delta+候选侧负证据（同批，附 SMARTS 质子化容忍修正），Δ 分子式次之；歧义面收益期望写"部分回收"。−6 本身在噪声量级，只支撑"不装载"的决策，不支撑"信息注入必然有害"的结论；设计问题 vs 档位问题的分界用 v2 复跑的 rank>1 来判。以上按与程序证据互证采信，执行类事实未核对。
