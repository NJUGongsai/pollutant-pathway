## 三、recorded 源与任务口径判据（W2/W5）

- **W2-A 分层**：`recorded_strict_exact` = 库记录 donor 的**严格结构身份**（canonical 含电荷/立体）== 当前底物严格身份，方向 donor→products，且编译执行产物的**逐组分严格身份多重集** == 库记录完整净产物集合（同 (btid, reac_id) 全部行）；`recorded_cn_candidate` = CN（电荷归一立体盲）同而严格身份异 —— 不升格 strict；`analog_transfer` = 另一底物（相似通道，不属 exact 分层）。
- **W2-B 完整净产物**：一个原反应多产品构成**同一事件**（一候选）；不同原反应是备选事件，不拼共同产物；过滤声明（ion/cofactor filtered）如实透传；过滤过的单产品行不冒充完整 record（缺组分 ⇒ product_set_mismatch 拒）。
- **W2-C 推断映射**：无原生映射 ⇒ 确定性结构对应（元素标记 + any-bond 子结构同构枚举，上限 200）：产物原子数 ≤ 供体 ⇒ 逐产物组分在供体内枚举同构、组分间供体原子不相交组合；供体原子数 < 产物 ⇒ 供体在单一产物组分内同构；未覆盖供体原子 = 离去组分、未覆盖产物原子 = 新原子。同目标映射合并、异目标歧义拒、枚举触顶拒。标 `mapping_origin=inferred`（不是原生/机制证据）；中心 = 推断变换的变化原子（键差端点 + 离去）+ 新增原子。

## 四、评审问题（逐条编号作答）

**A. 编译器芳香/共振判据（§二 R5）**

- A1：aromatic≡aromatic 不算键差、双侧独立 Kekulé 的"6 键反向"按伪键差丢弃 —— 这对苯/吡啶/稠环（萘、吲哚）都成立吗？哪些芳香系会出现"合法的逐键 Kekulé 差异"被误当成不变（或反之）？
- A2：去芳香化要求**整环系同步**显式键级（部分去芳香拒）—— 化学上是否过严/过松？Birch 型（1,4-环己二烯）、Hantzsch 型（1,4-DHP）产物会被正确表达吗？环系闭合用"BFS 芳香键邻接"定义，稠环共享键跨环时是否正确？
- A3：芳香化取 **rhs kekulé 形对应键**落图、执行后 sanitize 重感知 —— 杂芳香（吡咯 [nH]、吡啶 n、呋喃 o）经该路径能否还原出正确芳香分子？有没有 sanitize 重感知与原记录不一致的病理情形？
- A4：新成键目标 aromatic ⇒ unsupported（芳香环新合成不做）—— 这会拒绝哪些真实的酶促转化（如环化芳构化）？在"诚实 unsupported"与"表达力缺口"之间，这个取舍该不该保留？

**B. 键级/价态/氢判据（§二 R4/R6/R7）**

- B1：from_order 从当前底物 kekulé 执行图读、模板 lhs 只作核验 —— 供体/底物 Kekulé pattern 不同（同一芳香环两种交替写法）时，显式键级核验会不会误拒合法迁移？
- B2：新增原子带形式电荷一律拒；保留原子电荷变化一律 unsupported —— 常见酶促转化（脱羧生成 CO₂⁻/HCO₃⁻、磷酸转移、CoA 硫酯）里有多少会被这两条挡住？这个首版边界是否合理？
- B3：氢数变化隐式随键级 sanitize 结算（不显式编辑 H）—— 哪些转化（水合/脱水/脱氢）会因此出现产物 H 数错误而未被拒？
- B4：离去组分 = 断键后留多组分产物（不删除）—— 对 β-氧化断链、水解断 C-X、脱羧的净产物集合语义（主产物 + 共同产物）是否正确？
- B5：`SN_<元素>_<n>` 新原子 ID 与执行器命名空间 —— 有无与 MoleCode 渲染 ID 冲突的边角（同元素多新原子、跨模板序号复用）？（此条偏工程，可一句话。）

**C. recorded 源分层与推断映射（§三）**

- C1：strict exact 要求 donor 与底物**严格身份相等**（电荷/立体全同）—— EAWAG 库里负离子 donor（如邻苯二甲酸二阴离子）对中性底物查询会落到 CN candidate 不升格 strict：这个边界对吗？还是应该允许"质子化态差异但骨架相同"升 strict（配平语义上差一个 H⁺）？
- C2：编译执行产物**逐组分严格身份多重集** == 库记录完整净产物集合才通过 —— 库记录本身漏写共同产物（数据缺口）时会被 product_set_mismatch 拒：这是想要的保守行为吗？还是应披露为 partial 而非拒？
- C3：推断映射的 any-bond 元素标记同构（产物⊆供体组分分离 / 供体⊆产物二选一）—— 对称分子上会不会系统性选出"错误但同目标"的对应（同目标合并可接受）或假歧义（不同目标拒但化学上等价）？给出你最担心的 2 个反例类型。
- C4：`recorded_cn_candidate` 不进 strict 但作为 analog 级候选供给 —— CN 同而电荷/立体异的记录以类比通道迁移时，电荷差异会在编译层被 charge_edit_unsupported 拒：这条链路的诚实性（不冒充 exact）与供给损失（大量负离子记录不可用）如何权衡？

**D. 任务口径与判分边界（§三 W5 / §一）**

- D1：中性"酶促单步转化"任务 + 至多 8 个不同净反应 + 弃权合法 —— 对 298 题域（RHEA 通用酶学）的任务描述是否会系统性偏向某类转化（如水解/氧化）而漏还原/异构/连接？
- D2：主口径 matched_strict 要求事件参与物侧与参考边全部产物严格身份匹配（不忽略共产物）—— "完整净产物集合"作为判分面，对漏检小分子共产物（CO₂/H₂O/NH₄⁺）的惩罚是否化学上过严？注意：判据冻结不在本轮评审的修改范围，只评"是否有化学上站不住的表示层错误"。
- D3：编译器对"同净产物集合"去重（不同 source 同净反应合并 provenance）—— 两个来源不同但产物集合相同的反应（如不同酶同底物同产物）合并为一个候选事件：会丢掉什么该保留的化学信息（条件/酶特异性）？这些信息当前是否已在事件/假设层保留？
