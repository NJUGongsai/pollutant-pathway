## 2. 各臂预注册

通用字段（每臂六项）：单一机制差异 / 主终点 / 最小有用增益 / 回退上限 / 费用上限 / 停机规则。

### 2.1 E2 温度臂（先行臂）

- **单一机制差异**：三协议（extract/rank/…）与 LLM client 显式 `temperature=0`
  （`adapters/llm_client.py` + `workflow/nodes.py:_prompt_for` 组装处）；温度参数进 policy 与 run identity。
  登记时提供方缺省行为：client 当前缺省不发 temperature（`llm_client.py:157` 显式禁发，
  GLM-5.3-Flash 等按官方默认 T=1.0 运行）——本臂即把"协议要确定性 vs 请求容忍抽样"的矛盾钉死：
  提供方在 T=0 下的实际确定性行为（完全确定 / 仍有残余噪声）写入登记文件，不假设。
- **主终点**：dev cn@1（配对净赢 vs C0 照报，但见判 win 条件）。
- **机制预期与 win 条件**：本臂预期"增益"体现为**方差下降**而非均值上升。判 win =
  逐题翻转数显著减少：同一臂两次独立采样（同题卷、同身份、新批次根）之间 cn@1 结果翻转的题数 F；
  比较 E2 的 F_E2 与 C0 的 F_C0（C0 需同样两次采样；若 C0 单次即零翻转则提供方本就确定，
  记录后 E2 自动 inconclusive-无必要）。**预注册口径**：F_E2 + F_C0 ≥ 3 时用符号检验方向性
  （双侧 p<0.05），或 F_E2 ≤ max(0, F_C0 − 3) 记显著减少；两者任一成立且 E2 cn@1 均值不劣于
  C0 −2 题 → `dev_candidate`。
- **最小有用增益**：均值不降（≥ −2 题）+ 翻转显著减少（如上）。
- **回退上限**：cn@5 不降超过 2 题；空答率不升超过 2 题；spurious 率不升。
- **费用上限**：单批次 ≤ ¥5（56 题 × ≤3 LLM 调用 × 2 次采样）。
- **停机规则**：单批非法终态（超时/孤儿/解析失败）>10% → 批次作废，修基础设施后新批次根重跑；
  单批费用 >¥8 或总费用触顶（§5）→ 停机上报。

## 3. 跑分顺序与配对结构

**C0 → E2 →（E3，E1 并行或串行均可）**。

1. **批次 1 C0 基线**：当前行为（缺省不发 temperature）。同时作 E2 的对照。
2. **批次 2 E2**：先行，因其可能改变基线方差——若 E2 判 win（方差显著下降），
   E2 落地后**作为 E3/E1 的新对照**（E3/E1 臂在其配置上各自叠加单一差异，对照 = E2 配置批）；
   若 E2 inconclusive 或 rejected，E3/E1 直接对 C0 配对（温度行为与 C0 一致）。
   无论哪种结局，E3/E1 的对照选择在发车前登记，看分后不得换对照。
3. **批次 3+ E3、E1**：各 56 题，与其登记对照逐字段相等除单一差异。
4. 方差监控触发（任一批内重试/不一致迹象，或 E2 显示提供方非确定）→ 关键臂加第二次采样
   （新批次根、同身份）报方差；单次抽样不证因果写进报告模板。
5. 已判臂不重跑（E4 到位后只补缺角臂，见 §6）。

## 4. 采用判据与止损门（**提案，待用户批准**）

> 以下数字为预注册提案；未经用户批准不得发车。批准后看分不得再改（I2）。

- **单臂采用**：dev cn@1 净赢 ≥3 题（3/56 ≈ 5.4pp）**且** cn@5 不降、空答率不升
  （E2 按 §2.1 的翻转口径替代均值门槛）。满足 → `dev_candidate`；不满足净赢但次级指标
  全守 → `rejected`（均值未动）或 `inconclusive`（方差/账目不完整）；任一次级回退上限击穿
  → 一律不得 `dev_candidate`。
- **结论三态**：`dev_candidate | rejected | inconclusive`，不写 `adopted`（发布默认变更另走发布审查）。
- **累计止损门（teacher §4 S1）**：各已判臂净赢（pp，对其登记对照）累计 <+8pp →
  停止冲刺，出止损结论，重估目标或转 S3——不带弱证据去碰 298。判定点在每个臂判定后立即评估。
- **小样本纪律**：56 题逐题四格 + 区间一起报；净赢 3 题恰在噪声带边缘时结论只能
  `inconclusive` 或依赖 §3.4 的二次采样方差证据。
