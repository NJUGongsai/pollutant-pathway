## 0. 术语与判定单位（口径 v3 的操作化定义）

| 术语 | 定义 |
|---|---|
| 候选 | 答卷 `steps[].predicted_products` 跨 step 顺次拼接后的有序条目；**不可解析候选占名次但不命中**（与 v2 一致）；空答留分母 |
| 金标主产物组分集合 G(qid) | `products_smiles` 每条按 `.` 拆分，逐组分取 `cn_identity`（cn-v1：电荷归一 + 立体盲 canonical，与判分同源），收集全部非 None 身份；**为空即 fail-closed 报错** |
| 候选组分集合 S(c) | 候选 c 按 `.` 拆分，逐组分 `cn_identity`，非 None 身份集合 |
| **命中（主分）** | 存在位次 r 使 **G ⊆ S(c_r)**（「全部主产物组分命中」）；rank = 最早 r；@k = rank ≤ k |
| partial（单列指标，不进主分） | rank 为 None 且 `covered ≠ ∅`，其中 covered = (∪_r S(c_r)) ∩ G |
| scattered_full（partial 子旗标） | rank 为 None 且 covered = G（金标组分全被覆盖、但分散在不同候选、无任何单候选全覆盖） |
| 题域标签 | dev = B1 环境路径中间步骤；298 = RHEA 通用酶学。**双向不外推，所有对外数字必带标签** |

版本标识：`v43-exam-caliber-3`（代码常量 `CALIBER_V3_VERSION`）。

## 1. 条件①：组分命中细则（teacher 原文逐条落盘）

teacher §五.4.1 原文语义，**不得走样**：

1. 多主产物金标「**全部主产物组分命中 = 对**」→ 操作化为 §0 的
   `G ⊆ S(c_r)`（候选组分**包含**全部金标主产物组分）。
2. 部分命中单列 **partial** 指标、**不进主分** → §0 partial 定义；
   partial 只作披露列，任何主分/配对判定不使用。
3. **禁止「任一组分命中即对」（any-of 明令禁止）** → 两处同时生效：
   - 含 `.` 候选不再"任一组分命中即对"（既有 `component_mode` 语义）；
   - **多产物金标下单组分候选只答对其中之一也不再判中**（v1/v2 整串模式
     在多产物金标上事实是 any-of：gold_ids 是集合，单产物命中即计）。
     该类题降级为 partial。

### 1.1 实施前核对结论（现有实现 vs v3 细则）

核对对象 `src/pathway_v43/exam_v2.py::first_hit_rank(component_mode=True)`
（COVERAGE_STAT M3 与 multicomponent_sensitivity 表所用代码路径）：

| 项 | 现有实现 | v3 细则 | 结论 |
|---|---|---|---|
| 含 `.` 候选 | 任一组分命中任一金标产物即取该名次 | 全部金标组分被该候选覆盖才命中 | **不一致（any-of，明令禁止）** |
| 多产物金标 + 单组分候选 | 整串身份 ∈ gold_ids 即命中（=答对任意一个产物即中） | 只覆盖部分组分 → partial，不进主分 | **不一致（整串模式同为 any-of）** |
| 部分命中 | 无此指标 | 单列 partial | **缺失** |

**修正方式（允许改代码，属判分定义勘误）**：

- 新增 `gold_main_component_ids()`（G 的构造，fail-closed）与
  `first_full_coverage_rank()`（v3 主分 rank）；v3 重刷一律走新函数。
- **既有 `first_hit_rank` / `component_mode`（any-of）原样保留**，仅用于
  历史敏感性表的复现（M3/multicomponent_sensitivity 为 v2 时代探索性读数，
  历史数字不覆写）；任何 v3 主分路径禁止调用 any-of 路径。
  差异与修正即本节登记。

### 1.2 数据结构核对（实施时实核，结构性事实非重刷结果）

- dev 56：52 单金标、4 双金标（008-S03 / 010-S04 / 058-S01 / 149-S04），
  金标条目内无 `.` 点串；298 金标 298 题：253 单条目、41 双条目、4 三条目，
  条目内无点串、底物均单组分、全部可解析。→ G 的构造在两卷上均退化为
  「逐条目身份集合」，与 v2 `gold_ids` 同集；点串条目拆分为**前瞻泛化**
  （若未来题卷出现点串条目，同规则适用，不另行口径）。
- dev 7 道整串假失分题（B 桶）的救回候选构成：**5 题为「金标组分 + 额外
  共产物组分」（超集）**、2 题为 2/2 精确覆盖。→ 若采用「精确匹配」语义
  （候选组分集 = G），5 题不救，@1 = 9/56，与 teacher 参照 14/56 不符；
  mimo D1 原文（「化学答案已含全部金标组分」「断键/水解的另一半骨架被
  模型一并写出，金标只收了主产物那一半」）亦为**包含**语义。
  **故 v3 = 包含语义（超集不破命中）**，精确匹配语义否决。
- 超集语义的**已注册边界**（如实披露）：候选含全部金标组分**外加一个
  化学上错误的组分**时仍判命中（精确度侧风险）。处置：不额外发明判据
  （无法在不引入化学知识的前提下确定性区分「真实共产物」与「错误组分」，
  且 teacher 参照数字锚定包含语义）；注入测试（§2）将该边界显式钉住为
  **已知注册项**，并新增披露列 `hit_with_extra_components`（命中的触发
  候选含 G 之外组分的题数）供报告透明。
- **149-S04 型 any-of 假阳性剔除（v3 与参照偏差的来源，先期登记）**：
  149-S04（双金标）在六批的整串读数内均为「单组分候选命中双金标之一」
  （位次 1–3 不等；E2-b 另有 058-S01 同型）。v3 按细则③将其从主分移入
  partial。**预期**：六批 @1 增益 = C0-a/C0-b/E2-a/E3 四批 +6、E1 +5
  （其整串 @1 含 149-S04）、E2-b +4（含 149-S04 与 058-S01）；@3/@5
  增益预期 +6（非 M3 any-of 的 +7，差异源 = 同型剔除）。以重刷实测为准，
  差异如实登记——**这不是口径失效，恰是 any-of 禁令的另一侧生效**。
- 敏感性辅读（不改主分、不入封存主读数）：「累计覆盖」语义（scattered
  全覆盖按覆盖完成位次计 hit）会使 149-S04 型在 @5 保留。**不采用**，理由：
  候选列表是有序备选（每条候选是一次完整预测），模型从未声明「联合产物
  = A+B」时不应按拼接替它声明；v3 修正的对象是「多组分候选可判分」，
  不是「合并多条单组分预测」。该读数在 detail 文件中单列
  （`rank_v3_cum`）供披露。

## 2. 条件②：假阳性分析义务（错配注入测试）

**目的**：证明口径 v3 不会把错答洗成对答。两层：

1. **pytest 合成夹具（长期钉住，不含任何真实金标）**：
   `tests/test_exam_v3_caliber.py`，四类注入 + 边界：
   - **完全命中**：G={A,B}，答卷 `[X, A.B]` → v3 rank=2 计主分；
   - **缺一组分**：G={A,B}，答卷 `[A]` / `[A.C]` → v3 miss + partial
     （断言同时钉住：v1/v2 整串在 `[A]` 上判 rank=1 —— any-of 假阳性
     被 v3 修复）；
   - **部分命中（scattered）**：G={A,B}，答卷 `[A, B]` → v3 miss +
     partial + scattered_full；
   - **多一错误组分**：G={A,B} 答卷 `[C.D]`、G={A} 答卷 `[B.C]` →
     v3 miss（错误答加错误组分不产生命中）；**注册边界**：G={A,B}
     答卷 `[A.B.C]` → v3 hit（§1.2 超集语义已注册项，测试钉住防漂移）；
   - 辅助：点串金标条目拆分、不可解析占名次、空 G fail-closed、
     partial 计数、重复候选。
   **通过判据**：全部错答注入样本 v3 主分零命中（0 洗白）；
   全部完全命中样本命中；partial/scattered 旗标逐例正确。
2. **真实六批答卷注入审计（离线，金标只在评分进程内使用）**：
   `dual_track_rescore/injection_audit.py`。对六批每题构造注入变体
   （缺一组分：把 v3 命中题的触发候选删去一个金标组分，断言命中消失；
   多一错误组分：对 v3 miss 题的候选追加一个非金标组分，断言仍 miss；
   部分命中/完全命中对照组），产出只有 qid/计数/旗标。
   **通过判据**：洗白数 = 0（错答注入后 v3 主分命中率不升）。

## 5. 金标体检（随本预注册一并冻结的确定性规则判据，标注「待 mimo 评审冻结」）

四条规则全量跑（dev 56 + 298 全卷只诊断打标）→ quarantine 提案表
（qid、规则命中、处置建议）→ **剔分母处置等人审 + mimo 评审后再生效**
（两份 mimo 评审请求已在用户手上待送；规则判据标「待评审冻结」，评审
独立性不做背书，采信到与程序证据互证为止——teacher §八.5）：

- **R1**：金标含题面没有的元素 ∈ {P, S, 金属, 核糖/核苷酸骨架} 且无
  共底物解释 → `gold_cosubstrate_unreachable`（题面元素集合 = 题面
  全部组分元素之并；若题面本身多组分则共底物元素自然「在题面」不判新，
  即共底物解释的确定性实现）。
- **R2**：金标相对题面新增元素仅 {O, H} → 保留（O₂/H₂O 可默认供给；
  新增 O/H 不打标）。N/卤素等不在 R1 集亦不在 R2 白名单 → 不打标、

- **R3**：金标碳数（全部金标产物碳数总和）> 题面碳数且无共底物解释 →
  `gold_conserv_violation`。

- 合成夹具钉规则：碳守恒通过/不通过、退化、CoA 例外（题面含共底物 →
