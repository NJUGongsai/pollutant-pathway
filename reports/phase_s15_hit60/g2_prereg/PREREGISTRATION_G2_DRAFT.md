### 2.0 适用对象与声明语义

- 适用对象：novel/analogy 产出、进入答案的每个候选（含 `.` 多组分串——
  按 G1-a/G2-a 全物种口径整体计数）。dev 题卷构造为单步（max_depth=1），
  本臂全部候选按**单步产物**处理；整体矿化式答案（"X → CO₂ + H₂O + NH₃"
  型）落 G1-b 越界 → 降位（不是违规，是超出口径；mimo 风险 #4）。
- **产物列表完整性声明（两处硬剔除的共同前提，操作化定义）**：仅当候选
  note 含封闭关键词表中的完整声明（版本化关键词表 v43-cons-kw-1，如
  "complete"/"唯一产物"类显式声明）时视为"声明完整"；**novel 候选默认
  "未声明完整"**。未声明完整时，增侧与减少侧的守恒异常一律落"不可审计
  → 降位"，不落剔除（mimo 风险 #2：隐式共存供体经常不写，把信息不足当
  违规是本过滤器最可能的诚实性出血点）。

### 2.1 G1-a 全局碳守恒（硬剔除档；唯一与 G2-a 并列的守恒硬剔除）

底物侧与产物侧的**全部含碳物种**计数：含 CO₂/HCO₃⁻、CN⁻、甲酸、甲醛、
乙酰-CoA、糖基、酰基等一切含碳碎片，含显式写出的气态产物。

- **违规①（增碳无登记供体）**：产物总 C > 底物总 C + 题面已登记碳供体
  提供的 C，**且产物声明完整** ⇒ 剔除；
- **违规②（原子消失）**：产物声明完整，却 产物总 C < 底物总 C ⇒ 剔除；
- **不可审计（降位）**：其余碳减少且含碳碎片未显式列出（C1/C2 去向不明）
  ⇒ 降位。**脱羧、β-氧化硫解、双加氧开环小分子释放、氰醇裂解、糖苷/酯/
  酰胺水解属此族保护对象**（数全物种时脱羧 ΔC=0；碎片未列时降位不剔除）。

### 2.2 G1-b 主产物碳骨架（启发式，降位档）

主产物（候选中碳数最大的有机组分；并列时取题面母体结构相似度最高者，
相似度口径 = v43-norm-1 规范化后的 Morgan r2 Tanimoto）相对题面母体分子
的碳数变化允许集 **ΔC ∈ {0, −1, −2, 断键裂解}**：

- **−1**：脱羧、脱羰、脱甲基、氰醇裂解等 C1 脱除（脱甲基算 −1，不算裂解）；
- **−2**：β-酮硫解、逆醛醇、α-羟基酸裂解产生的 C2 缺口；
- **断键裂解（一变多）不按配比枚举、按键型判定**：母体上被断的 C–C 键须
  邻接氧化位或不饱和位（逆醛醇要求 β-羟基或 β-酮、硫解要求 β-酮、双加氧
  开环要求芳环），用母体结构 SMARTS 机械判定；C10→C6+C4 与 C10→C7+C3
  同判放行；
- **增碳**：仅当题面显式登记碳供体时放行（供体表见 §2.4）；
- 越界（ΔC ≤ −3 非键型合法裂解、或 ΔC > 0 无登记供体）⇒ **降位**（不是
  剔除；金标口径登记的裂解配比**永不**作为放行依据——评审明确否决，同时
  踩金标不入仓与 novel 退化为回忆两条红线）。

### 2.3 G2-a 全局杂原子守恒（硬剔除档）

对 **N / S / P / 卤素 / 金属**做与 G1-a 相同的两侧全物种计数（产物侧含
NH₃、X⁻、SO₃²⁻/SO₄²⁻/H₂S、Pi、H₂O 等无机碎片）：

- **违规（增杂原子无来源）**：产物侧出现"底物 + 题面已登记共底物"之外的
  杂原子，**且产物声明完整** ⇒ 剔除；
- **不可审计（降位）**：杂原子消失且受体/无机碎片未显式列出 ⇒ 降位；
- **金属特例**：仅共价键合的金属新增计违规；配位复合物/金属离子缔合不按
  "新增金属"剔除；配位与共价不可区分时 → 豁免并标注"不可判定"（hold 触发
  族，mimo 风险 #6）。

### 2.4 G2-b 主产物杂原子增删（分档）

- **新增默认仅 {O, H}**（源 O₂/H₂O，含氧基团氧化不改档）；新增 N/S/P/卤素/
  金属 ⇒ **剔除，除非题面显式登记供体**。供体登记**封闭表**（默认隐式供体
  恒为 {H₂O, O₂}，不含 HCO₃⁻/NH₄⁺/ATP 等——每默认放宽一项等于把门禁拆
  一角）：

| 供体（题面显式登记才生效） | 覆盖反应类 | 引入 |
|---|---|---|
| NH₄⁺ / 谷氨酸 / 丙氨酸 / 谷氨酰胺 | 转氨、还原氨化、酰胺转移 | +N |
| ATP | 激酶磷酸化 | +P |
| SAM | O-/N-甲基化 | +C1 |
| PAPS / APS | 磺基转移 | +S |
| UDP-糖 / 核苷糖 | 糖基转移 | +C6 |
| 乙酰-CoA / 酰基-CoA（丙二酰类须显式登记） | 酰化 | +C2/+C4 |
| 羰基磷酸 | 氨甲酰化 | +C1 +N |
| CO₂ / HCO₃⁻ | 羧化 | +C1 |
| 另一个有机羧酸（ThDP 偶联） | 脱羧性 C–C 偶联 | +C |

- **卤素新增：有意禁用，登记为"先验排除"**（被设计排除，不是被遗漏；登记
  待定项：卤化剂将来是否解禁——维持禁用）。卤素迁移（邻位移）不改变卤素
  计数，不触发。
- **减少侧白名单（一次性写全，全表）**：脱卤（还原/水解/氧化脱卤、脱卤素
  酶）、脱硫（含脱磺酸、硫酸酯水解、硫醚裂解）、脱氨/脱酰胺、**脱磷酸**
  （磷酸酶/酯酶）、**脱糖基**（糖苷酶）、**脱酰基**（酯酶/酰胺酶）、**含氧
  基团还原脱 O**（硝基→胺、N-氧化物→胺、亚砜→硫醚、过氧化物）。白名单外
  的减少 ⇒ 不可审计 → **降位**，不落剔除（注意：硝基→羟胺→胺是脱 O 不是
  脱 N；脱羧不改杂原子计数，归 G1-a 口径管）。

### 2.5 G3 可进攻性三层 + 处置四档语义

**G3 三层（拆分冻结）**：

- **G3-a 价键/形式不可行（硬剔除，可并入统一结构有效性门）**：五价碳、
  芳香性/环完整性被破坏、饱和碳加 OH 未脱 H、无登记供体的烷基/酰基/糖基/
  磷酸基新增、形式电荷不平衡、"无 H 的碳被直接羟化且未去饱和"（位点不可
  能上收至此）。零化学先验、可完全确定性计算、误杀 ≈ 0。
- **G3-b 官能团级可进攻性（标注 + 降位）**：以 EC 第三位/KEGG RCLASS/
  UM-BBD 键型表生成"底物具备的可进攻键型 → 允许的首步反应类"清单，随候选
  一起给出（标注）；候选的转化不在清单内 ⇒ 降位，不剔除（编目覆盖不全是

### 2.6 前置规范化（v43-norm-1；计数前的硬步骤，不是可选项）

1. **电荷归一**：rdMolStandardize.Uncharger，与判分 cn_identity 同源口径；
2. **立体忽略**：判分口径立体盲，同构处理；
3. **去盐剥离 spectator 反离子**：两侧（题面与候选）都剥离带电单原子
   spectator，salt_form 标记入报告；
4. **互变规范化**：TautomerEnumerator.Canonicalize 后再计数（门 1 迭代 2
   实测：互变规范化指纹为两轮最优零成本信号，K=16 捞 12/22、+6；计数侧
   防互变写法差被读成 ΔH/ΔO——mimo 风险 #5）；
5. **解析失败按"未知"不按"零"**（gold_health 断言 3 教训）：题面/底物解析
   失败 → 整题 hold（无法判定族）；候选产物解析失败 → 该候选降位 +
   parse_fail 计数入报告，不参与守恒判定与自排序键；全部解析失败题/候选
   进入事后人审清单（判定按预注册线即时出，人审清单供 §7.4 结果复核）。

### 2.7 确定性自排序键（v43-selfrank-1；冻结键序）

novel 自产候选（降位/剔除处置完成后）按以下键序重排：

1. **处置档**：未违规项 → 降位档垫底（未违规项之后）→ 剔除档不入榜；
2. 未违规项内部：**反应类型匹配（G3-b 清单命中）> 位点白名单匹配 > 来源
   强度（提案位次）**；
3. 同分稳定序：提案原位次（保序，防实现者自由发挥）。

**两处明令禁止（迭代 2 硬证据，见 §3）**：守恒连续值（cons 罚分）**不参与
任何排序键**（只进披露列与簇识别）；守恒档**不作全局前置排序**（档位是
分量不是主序）。**纯重排硬验收沿用（E1 order 契约工程复用）**：自排序
分量执行后候选集合与 @5 逐题不变（pytest 钉住）；集合变化只允许来自剔除
与 hold（§2.5）。

## 3. 降位制约束（迭代 2 硬证据 → 设计原则，冻结）

门 1 迭代 2 在封存 C0-b 检索池上的测量（33 配置，零 LLM）给出三条硬证据，
全部写进本臂设计原则：

1. **硬过滤误杀率 7/22（32%）**：任务书口径的守恒硬过滤（ΔC∈{0,−1,−2}
   且杂原子限 {O,H}）杀死 22 题金标卡中的 7 题（005/008-S01/008-S03/
   010-S04/053-S02/081-S03/143-S04）。按硬剔除语义部署会永久损失这 7 题
   → **本臂默认降位不硬剔**；硬剔除仅限 §2.1/§2.3 的"可证明违规 + 声明
   完整"双前提与 §2.5 G3-a（价键不可行）。
2. **守恒优先排序是反向先验**：22 题金标卡 cons 分布 = cons=0（同分异构/
   互变级）5 题、0<cons≤1（小步）6 题、**cons>1（原子数变动）11 题**；
   预声明主口径 s3x（cons 升序）回撤到 7/10/10（比基线 S3 的 9/12/13 还
   差）→ **守恒特征只作簇识别与降位分量，不作全局前置排序**（§2.7 明令）。
3. **互变规范化有增益**：S3-taut 12/22（K=16，+6 对引擎，两轮最优）→
   互变规范化进前置规范化硬步骤（§2.6.4）。

## 5. 对照设计（两选项，待冻结时定）

**共同前提（设计钉死）**：过滤器为纯后处理、无生成端反馈（§1.1）→ 开关
off ≡ 无过滤器行为。该等价性须在发车前以 **no-op 回归**证明（同输入同
输出逐字节一致 + pytest 钉住 off 路径），是方案 B 的启用条件。

### 方案 A：同代码关过滤重跑 C0（in-run 双臂新跑）

- 结构：主臂（开关 on）与对照（开关 off）各为新批次根、同 commit、同资产、
  同协议，各 ≥2 次独立采样（双采样）→ 4 个计费批次。
- 配对性质：**身份级配对**（除开关外逐字段相等，S1 纪律字面合规）；答案级
  不配对——novel 采样方差（@1 翻转 ~7 题量级）直接进入臂差，须靠双采样
  均值与逐题配对吸收。
- 费用：单批 ≤¥3（S1 单臂单批 ¥2.3–2.5 参照）；总帽 ≤¥12（4 批 + 烟测）。
- 附加价值：验证开关进 run identity 的生产 in-run 形态。

### 方案 B：复用封存 C0 答卷 + 离线确定性重放（判读主案建议）

- 结构：对照 = dual_track_rescore 封存 C0-a/C0-b（v3 读数即 off 读数，
  C0-a/C0-b 本身即同身份两次独立采样）；主臂 = 对**同一封存答卷**离线应用
  过滤器 + 自排序（确定性、零 LLM）→ 每题 on/off 同底答案的配对读数。
- 配对性质：**答案级完美配对**（同一底答案、确定性开关差、零 novel 采样
  方差）——@1/spurious 差值纯归因于过滤器；双采样现成（两封存样本分别
  重放 + 一致性核对）。
- 身份差异（须登记）：封存 run 产于无过滤器代码路径的 commit；以 §5 开头
  的 no-op 回归证据支撑行为等价（off ≡ 无操作）；重放器版本
  （v43-g2-replay-1）与判据版本一并封存。
- 费用：生成成本 ¥0（无 LLM 调用）；仅本地确定性计算 + 判分（金标仅在
  离线评分进程打开）；总帽 ≤¥1 计账余量（若追加一次 in-run 烟测批则
  +¥3）。
- 适用前提：纯后处理钉死（§1.1）+ no-op 回归通过；若将来过滤器要进生成端
  （反馈形态），B 测不了（本臂明确无反馈，故无此效应）。

### 两选项差异一览

| 维度 | A（in-run 新跑） | B（封存重放） |
|---|---|---|
| 配对严格度 | 身份级（代码/资产逐字段同） | 答案级（同底答案，更强）+ 身份差异登记 |
| 采样方差 | 含 novel 重采样方差（@1 翻转 ~7 题量级） | 零（确定性重放） |
| 费用 | ≤¥12（4 批） | ≈¥0（生成侧） |
| 形态 | 生产 in-run 形态验证 | 判定用离线测量（门 1 迭代 2 先例） |
| 前提 | 无额外前提 | 纯后处理钉死 + no-op 回归通过 |
| 风险 | +3 净赢被采样方差淹没（双采样必要） | "重放非真跑"的形态质疑（判定对象本就是确定性后处理，重放即全息测量） |

**建议**：B 为判定主案（配对最干净、零成本、双采样现成），A 为可选补强
（若 teacher/用户要求 in-run 生产形态先行验证）。**待冻结时定。**

   闭卷 30% 里程碑重估，**teacher 侧重新审议目标，学生不得在 dev 上加臂
